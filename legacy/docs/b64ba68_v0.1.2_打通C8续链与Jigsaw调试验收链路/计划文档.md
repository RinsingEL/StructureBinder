# 本次任务标题
修复 `jigsaw_solve` 不入树与 `start` 高度偏高的主链 Bug

# 最终计划摘要
本轮只修两条主链问题：

- `city_jigsaw_solve` 成功后把真实 child 沉回 `C8` 会话树，`apply_now` 只决定是否同时落地到世界。
- `start` 的高度改成按当前运行时已加载模板的真实 start connector 定高，兼容 `bettervillageforge` 这类覆盖 `minecraft:` 结构的 mod。

本轮不处理“方向偶发不对 / 像被砍了一半”的独立视觉问题，也不全局重解释 `origin_offset.y`。

# 实施步骤
1. 在 `CityC8Stages` 增加 solved child 入树与旧 placeholder 替换逻辑。
2. 在 `CityC8Stages` 增加 start runtime 高度归一化逻辑，并复用运行时 connector 真值计算 start y。
3. 在 `CityController.handleCityJigsawSolve(...)` 接入入树、保存与增强响应。
4. 补充/更新定向测试，覆盖 solved child 入树、placeholder 替换、start 高度归一化。
5. 同步文档仓契约与测试入口，并在当前 `dev_docs` 追加实现与验证记录。
6. 编译、定向测试、真机验证 `g_market_03` 当前样本链路。

# 验收标准
- `city_jigsaw_solve(apply_now=false)` 成功后，`validated_nodes` 中出现真实 `vjigsaw_*` child，旧 placeholder 被替换。
- `city_jigsaw_solve(apply_now=true)` 在继续正常落地的同时，不回退已写入的 C8 会话树。
- 当前 `g_market_03` 的 `start` 能从原先的 `y=65` 自动归一化为符合运行时 connector 真值的 `y=64`。
- `start` 现场视觉不再比 child 明显高出一格。
- 文档仓与 `dev_docs/current_20260409_011021` 已同步到本轮真值。

# 关键假设
- 当前运行时模板真值优先于 `template_output` 中的 `origin_offset.y`，但只在 start 这条 runtime 可观测链路启用。
- 旧 placeholder child 是临时会话节点；一旦同 parent 下出现真实 runtime child，应直接替换为真实链。
- 当前 `g_market_03` 仍作为本轮真机回归主样本。
