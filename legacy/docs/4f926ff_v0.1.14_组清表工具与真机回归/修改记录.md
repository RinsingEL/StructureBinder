## 2026-04-08 02:00:00

- 已完成 group 级清表工具的实现主链：
  - 新增 `GroupSurfaceClearService`
    - 复用当前执行层 `soft_clearable / protected / embedded_excavate` 语义
    - 以 `CityC8Stages.AreaGeometry.block_set` 的 polygon 真值逐列清理
    - 支持 `min_y / max_y / clear_solids`
    - 支持 `excluded_bounds`，用于默认保护已有 validated placement 的真实模板 bounds
  - 新增 `GroupSurfaceClearServiceTest`
    - 覆盖“只清 polygon 内列”
    - 覆盖“excluded bounds 与 protected block 不会被误清”
  - 在 `CityController` 新增 `/city_group_surface_clear`
    - 输入：
      - `city_id`
      - `group_id`
      - 可选 `build_area_id`
      - 可选 `min_y`
      - 可选 `max_y`
      - 可选 `clear_solids`
      - 可选 `preserve_existing_placements`
    - 输出：
      - 中文清理统计
      - area block / scanned column 计数
      - `terrain_preparation` 统计
      - group 级 artifact json 路径
  - 在 `ModHttpServer` 注册新路由 `/city_group_surface_clear`
- 为什么改：
  - 当前单节点 `apply_now` 虽然已能工作，但无法直接把某个 group 的测试地表整体清出来，联调观察成本高
  - 用户明确希望有一个“按 group 清地表”的独立工具，便于后续结构测试
