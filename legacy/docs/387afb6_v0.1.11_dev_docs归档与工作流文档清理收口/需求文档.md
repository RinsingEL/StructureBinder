# 剩余工作区清理提交需求

## 用户本次需求摘要

把当前工作区里剩余的修改一起整理并提交。

## 用户特别强调的约束

- 需要实际处理并提交，不只是列出状态。
- 要把剩余修改一起收口。
- 继续遵守仓库的中文提交和 `dev_docs` 规则。

## 不做的事情

- 不把明显属于运行时产物的 `logs/` 直接提交。
- 不擅自恢复或改写用户未要求保留的历史内容。
- 不在未核实范围的情况下把无关文件塞进提交。

## 当前决定的工作边界

- 聚焦 `dev_docs` 历史归档重命名与 `docs/workFlow` 删除整理。
- 本轮允许补充当前清理任务对应的 `dev_docs/current_...` 文档。
- 对未跟踪的运行产物只说明，不纳入提交。
