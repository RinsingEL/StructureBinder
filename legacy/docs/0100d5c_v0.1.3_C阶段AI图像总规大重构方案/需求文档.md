# C阶段 AI 图像总规大重构需求

## 用户本次需求摘要

用户希望重新审视 C 阶段城市生成主链：新的图像模型能力足够强，过去大量程序选簇、扩张、功能区与道路工具可能不再需要作为主线。用户倾向让 AI 直接画城市边界、功能区和道路，并希望形成一个新的重构案。

## 用户特别强调的约束

- 先讨论并形成方案，不急着直接改代码。
- C 阶段从开头开始都可以重新规划。
- 旧的城市落地选簇能力不一定删除，可以考虑保留为可选项。
- 需要判断“只画好网格线是否足够”以及 AI 图像输出如何变成可落地数据。

## 不做的事情

- 不删除现有 C1-C9 代码。
- 不修改 MCP 接口或运行态逻辑。
- 不启动游戏客户端做运行态测试。
- 不提交代码。

## 当前决定的工作边界

- 实现仓库只记录本轮过程文档。
- 文档仓库承载正式产品方案、数据契约草案和验收入口。
- 新案默认采用 AI-first 总规路线，程序工具降级为 guardrail、parser、validator、repair、fallback 和 executor。
