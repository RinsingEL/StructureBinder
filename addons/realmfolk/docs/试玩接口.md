# 本地真实客户端试玩接口

仅在启动脚本传入 `-TestBridge` 时启用，绑定 `127.0.0.1:5021`。每次启动随机生成访问令牌，保存在测试目录 `playtest-token.txt`。正常玩家启动不启用接口。

通过 `scripts/playtest-request.ps1 -Route <路由> -Body '<JSON>'` 调用；每次请求和返回摘要写入 `playtest-evidence/calls.jsonl`。控制请求走真实客户端输入、游戏操作或网络包，不能直接写社会状态。

| 路由 | 参数 | 用途 |
| --- | --- | --- |
| `/state` | `{}` | 当前画面、玩家位置和生命、附近实体、背包和容器槽位、对话内容。 |
| `/create` | `{"name":"Realmfolk_Playtest"}` | 在标题画面创建新的独立超平坦生存测试存档，启用管理员命令；已有同名存档会拒绝覆盖。 |
| `/command` | `{"command":"realmfolk demo"}` | 由当前玩家发送正常游戏命令，仍受游戏权限检查。 |
| `/screenshot` | `{}` | 保存真实游戏帧缓冲截图并返回文件位置。 |
| `/look` | `{"yaw":0,"pitch":0}` | 转动玩家视角。 |
| `/move` | `{"ticks":40}` | 按住前进，最多 200 tick。 |
| `/interact` | `{"entity":123}` | 右键交互范围内的实体。 |
| `/attack` | `{"entity":123}` | 普通近战攻击。 |
| `/select` | `{"slot":0}` | 选择 0–8 快捷栏槽位。 |
| `/use_item` | `{"ticks":1}` | 对当前主手物品执行原版使用动作，可按住 1–100 tick；必须先关闭界面。用于符文学习、食用等，不直接写任务或模组能力。 |
| `/use` | `{"x":0,"y":65,"z":0}` | 右键可触及的方块。 |
| `/break` | `{"x":0,"y":65,"z":0}` | 持续普通挖掘，最多 160 tick；受实际工具速度和游戏规则约束。 |
| `/slot` | `{"slot":0}` | 对当前菜单的指定槽位执行 Shift 点击。 |
| `/dialogue` | `{"action":"quest_accept"}` | 点击当前对话屏幕中实际存在且可用的选项；跨页时先翻到该页。 |
| `/close` | `{}` | 关闭当前容器或对话。 |

试玩时先确认观察目标，再执行游戏操作并查看正式返回、日志和截图。遇到产品故障时先记下现象并结束该轮游玩，再进入源码诊断，修复后重新开始验证。

补充控制：`/load {"name":"Realmfolk_Playtest"}` 从标题界面加载既有存档；`/leave {}` 正常退出并保存至标题；`/respawn {}` 在死亡后发送原版重生操作；`/quit {}` 正常关闭客户端；`/confirm {}` 仅接受原版确认界面的首个可用确认按钮（如已知存档的实验性设置确认）。

经济界面：`/state` 返回 `shop`（服务端报价、库存、余额、掷骰结果）；`/shop {"selling":false,"index":0,"count":16,"action":"buy"}` 选择界面物品并点击可用按钮。`selling:true, action:sell` 为出售；`action:gift` 为请求赠礼。接口不能绕过按钮可用状态，不直接改余额或库存。
