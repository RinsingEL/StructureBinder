# 第四题 · 魔法学院配置实验

离线实验；没有创建游戏内 NPC 或写入游戏存档。

## 实际结果

- 使用已接受 D4 的 51 栋建筑和冻结用途。
- AI 输入 5 个群体、1183 字符；展开 10 种职业、38 行功能安排、8253 字符的正式提交。
- 正式 Java 校验通过；假定住宅站立名额可用时，规划 40 人，住房 12 栋，名额 48。
- 生成 4 类物资委托，来源是已配置商品池；没有证明附近野外资源或即时库存。
- 未发出附近讨伐委托：缺少本学院的实际目标证据和正式任务计数接口。

## 需要继续开发的边界

- 离线使用正式校验与规划器，不代表游戏已生成 NPC。
- 人口演算站立点为显式试验假设，未进行游戏内可站立验证。
- 群体目前映射为职业与背景，亲属关系、共同住所、群体声望尚未写入运行时。
- 岗位按建筑用途匹配，不能保证落在 AI 指定的某个院落。
- 赠礼使用已有个人好感和 d100 规则；尚无派系专属关系门槛。
- 教学、施法及附近讨伐待接入；不会自动降级成交易来宣称已实现。
