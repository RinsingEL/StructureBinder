打开 http://127.0.0.1:8775/ 。选择星落或青枝的经历，以及魔法材料、工业制品、农产品中的起始身份。点击“走进学院”，按页面行动。换方案/身份后点击“开启新的体验”创建独立进度；刷新自动恢复上次会话。

流程：与发起人交谈 → 前往合作者的实际建筑交谈 → 回来选择一种材料贡献 → 前往绑定的学院场所记录 → 回报 → 自由选择一份奖励 → 使用新开放的服务、再次交谈。

两份 AI 方案绑定了不同居民、建筑、文化介绍和项目结果；三种供给方式都可推进，同一次只能使用一种。贡献和奖励选择独立，例如工业玩家交付安山合金后可以选择魔法材料奖励。作者的示例数值用于验证渠道，不是正式经济平衡。

## 作者与 AI 分工

| 文件 | 维护者与内容 |
| --- | --- |
| `author-catalog.json` | 作者：三种核心类型的判定、阶段规则、允许角色/用途、三种贡献途径、奖励包与预算、服务物品、实验起始背包。 |
| `ai-programs.json` | 本轮 AI：选择群体、用途、项目、贡献/奖励候选，填写当地目的和两段介绍。不编写执行脚本、不改基础价格。 |
| `lab.py` | 程序：校验上一轮证据与来源哈希，选择实际有岗居民、批准用途建筑，编译任务，处理独立实验状态。 |
| `results/compiled.json` | 编译结果：两份绑定共 1002 字符，展开 6 个任务实例，记录输入 hash。 |

现有三个类型是认识当地、专业委托、共同项目；首轮只验证一个三阶段流程的两种配置。添加新的行为判定仍需实现执行器。没有声明任意改 JSON 即可生成任意新玩法。

## 状态和限制

- 浏览器前往、交谈、整理记录、交付和购买均为模拟事件；不代表真实 NPC 寻路、施法、采集或工业制造。
- 场所来自冻结 D4 的保留建筑；人物来自上轮正式人口规划器结果，本次未在游戏中发现或生成实体。
- 每次交付扣实际实验背包，奖励按白名单和价值预算发放。没有物资不能交付，没有到场不能交互；同一任务无法靠重复请求刷奖励。
- 项目完成开放真实可操作的实验用品窗口，购买消耗余额和库存；人物后续回应根据完成状态变化。没有写入正式个人/派系声望。
- “资料开放”等叙述仅为实验项目背景；当前可操作的新功能是用品窗口，未实现独立的阅读/知识系统。
- 未生成附近地牢或讨伐任务；没有可用的本地证据与任务适配，不能凭结构池推断附近目标。
- 实验进度存在仓库旁 `.realmfolk-build/core-task-lab/sessions/`，与所有游戏存档分离。操作串行、原子保存，版本不符拒绝，已处理操作可重放但不重复结算。配置改变后旧会话保留，要求开始新实验。
- 服务只监听 127.0.0.1，写操作仅接受同源页面；没有 AI 付费调用和联网依赖。
