2026-10-14 起，当前源码位于 `StructureBinder/addons/realmfolk/`，跟随主仓推送，保留独立 Gradle 构建。原本地仓库和已有运行存档保留作迁移来源，未复制到这里；下文旧试玩记录描述原实例，需要先准备本目录的运行环境。来源与目录约定见 [附属模组入口](../README.md)。

## 直接试玩

**本次经济版本：双击 `试玩城市经济.bat`。** 使用独立目录 `.realmfolk-economy-playtest` 和存档 `Realmfolk_Economy`，从住房试玩世界复制而来，原世界不受影响。角色位于额外的双城示范区；右键附近铁匠艾琳 → 查看货物，可以卖矿产、农作物，再按 1/16/64/全部采购建材。普通居民也能请求赠礼。主 MCP 为 `http://127.0.0.1:5060/mcp`，独立居民设计 MCP 为 5062，后者 token 仍保存在该游戏目录的 runtime 文件里。

主模组新拆出的 Harness 和冒险地图都是可选包；本次接入只需主包，已经在未安装两个可选包的客户端验证。城市主流程会自动追加居民与商贸任务，具体规则见[经济与主流程契约](docs/城市经济与主流程契约.md)。

以下为保留的旧版试玩入口：

独立运行目录为本仓库相邻的 `.realmfolk-playtest`；已复制主模组配置与模板依赖。0.3.0 验证时的存档 `Realmfolk_Housing` 可双击 `试玩住宅人口.bat`：当次记录为崖京首府 10 处可入住住宅、40 个住房名额、85% 入住率，共 34 名 NPC，含原有 14 人；午间与傍晚可见公共活动。入门场景可双击 `开始试玩.bat`。另有 `Realmfolk_Abilities`：已通过 MCP 配置崖京巡旅者，保留旧居民，可用 `试玩城市能力.bat` 直接进入。现有入门存档：`Realmfolk_Start`（干净双城入门场景），`Realmfolk_Playtest`（保留测试痕迹），`Realmfolk_City_Test`（主模组 0921 城市存档的副本，可用 `试玩真实城市.bat` 启动）。

在本目录运行：

```powershell
.\scripts\launch-playtest.ps1 -World Realmfolk_Start
```

启动器脚本使用本机已安装的 Forge、Java 和游戏素材，测试角色为本地离线身份。日常玩家可把两个 JAR 放进自己的 Forge 1.20.1 实例；若使用主模组现有城市存档，也要保留原实例需要的地形与结构依赖。

新建测试世界后输入 `/realmfolk demo`，在当前位置上方生成独立的双城试验场景及初始物资。每个存档只生成一次；此命令会建造方块，适合测试存档。右键居民开始交谈，`/realmfolk journal` 查看委托、伙伴、产权与纠纷。

推荐体验顺序：与铁匠交谈并完成委托 → 邀请同伴 → 查看/取走/归还商店存货 → 与领事购买房屋或领取讨伐委托 → 向商人打听消息并一起旅行。荒野魔首会主动攻击，带上装备和伙伴再接近营地。

城市设计模式可用 `启动城市设计.bat`，进入世界后通过 MCP 动态发布规则；连接方法见下方文档。

## 当前实现

- 城市功能填写表：以 D4 实际编译建筑和批准用途生成分页题单，AI 分批保存住房/职业安排；提交检查功能覆盖和显式委托配置，预览全城人口与商品、委托差异后携带审查凭证发布。支持按住房用途覆盖人数；详见经济与主流程契约。

- 作者维护物品池与基价，AI 多选城市/职业物品池和权重，程序按规则生成库存；没有风格到 Mod 的固定映射。
- 统一通币账户、多格商品与批量收购/购买；赠礼按好感和档位掷一次真实 d100，购买与赠礼共用库存。
- 城市编译完成后自动进入主规划扩展，预览、持久化发布再继续下一城；不用加载全城才能设计居民。
- 稳定居民身份、房屋归属、职业外观、白天工作与晚间回家。
- 对话、物资委托、好感与国度声望、最多三名同伴、跟随/等待/暂别和近战协助。
- 财产提示、目击判断、取物/破坏/擅闯/伤害纠纷、归还与赔偿、警卫查问和严重行为追捕；不会取消玩家拆方块。
- 购买空房、示范讨伐住宅奖励、传闻位置、商人步行护送。
- 职业由 14 项已实现能力组合，国度规则、城市模板和职业权重批量生成居民；关键人物可单独创作。
- 住房和工作分别分配，按住宅容量 × 入住率补员；公共活动让居民在午间、傍晚走出家门；姓名、个性标签和属性按稳定身份抽取。
- 设计 MCP 提供能力查询、城市摘要、草案校验、预览与发布；旧居民默认保留，可显式刷新未建立关系者。
- 从 Geomantia 的正式落地建筑及批准用途接入居民；旧版其他生物映射继续兼容。
- 重进存档保留社会状态；正常启动不开启本地测试接口。

## 当前边界

默认经济池只包含原版物品。其他 Mod 的真实物品 ID、概率和基价由整合包作者加入 `config/realmfolk/economy.json`；当前不支持带自定义 NBT 的商品定义。默认价格、补货和赠礼额度均可配置，仍需按整合包节奏调整。

这是玩法原型。居民使用原版村民外观；委托和对话以规则及配置文本为主；日常行为包括工作、回家及配置时段的公共场所闲逛与小聚，不含完整生产经济、睡眠动画、家庭与关系剧情。示范魔首是命名的原版敌人，尚非完整魔王主线。

自然城市只在已有落地证据、明确用途和可站立位置时安排人口；未知用途会跳过。新安装默认按可用住房名额的 85% 补员（向下取整），实现上限 256 人；旧世界须通过 MCP 切换住房模式，每第 5 处住宅预留空房，购房需要该城已有领事。自动导入尚不自动铺道路、建营地或生成主线任务。商人使用原版寻路，远途无人加载、地形阻断、跨海和跨维度尚无完整交通保障；目前适合近距离路线试玩。

## 构建与准备

先在 StructureBinder 根目录执行 `gradlew.bat jar`。进入 `addons/realmfolk/`，执行 `scripts/sync-geomantia.ps1` 同步主包（脚本默认定位两层上方主仓，依赖 Planning API v1）。再使用 Java 17：

```powershell
$env:JAVA_HOME='C:\Program Files\Java\jdk-17'
$env:PATH=$env:JAVA_HOME+'\bin;'+$env:PATH
.\gradlew.bat build
.\scripts\prepare-playtest.ps1
```

产物位于 `StructureBinder/addons/.realmfolk-build/libs/realmfolk-0.4.0.jar`。附属模组与主模组使用独立构建输出；本机依赖 JAR 保存在已忽略的 `libs/`。准备脚本只复制依赖与测试配置，不复制 API 凭据；测试配置关闭外部 AI 调用，原项目配置不受影响。
