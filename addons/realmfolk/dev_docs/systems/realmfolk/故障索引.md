# Realmfolk 故障索引

## RF-014：Git 迁移后的实验输入被误判过期

*现象*：从已提交源码导入新目录后，旧流程实验报告 economy.json 等输入哈希过期。

*首次偏离*：Windows 输出 CRLF 的 JSON 被 Git 的 eol=lf 规范化，保存的原始字节 SHA256 未同步。

*根因*：文件内容语义不变，但实验依赖原始字节哈希；Python 默认平台换行与 Git 文件约定不一致。

*修复*：JSON 写入显式使用 LF；用新目录实际 Java 测试生成的校验结果重建报告，再导出布局和旧流程配置。保留原 D4 蓝图哈希与历史来源，不关闭过期检查。

*验证*：新目录 Java 全量 101 项与打包通过；报告重建后复验旧流程与布局导出，结果见本次迁移任务记录。

*记录*：主仓 `dev_docs/workflows/版本提交/active/20261014_第四题实验与待推送资料归档/任务记录.md`。

## RF-013：新版离线页面的 JavaScript 模块被浏览器拒绝

*现象*：实验 03 页面停在载入状态，浏览器提示模块 MIME 为 text/plain。

*首次偏离*：Python 通用静态服务响应 `.mjs` 请求时。

*根因*：本机 MIME 推断返回 text/plain，模块脚本要求 JavaScript 类型；HTTP 响应与浏览器控制台已核对。

*修复*：本目录静态服务 `serve.py` 显式指定 `.mjs` 为 text/javascript；仍仅监听 127.0.0.1，无系统 MIME 设置修改。

*验证*：修复后浏览器完成两组学院的 6 条委托路径、4 项已有知识/缺模组边界和移动端检查，共 11 项，页面异常 0；桌面与移动端截图已查看。

*记录*：[模组专属任务目标实验](archive/d4848a9_v0.4.0_模组专属任务目标实验/任务记录.md)，未提交。

*修复*：撤下失效启动命令，保留配置与结果；未恢复脚本、添加排除项或重启服务。

*验证*：源码 PopulationPlanner、GeomantiaBridge、Economy.ensure 与实际 society_utf8、economy.json 交叉核对。用户已确认看见实体；本轮未修改存档、配置或运行游戏。
*记录*：[城市功能配置必答表](archive/be7a6be_v0.4.0_城市功能配置必答表/任务记录.md)，93 项测试及打包通过，现场题单待验；实现提交 `be7a6be`。

## RF-006：城市规则使社会存档超过单个 NBT 文本上限

*现象*：第 1 轮退出世界日志出现 Failed to write NBT String / UTFDataFormatException，社会 JSON 为 71156 字节，保存失败。

*首次偏离*：SocietyData 将完整社会状态写入单个 StringTag。

*根因*：Java/NBT UTF 字符串约 64 KiB 上限；职业快照和规则使旧存储方式很快超过上限。

*修复*：改为 UTF-8 ByteArrayTag，版本 2；读取时兼容旧 society 字符串。仅独立测试副本受此次失败影响。

*验证*：大于 64 KiB 的压缩 NBT 往返及旧格式迁移测试通过；真实重新入场保留 14 人、职业快照、草案、回执和关系。原失败日志保存在 playtest-evidence/v020-round1-latest.log。

*记录*：[本次任务](archive/c299f12_v0.2.0_能力职业与城市人口方案/任务记录.md)。

## RF-007：公共活动寻路失败时缺少退出条件

*现象*：v0.3.0 开发审查发现，公共活动分支对未抵达人物始终继续导航；目标虽可站立但路途被阻断时，整段活动时间内不会恢复原作息。这是实现审查发现，不冒充真实城市已复现故障。

*首次偏离*：公共活动分支缺少行进进展与失败退出判断。

*根因*：目的地安全检查不等于路径可达；只检测站立点、未限制失败行程。

*修复*：20 秒未接近目标或单次行程超过 90 秒后，本次活动恢复普通作息；下次活动重新尝试。抵达后正常停留，不受行程超时影响，不传送补位。

*验证*：卡住、重新参加、持续前进、抵达停留与无限绕路的规则测试；真实城市复测见本次任务记录。

*记录*：[本次任务](archive/c810452_v0.3.0_住宅人口与公共生活/任务记录.md)。
