# 城市规划接入与物品池经济

*需求入口*：用户要求核对主模组 791e5b71 重构并一起开发；需求案 05 城市物品池与多商品交易、01 NPC 居民生活与冒险同伴；主模组附属规划流程 Java 接口 v1。

*修改内容*：适配主包与可选 Harness/地图拆分，注册 realmfolk:city_society。城市局部职业命名隔离，未加载城市可先发布，发布前原子持久化。作者 JSON 维护池、兴趣说明、基价与价格档位，AI 多选池和权重。新增 trade/buyback/gift 组合、实际库存、统一账户、多格批量买卖、一次真实 d100 赠礼、请求间隔与共享额度；委托、购地、罚款、护送奖励共用账户。旧居民身份、住房、关系保留，兼容裸城市 ID 及关键人物方案。新增配置契约、依赖同步脚本、独立试玩入口。

*验证结果*：83 项 JVM 测试全部通过（0 失败、0 跳过），包括真实主包的扩展注册/Schema 兼容、城市发布幂等与隔离、概率分层、买卖扣账、防同店套利、赠礼与 NBT/JSON 持久化；jar/reobfJar 成功。真实 Forge 客户端仅安装主包和 Realmfolk，未安装可选 Harness/地图：主 MCP 自动追加扩展，雪见岭未加载也能预览发布，随后进入崖京；崖京发布 created=0、refreshed=0，保留关键人物岚川、51 名原居民及住房。源存档实际为 51 名 NPC，全部类型 realmfolk:citizen；早期 commentary 沿用旧 34 人记录的分类已更正。另在独立测试副本用正式 demo 命令创建 9 人场景。

交易验证：32 粗铁出售 +320，32 泥土采购 -64，64 小麦出售 +128，委托奖励 +64，余额 448；修复后按 /shop action=sell 出售 1 泥土 +1，最终 449。实际赠礼两次 d100 分别 43/30、95/34，均婉拒、不扣好感；成功转移分支由规则测试验证，没有控制真实骰子结果。退出再进余额、库存版本和物品数量一致，请求冷却保留；已发布雪见岭任务不重跑。实际请求、参数修正、返回、XML、截图索引和哈希见验证产物。未调用付费模型，没有宣称已验证模型自动写出合适规则。

*剩余问题*：本次实现范围无未完成项。当前示例池为原版物品，其他 Mod 由作者填写真实物品 ID；自定义 NBT 商品不在首期配置中。默认经济数值仍需整合包试玩调整；没有真实多人客户端或大规模 NPC 性能压测。未清理案子，原试玩存档未修改。成品 releases/0.4.0；新入口使用 .realmfolk-economy-playtest/Realmfolk_Economy。
