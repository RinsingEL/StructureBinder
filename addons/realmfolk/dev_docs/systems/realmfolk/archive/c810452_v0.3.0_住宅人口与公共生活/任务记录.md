# 住宅人口与公共生活

*需求入口*：需求案/01_NPC居民生活与冒险同伴.md；用户认为城市不够热闹，确认“跟着住宅走是对的”，同意修改后体验。

*修改内容*：housing 模式根据可用住宅容量与入住率补员，默认 85%，保留 fixed 兼容；住房/职位缺口及目标通过 MCP 摘要呈现；public_life 能力和城市活动配置控制午间闲逛、傍晚小聚；区别住所、岗位和公共站位，分散到场，保护同伴、关键关系、交谈、战斗、执勤、旅行与休息。仅已加载居民步行参加；跨零点活动不重新洗牌；冻结昼夜时运行缓存仍会刷新。发现寻路失败缺少退出条件并修复，见 RF-007。

*验证结果*：Java 17 执行 gradlew.bat build 成功，55 项测试全部通过。两轮真实打包 Forge 客户端验证，第一轮 MCP 一次发布 20 人，14→34；40 个住房名额 × 85% = 34；重复发布不重复生成；低密度预览保留已有居民；午间 12 人实际到场，非活动时段恢复工作，傍晚选择 8 人，夜间 33 人回家、1 人同行。重进存档保持设计版本 4 和同一组 34 个 UUID。最终带寻路兜底的 JAR 再启动，12 人到场，交谈 5 秒保持原地，关闭后恢复活动，退出保存完成。

*调用及修正*：请求/返回在验证产物/mcp-v030.jsonl；首轮观察者管理员传送误入墙体，重生并实际拾回原物品；远距交互返回 Entity out of reach 后靠近重试；低层观察点视线失效后改为同层位置复验。没有通过传送居民替代公共活动移动。完整日志位于本地 playtest-evidence/v030-round1-latest.log、v030-round2-latest.log，客户端调用在 calls.jsonl。UUID 集合与测试统计记录在验证产物/验证汇总.json。

*交付*：releases/0.3.0 含附属 JAR、已实测依赖及 SHA256SUMS；本机试玩运行目录更新到 0.3.0，旧 JAR 备份在 mod-backups/v030-before。新建独立存档 Realmfolk_Housing，入口 试玩住宅人口.bat；旧存档保留。需求案、契约、MCP 示例与试玩说明同步更新。
