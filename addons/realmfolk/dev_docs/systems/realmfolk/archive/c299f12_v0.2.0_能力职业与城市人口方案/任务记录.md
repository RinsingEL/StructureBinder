# 能力职业与城市人口方案

*需求入口*：[NPC 居民生活与冒险同伴](../../../../../需求案/01_NPC居民生活与冒险同伴.md)；用户要求职业按能力组合，AI 通过 MCP 配置城市规则，普通 NPC 不逐人设计，并明确本轮案子和代码一起改。不清理其他案子。

*修改内容*：11 项已实现能力的职业组合；默认七种职业；国度文化及法律、城市模板/覆盖项、住房与工作分配、稳定权重随机器和少量关键人物；8 个本地认证 MCP 工具与 stdio 适配器；草案/预览/发布版本及状态校验、重复发布回执、现有人物快照和关系保护。旧存档迁移为 UTF-8 NBT 字节数组，解决约 64 KiB 文本限制；交谈心跳暂停日常导航。同步需求案、配置契约、MCP 说明、可复用示例及试玩入口，版本升至 0.2.0。

*验证结果*：Java 17 / Forge 1.20.1 构建及 36 项测试通过。真实独立崖京城市保留 10 人新增 4 人（1 关键、3 普通），住房与工作地点分离，自定义属性、商品、委托和招募均在游戏生效。过期预览拒绝，显式刷新保护关键人物和已接委托人物，其他 12 人刷新；重复发布无重复生成。正常保存重进保留 14 人、版本 3、关系、任务、草案指纹与旧发布回执。第 1 轮发现的交谈走远和存档超长问题已登记 RF-005 / RF-006，第 2 轮修复复验通过。初始单测的“工坊”与正式用途词“工坊生产”不匹配已修正测试输入；第 2 轮启动时尚未登记建筑，通过正式 import 后继续。

完整 MCP 实际请求/返回：[MCP验证.jsonl](MCP验证.jsonl)。客户端操作记录和两轮原始日志在本地 `playtest-evidence`，展示截图与覆盖说明见 `docs/试玩验证.md`。成品在 `releases/0.2.0`，SHA256SUMS.txt 校验；最终 JAR 解包内容与真实验证 JAR 相同。复制已验证存档为独立 Realmfolk_Abilities，一键入口“试玩城市能力.bat”。主模组源码未修改，交付沿用实际验证的依赖 JAR；旧测试 JAR 已备份。

*剩余问题*：本轮要求无未完成项。个性暂为标签，原版外观与近战/寻路仍为原型能力；家庭、生产经济和完整剧情尚未实现。MCP 接入示例已提供，未修改用户全局客户端配置。
