# 测试端模组与经济池配置

*需求入口*：用户要求将农夫乐事、机械动力、新生魔艺与 JEI 安装到 PCL Forge 1.20.1 测试端，并配置城市商品池。

*修改内容*：新增四个内容/工具模组及 Curios、Patchouli、GeckoLib 三个配套库，逐个核验官方 SHA-512。备份原经济配置；保留原四个综合池并新增七个功能池，共 93 个商品。风格不限制选池，沿用原版基价、通币、补货与请求冷却。配置与版本清单保存于 examples/modpacks/pcl-industries，副本说明放在测试端 config/realmfolk/商品池说明.md。未修改主模组、附属模组默认配置或 PCL 存档。

*验证结果*：独立副本加载同一套 12 个活动 JAR 与相同经济 JSON，通过实际服务器启动时的全部商品注册检查。真实商店售出测试准备的 64 个番茄获得 128 通币，再买入 4 个安山合金和 1 个魔源宝石，余额 60 且背包/库存正确。请求赠送番茄真实骰子 54 > 30，失败不扣好感并进入冷却；正常退出保存。详见验证摘要、试玩调用记录与跨模组商品交易截图。

首轮停在既有 ReTerraForged 缺失资源包信息的 Forge 警告画面；关闭客户端后，仅将验证副本的 showLoadWarnings 关闭再启动。测试端原 JAR 与 Forge 配置保持原值。重启时的一次 403 在新服务完成启动、读取新令牌后消失；以 NPC 显示名称选择目标未移动到商人，改用 /state 的实测坐标传送后完成交互。调用工具的原始完整记录位于仓库 playtest-evidence/calls.jsonl，本任务归档了当日 33 次调用且移除商店临时令牌。
