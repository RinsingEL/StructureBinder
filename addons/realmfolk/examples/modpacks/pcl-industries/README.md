## 商品池

共 93 个物品定义：原版 30 个、新增模组物品 63 个；11 个池。每件商品只定义一次价格，多个池可以引用同一个物品。

| 池 ID | 内容 | 功能参考 |
| --- | --- | --- |
| `building` | 原版建材、厨具和农家用品 | 建造、零售、器皿销售 |
| `farming` | 原版作物、农夫乐事作物与餐食 | 农田种植、棚架种植、餐饮 |
| `mining` | 原版矿物、Create 零件及设备 | 工具维修、修补维护、研究配套作业 |
| `adventure` | 原版冒险补给、Ars 材料及研究用品 | 冒险、实验、魔力配给场所 |
| `fd_produce` | 作物、种苗、土壤用品 | 农田种植、种子销售、果蔬销售 |
| `fd_meals` | 原料和成品料理 | 餐饮、烘焙、商队补给 |
| `fd_kitchen` | 厨具、绳索、帆布、橱柜 | 器皿销售、零售、工具维护 |
| `create_components` | 合金、金属板、传动件、精密构件 | 工具维护、修补维护、研究配套作业 |
| `create_machines` | 水车、动力与生产设备 | 工坊零售、农业自动化、研究配套作业 |
| `ars_materials` | 魔源宝石、魔法栽培产物、精华与荒野素材 | 晶石加工、药材配制、棚架种植 |
| `ars_workshop` | 空白耗材、建材、未充能研究设备 | 魔力配给场所、实验、纸墨配制 |

四个原池 ID 保留，因此已有城市沿用原池时也能抽到新商品。七个专门池供后续 AI 按城市产业和玩家兴趣选用；不按沙漠、精灵或魔法学院等风格设置门槛。综合池和专门池重叠时可提高某产业占比，程序仍将重复物品合并为一个货架条目。

番茄、安山合金、魔源宝石分别作为对应池的常备基础品。高阶设备库存少、抽取权重低，且不作为赠礼；普通材料、餐食和部分稀有素材可请求赠送。沿用统一通币、原版物品基价、20 分钟补货、10 分钟请求冷却与原预算。当前价格是试玩起点，尚未完成长期生产效率和跨城贸易平衡测试。

只配置普通物品和未使用设备，不生成预写法术书、充能容器或已绑定卷轴。建筑功能标记用于选择商品池，不会自动安装或运行建筑内的机器。

## 给城市设计 AI 的使用说明

读取 `realmfolk_planning_context` 或 `realmfolk_economy_catalogue` 中的池名、`interests` 和 `function`。按城市的生产、需求和贸易设定混选池，并通过池权重、档位权重和作者提供的价格档位调整特色；具体 NPC 库存仍由程序生成。

例如，一个兼有农业、维修和魔法研究产业的城镇可以使用：

```json
{
  "pools": {
    "building": 1,
    "fd_produce": 2,
    "fd_meals": 1,
    "create_components": 1,
    "ars_materials": 0.6
  },
  "tiers": {"basic": 1, "rare": 0.5, "epic": 0.15},
  "priceBand": "standard"
}
```

这只是城市方案中的 `economy` 字段示例，不是自动生效的独立配置。专门商人可用职业模板的 `itemPools` 筛选城市已选池；不要逐人配置库存。城市规模可以影响权重，但不排除小型专业城镇拥有高级设备。

## 生效、备份与验证

从 PCL 正常启动这个 Forge 版本即可。经济目录在服务器启动时读取。已有商人的库存快照会保留到下次补货，通常需要累计约 20 分钟游戏时间；新生成库存使用新目录。重新打开商店不会强制补货，不需要为了商品池另开存档。

修改前的经济配置位于测试端 `realmfolk-setup-backups/20260925_modpack/economy.before.json`，下载清单和配置后快照也保存在此目录。回退时先关闭游戏，恢复原经济 JSON，再移走该清单列出的七个新增 JAR；原有文件不在移除范围内。已经保存过新增模组方块或物品的世界，应配合世界备份回退。

使用独立目录 `E:\Mod\_Dev\.realmfolk-modpack-validation-20260925`，复制测试端全部 12 个活动 JAR 与同一份经济配置，创建独立超平坦验证世界；未打开或修改 PCL 原存档。
