# 教学区原尺寸试摆 · R8

用户认为组团素材可能偏大，先在实际 D3 地形与 Java 地表/道路/核心台地系统上试教学区。当前试摆为礼堂 + 两栋直翼 + 三层研究书楼 + 两间小课堂 + 两块阅读小庭，共 6 栋建筑、2 个地块；两侧翼楼及小课堂面向中间通路，研究书楼面向礼堂。

[打开教学区](http://127.0.0.1:8767/?district=teaching)。方案文件：[academy-teaching-trial.json](academy-teaching-trial.json)。网页“编辑完整方案”可导入该文件并生成，当前版本可导出。原始示范方案仍为此前 R7 配方。

本轮按真实宽深手工设置各叶阵列的位置与旋转，判断素材尺度；教学区暂不使用原来统一最大边长的父组团排布。生活区原有嵌套保持，生活与农林的成员素材、位置、旋转和高程逐项与 R7 一致。教学区全部配套仍绑定唯一礼堂核心的台地高程，不额外建核心。

“上部楼体投影”按真实预览方块 local Y≥4 的水平投影计算，排除两块完整景观地块，包含屋顶、出檐等；不代表可用楼层面积。包围盒以闭合模板占地计算，不包含外围道路及台地扩边。

实际看过前、后、西侧及俯视效果。直翼的 47×29 占地适合放在礼堂两侧；两层主楼体低于礼堂，尖塔作为次级轮廓。31×31 的三层研究书楼较醒目，继续观察是否需要降为两层。57×49 的 U 形庭院已经接近独立次级核心，本轮不将其作为普通小配楼。没有缩放模型或改动原素材 NBT。

试摆仍留有规整硬质场地，连廊自动拼装、旧文化核心的连接端口、小中型程序绿化素材及自动围合算法尚待后续。此版本用于判断体量与布局，不认为已经达到用户参考图的美术目标。
