# C1 ImageIntent 重构任务记录

## 目标与边界

- 本轮只实现 C1 ImageIntent 第一阶段：MCP 生成底图、图片 API 或离线导入意图图、CV 解析、输出 `UrbanIntentMap.json` 与预览/报告。
- 不替换旧 `city_c1_generate`，不推进 C2-C9 消费新契约。
- 文档真值同步到 `designer_territoryMod`，实现仓仅保留过程记录。

## 当前计划

- 新增 `world.city.stage.c1.intent` 独立包，隔离新 C1 代码规范与契约。
- 新增 MC HTTP endpoint 与 MCP tool：prepare / generate / import / data。
- MCP 侧实现可配置 OpenAI 图片 API；无 key 时返回离线导入提示。
- 增加 Java 单测覆盖解析、坐标、契约禁用旧字段。
- 2026-05-12 追加 GeometryIntent 主链：保留旧 ImageIntent/CV 兼容路线，新增 terrain clean/locator、GPT 几何 JSON、程序 overlay、领域 patch 与自动闭环 MCP。

## 关键决策

- `UrbanIntentMap.json` 不写旧 C1 字段或 legacy/hint 变体。
- API 生成和手工导入共用同一个 Java import/parse 终点。
- 解析失败不覆盖上一份有效 `UrbanIntentMap.json`。
- GeometryIntent 主链不再把 image2 原图像素当最终真值；image2 只产出 `image2_concept.png`，最终 C1 契约来自几何 JSON 和程序重渲染校验。
- GeometryIntent 默认 `radius_blocks=1024`，坐标以 `terrain_locator.json` 为准，避免 T4 首都地形图窗口和旧 C1 capital 4096 范围错位。
- 审图修正采用领域 patch：`replace_city_boundary / upsert_district / remove_district / upsert_road_path / remove_road_path / upsert_anchor / remove_anchor`。

## 重要修改

- 新增 `world.city.stage.c1.intent` 包：模型、IO、底图渲染、mask 解析、基础校验、overlay 导出和服务层。
- 新增 MC HTTP 入口：`/city_c1_image_intent_prepare`、`/city_c1_image_intent_import`、`/city_c1_image_intent_data`。
- 新增 MCP 工具：`city_c1_image_intent_prepare`、`city_c1_image_intent_generate`、`city_c1_image_intent_import`、`city_c1_image_intent_data`。
- MCP 侧新增图片 API 调用能力；无 `OPENAI_API_KEY` 时返回离线导入提示。
- 补充 MCP-only 图片 API smoke test：`city_c1_image_intent_api_smoke_test`，用于不启动 MC 时单独验证 OpenAI 图片 API 是否能实际出图，并结构化返回网络、key 或额度类错误。
- MCP 图片客户端支持 `OPENAI_BASE_URL` / `OPENAI_IMAGE_BASE_URL` / 参数 `base_url`，可把 `.../chat/completions` 中转站地址规整为同域 `.../images/generations` 与 `.../images/edits`。
- 支持中转站 JSON 图生图模式：`api_mode=generation_image_array` 时不走 `/images/edits`，统一 POST `/images/generations`，并把底图或参考图放入 `image: []`。

- 文档仓同步更新 C 重构代码导览、测试入口和 `UrbanIntentMap` 当前实现状态。
- 2026-05-12 新增 GeometryIntent Java 主链：`CityC1GeometryTerrainRenderer` 导出 `terrain_clean.png`、`terrain_locator.png`、`terrain_locator.json`；`CityC1GeometryIntentService` 提供 prepare/import/patch/data，写 `C1_geometry_design.json`、`C1_geometry_overlay.png`、`C1_geometry_report.json` 和 `UrbanIntentMap.json`。
- 2026-05-12 新增 MC HTTP 与 dev command 入口：`/city_c1_geometry_prepare`、`/city_c1_geometry_import`、`/city_c1_geometry_patch`、`/city_c1_geometry_data`。
- 2026-05-12 新增 MCP 工具与自动闭环：`city_c1_geometry_prepare/generate/import/patch/data`；`generate` 串起 prepare、图片 concept、chat geometry、import overlay、chat review patch 和 data。
- 2026-05-12 `UrbanIntentMap` 模型补充 geometry source refs、locator/grid 信息和 `geometry_report`；几何主链落盘时 `color_mapping/cv_report` 置空，旧兼容路线保持原行为。
- 2026-05-12 补强 GeometryIntent 导入兼容：正式契约仍要求 `coordinate_space` 为 `"pixel"`/`"world"`、点为对象字段，但导入层会归一化模型常见漂移形状，包括 `coordinate_space` 对象、`[x,z]` 点数组、district `id/role`、road `id/type/points`、anchor `id/point/coordinate`，并在 `geometry_layers.normalization_notes` 记录归一化痕迹。
- 2026-05-12 修复 MCP `city_c1_geometry_prepare/generate` 参数漏传：`radius_blocks` 现在会从 MCP 参数传给 MC HTTP，不再只停留在 tool schema。
