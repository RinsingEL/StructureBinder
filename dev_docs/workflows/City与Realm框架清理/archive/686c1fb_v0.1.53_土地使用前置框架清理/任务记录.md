# LandUse 前置框架清理任务记录

## 目标与边界

- 恢复当前 JVM 自动测试基线，修正 RoadWeaver 入口契约变化后过期的测试夹具。
- 修复本地 HTTP 服务线程池未随服务器停止回收的问题。
- 将 Realm run 状态收回到单个 Minecraft server 生命周期，并消除 HTTP 多线程并发访问可变 run 的风险。
- 在不改变 City workflow schema、artifact 和阶段行为的前提下，从 HTTP 适配层抽出可复用的 application 职责，为后续 LandUseAreaPlan 接入建立边界。
- 同步文档仓库的 City / Realm 代码导览与测试入口；不修改或提交用户正在编写的 LandUse 产品方案文件。

## 当前计划

## 重要修改

- RoadWeaver 测试夹具补合法 `templatePlacementPlan.transformed.roadEntrances[]`，不再依赖 bbox 伪造入口。
- `GeomantiaHttpServer` 持有并关闭专用 executor，覆盖正常关服和启动失败。
- `RealmPlanningService` 的 run map 改为实例状态；`RealmPlanningServices` 按 Minecraft server 复用并在关服释放；HTTP / Forge 共享该实例，所有可变 W/T HTTP 操作回到 server thread。
- City workflow 抽出 `CityWorkflowStepRunner` 和 `CityWorkflowCandidateSelector`，handler 删除原步骤执行和候选选择实现；新 application 类不依赖 `platform.http`。
- 文档仓库同步 City / Realm 代码导览和测试入口；未修改用户正在编写的 LandUse 产品方案。

## 未解决风险

- 本轮未清理 bounded-jigsaw 历史子图，也未执行全量 JSON DTO 迁移。
- Gradle 仍报告既有的 Gradle 9.0 弃用兼容警告，本轮未处理。
