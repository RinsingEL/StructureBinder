# Mixin Refmap 打包修复

*需求入口*：用户在外部 Forge 运行环境启动测试包时，Geomantia 的 `ChunkGeneratorStructureMaskMixin` 因 `No refMap loaded` 启动失败，并要求重新打包。

*修改内容*：恢复 MixinGradle 插件、Mixin annotation processor 与 `geomantia.refmap.json` 生成配置，并在 Mixin 配置中声明 refmap。曾尝试以无参构造器兼容 Forge 47.2.18；用户决定改用项目基准 Forge 47.4.0 后，恢复 `FMLJavaModLoadingContext` 构造器注入方式。

*验证结果*：refmap 修复后的完整构建成功；恢复 47.4 构造器后首次全量测试有一个 8 秒性能断言因耗时 9.87 秒瞬时失败，目标测试单独复跑通过，随后再次执行完整 `gradlew build` 通过（689 项测试）；最终 JAR 已确认包含 refmap，且 `GeomantiaMod` 的公开构造器参数为 `FMLJavaModLoadingContext`；`git diff --check` 通过。

*剩余问题*：待用户在 Forge 47.4.0 实际客户端确认启动。
