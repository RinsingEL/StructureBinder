# 测试运行包故障索引

## 正式 JAR 缺少 Mixin refmap

*现象*：外部 Forge 客户端加载 Geomantia 时，`ChunkGeneratorStructureMaskMixin` 报 `InvalidInjectionException`，日志包含 `No refMap loaded` 与无法匹配 `tryGenerateStructure`。

*首次偏离*：构建产物未生成或装入 `geomantia.refmap.json`，正式混淆环境无法解析开发映射方法名。

*根因*：构建脚本清理后缺失 MixinGradle、annotation processor 与 refmap 配置，而 Mixin 源码仍继续使用。

*修复*：恢复 Mixin refmap 的生成、声明与装包配置。

*验证*：`gradlew clean build` 成功；成品 JAR 已包含声明正确的 `geomantia.refmap.json`，目标方法均存在正式运行时映射；待外部客户端启动确认。

*记录*：[任务记录](active/20260903_MixinRefmap打包修复/任务记录.md)，提交待定。

## Forge 47.2 无法实例化 Mod 主类

*现象*：修复 refmap 后，Forge 47.2.18 在 CONSTRUCT 阶段报 `NoSuchMethodException: GeomantiaMod.<init>()`。

*首次偏离*：Forge 47.2.18 按无参构造器实例化 Mod，但成品类只有接受 `FMLJavaModLoadingContext` 的构造器。

*根因*：项目使用 Forge 47.4.0 编译并采用新版构造器注入写法，同时 `mods.toml` 声明兼容 `[47,)`，实际代码未兑现 47.2 兼容性。

*修复*：曾尝试恢复无参构造器；用户随后决定将运行环境升级到项目编译基准 Forge 47.4.0，因此该兼容改动撤回，继续采用 47.4 的构造器注入方式。

*验证*：47.2.18 的失败原因已确认；后续不再以该版本作为运行目标，待 47.4.0 外部客户端启动确认。

*记录*：[任务记录](active/20260903_MixinRefmap打包修复/任务记录.md)，提交待定。
