*需求入口*：用户反馈清理完成后新会话仍输出 `DUE state_invalid`。

*修改内容*：检查及标记到期脚本明确按 UTF-8 读取状态 JSON。此前 PowerShell 7 写入无 BOM UTF-8 中文范围，Windows PowerShell 5.1 默认解码产生乱码并吞掉字符串末尾引号，导致 JSON 解析失败；标记脚本也可能因此丢失既有状态。

*剩余问题*：无；未重跑清理或重置完成时间。
