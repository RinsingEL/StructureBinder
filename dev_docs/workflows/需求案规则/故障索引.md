# 需求案规则故障索引

## 清理完成后误报 state_invalid

*现象*：新会话检查输出 `DUE state_invalid`，状态实际为 CLEAN 且未到期。

*首次偏离*：Windows PowerShell 默认编码读取含中文的无 BOM UTF-8 状态 JSON。

*根因*：两个状态脚本未指定读取编码，错误解码导致 JSON 字符串不完整。

*修复*：检查与标记脚本均指定 `-Encoding UTF8`。

*验证*：真实启动命令返回 OK；Windows PowerShell 下中文状态读写保留、到期识别、损坏 JSON 检查通过。

*记录*：[任务记录](archive/26d05dfe_v0.1.0_修复清理状态编码/任务记录.md)，提交：26d05dfe。
