# RoadWeaver升级与三次外扩验收

## 目标

- 升级开发依赖到 RoadWeaver Forge `2.3.0-1.20.1`，验证反射 API 兼容。
- 开启 RoadWeaver 道路，关闭其 cabin 与 roadside 自动结构。
- 在未生成区域走 W -> T4 -> City D2-D7，并连续选择三次 D4 v0.5 outward 阵列。

## 验收口径

- D5 使用 `roadProvider=roadweaver`，注册 endpoint 与 connection，D7 不落 WorldEdit 调试道路。
- 三次 outward 均不传 `targetPatchRef`；候选从前一轮已选结构或阵列的 D2 body 前沿开始。
- 实机区块首次生成后检查结构 ledger、RoadWeaver registration report 和道路周边是否出现被关闭的 RoadWeaver 自动结构。

## 过程

- 2026-07-13：RoadWeaver 版本与运行配置已更新，等待标准客户端重启和真实流程执行。
- 2026-07-14：首轮 v0.5 `guide_line_dual_side` 实测未生成候选。定位为普通双侧横移先将首排推离连续前沿，且 gap 只读取第一个结构；修复为内侧首排锁定目标 gap、外侧排向外展开，`actualBodyGapBlocks` 改取整组最小方向 body gap。`CityStructureArrayLayoutLoopPlannerTest` 已通过，待重启客户端后从同一 D4 state 复验三轮 outward 与 RoadWeaver。
