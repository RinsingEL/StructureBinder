# MC 实机验收视角收敛

## 目标与边界

- 防止真实 MC agent loop 代入开发者视角读取源码，拖长实机验收。
- 只修改文档仓库的验收流程和角色权限真值，不修改运行时实现。

## 关键证据

- 同一 CitySeed 的 D2 返回 `territoryCheckResult=border`，D3 返回 `outside`。
- D3 实际请求由 agent 显式覆盖 `cellStepBlocks=16`，上游 W/T manifest 的步长为 `128`。
- 移除无依据覆盖后，D3 保持局部规划精度 `16`，领地结果恢复为 `border`。
- `outside` 只描述当前请求的判定结果，没有暴露有效参数来源或 `16` 与上游 `128` 的冲突，因此对工具使用者可能形成误导。

## 关键决策

- 真实 MC agent loop 只使用工具说明、上游产物、请求、返回、日志和 preview，不读源码或开发资料。
- 明确是自身命令或参数错误时直接纠正；仍异常就停止，不在验收阶段诊断。
- 返回标签只视为当前请求结果；缺少参数来源或与上游冲突时标记为信息不足或可能误导。
