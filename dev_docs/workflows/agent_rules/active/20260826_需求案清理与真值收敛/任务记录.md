*修改内容*：新增《需求案清理与真值收敛规则》，规定按职责链锁定实现当前案、允许设计中案和不同职责链并行、审计重叠旧案、迁移有效内容、用 Git 保存历史、保护工作区并收敛入口；新增只读到期脚本，session 启动时仅输出 `OK|DUE`，`OK` 禁止加载清理规则和需求文档；周期改为 1 天；新增事件标记脚本，并在需求案规则中要求替代案接管、职责变化或冲突发现时立即置为到期，普通编辑不触发；`docs/00_nav/README.md` 已收敛为双仓库唯一项目入口并独占 Session 与任务读取顺序，`task_router.md` 独占工作流和项目材料路由；两仓 AGENTS 只保留最小跳转；新增实现仓 `dev_docs/README.md`，登记正式目录、旧结构和按需读取边界，并增加领域内受限搜索兜底，禁止默认扫描全部需求案、文档仓库或历史记录。
