# Patch 探索式选址任务记录

## 任务范围

- 实现跨尺度 Patch Explorer，覆盖 `realm_t2`、`realm_t4`、`city_d4`。
- 由 AI 选择感兴趣的 patch 类型，程序按类型分页展示面积 Top 3，并只返回当前兴趣候选之间的稀疏几何关系。
- 选中后生成确认预览和稳定 selection ref；T4 用其登记城市种子，D4 用其约束后续 anchor 或完整阵列候选。
- 保留 D4 v0.5 已有连续外扩路径，不强制所有外扩先选 patch。
- 同步文档仓库的产品、接口、数据、代码导览与测试真值。

## 边界

- 面积排序只缩小候选范围，不计算文明叙事上的唯一最优项。
- 关系表不加入首都、国境、已有城市、建筑、occupied 等未被 AI 选为兴趣 patch 的对象；这些对象只参与硬校验。
- T 与 City 使用各自尺度的 patch 真值，selection ref 必须携带来源身份并拒绝 stale 消费。
