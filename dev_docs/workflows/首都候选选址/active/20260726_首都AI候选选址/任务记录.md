# 首都 AI 候选选址任务记录

## 目标

拆分 T2 国度扩张核心与首都最终选址，让首都在 T3 国境形成后由 AI 通过 `realm_t4` Patch Explorer 候选流程选定，并在 D3 局部真实地貌揭示后增加显式审查闸门。

## 已确认原因

- T2 同时生成 `RealmSeed` 与同坐标 `CapitalCitySeed`。
- T4 Patch 规划 create 直接继承该首都，容量校验只作用于新增非首都城市。
- D3 才揭示局部连续平地、崖壁、山谷与水域，但旧链路没有要求回退到 T4 重选。

## 实现边界

- 文档仓库：更新产品方案、数据契约、MCP 契约、代码导览和测试口径。
- 实现仓库：调整 T2/T4 artifact、HTTP/MCP 入口、D3 审查决策与 D4 阻断，并补自动测试。
- 兼容的自动 T4 只用于固定验收，必须标记 `rule_fixture`。
