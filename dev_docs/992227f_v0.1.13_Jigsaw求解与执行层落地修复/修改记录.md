- 已修正 `apply_now` 执行层对水平 jigsaw child 的两处误判来源：
  - `BuildRuntimeValidator`
    - runtime 碰撞校验现在显式跳过当前 task 的 parent task，不再把父节点本身当成 `runtime_footprint_collision`

    - `placementBounds(...)` 改为使用 runtime `StructureTemplate.getBoundingBox(...)` 作为真值

    - 同时执行层默认 `placementBounds(...)` 使用的是简化 bounds 计算，而 solver / vanilla 诊断使用的是 runtime 模板真实 bounding box，二者口径不一致
