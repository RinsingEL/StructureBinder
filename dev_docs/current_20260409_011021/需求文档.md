# 用户本次需求摘要
修复当前主链中的两个 bug：

- `jigsaw_solve` 成功后没有沉回 `C8` 会话树，导致 child 不能自然继续作为下一层 parent。
- `start` 结构高度偏高，和当前 runtime 覆盖模板的真实几何不一致。

# 用户特别强调的约束
- 本轮只修这两项主链问题。
- `start` 的高度要按运行时覆盖模板来修，不是简单改静态 catalog。
- solved child 成功后要自动入树并展开下一层，而不是继续保留旧的 placeholder child。
- 不把 `origin_offset.y = 0` 全局改成“统一下沉一格”的通用语义。

# 不做的事情
- 不处理“start 方向偶发不对 / 像被砍了一半”的后续视觉问题。
- 不修改 TerraSense 导出合同或额外补写 template_output override。
- 不要求 child 必须先落地到世界，才允许继续依赖 C8 会话树决策。
