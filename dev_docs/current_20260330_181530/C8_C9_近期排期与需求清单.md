## 6. 后续使用建议

后续推进时，建议每个任务都按下面的方式处理：

1. 先看“已落实，不再重复问策划”。
2. 只把 `Q1/Q2/Q3` 发给策划。
3. 策划回答完后，再同步写入需求文档。
4. 开发和验收继续按本任务的后两块推进。

这样可以避免：

- 已落实结论被反复重问
- 策划回答范围过大
- 需求文档里混入尚未拍板的开放问题
