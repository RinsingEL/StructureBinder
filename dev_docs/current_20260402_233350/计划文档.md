# C9 实际结构落地测试计划

## 本次任务标题

对当前 C8/C9 工作流继续联调，直接测试到实际结构落地。

## 最终计划摘要

基于已经通过 C8 联调的真实 group，确认 C9 真实落地入口与模式后，通过 MCP/HTTP 触发一次实际结构落地，并核对队列、执行结果和产物状态，最后给出是否成功落地、影响范围与残留风险。

## 实施步骤

1. 核对 C9 控制器与落地执行器，确认真实写入世界的调用参数。
2. 选择一个已完成 C8 首节点验证的 group 作为测试对象。
3. 执行真实 C9 落地，并读取返回结果与后续状态。
4. 记录测试证据、世界影响和风险，输出结论。

## 验收标准

- 能确认 C9 的实际落地模式与调用方式。
- 至少完成一轮真实结构落地，而不是仅生成队列或 dry run。
- 能说明落地了哪些节点、是否成功、失败原因是什么。
- 最终结论可以回溯到本轮测试记录。

## 关键假设

- 用户明确允许执行真实结构落地，允许测试对当前世界产生实际结构写入。
- 当前游戏内 HTTP 服务正常，且测试 group 的 C8 数据已具备可执行节点。
- 若真实落地受世界状态或模板问题影响失败，需要如实保留现场并报告。
