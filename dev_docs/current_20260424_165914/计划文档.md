围绕 C1 测试目的，先核对实现仓库中的 C1、W 步骤、T 步骤相关代码与已有运行入口，再检查文档仓库当前有效文档是否已经覆盖。若文档缺失或滞后，按代码事实补充文档仓库；实现仓库仅保留本轮过程记录。

1. 检查实现仓库与文档仓库当前 git 状态，确认不混入无关改动。

3. 对照文档仓库 docs/10_product、docs/20_contracts、docs/30_code_guide、docs/40_tests 中的当前说明。

5. 运行必要的文档/文本检查，必要时做 C1 相关测试或说明无法自动运行的原因。
6. 验收前读取本目录三份文档并据此总结。

## 验收标准
- 明确 C1 测试目的与当前测试/生成新图入口。

- 变更范围与任务目标一致。
