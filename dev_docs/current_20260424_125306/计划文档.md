# 本次任务标题
实现 C1 生存链路边界生成

# 最终计划摘要
新增并行 survival C1 城市边界生成链路，不替换旧 city_c1_generate / create_city。实现热力场边界 planner、兼容 claimedChunks 注册、/city_survival_c1_generate HTTP 入口、C1 边界 JSON/预览产物与轻量测试。

1. 创建本轮 AI 工作流过程文档。
2. 复核现有 C1/CityManager/HTTP 路由结构。
3. 实现 survival C1 boundary planner 与产物导出。

5. 添加轻量测试覆盖主权、重叠、地形风险、re-anchor 与 fail_safe。
6. 运行编译/测试验证。

# 验收标准
- 旧 /city_c1_generate 与 /create_city 行为不变。
- 新 /city_survival_c1_generate 可基于 CityConfig 生成 survival 边界。
- 最终 claimed chunks 不跨国度、不与其他城市硬重叠。
- 水体、坡地、方正度等不硬拒绝，只输出 risk tag / warning。
- 成功后现有 C2 能继续读取注册后的 claimedChunks。
- 编译和新增测试通过。

# 关键假设
- 第一版不接 OpenAI 图像模型、不做 C3 AI 草图。
- `allowed_polygon` 第一版允许先为空数组，以 claimed_chunks_compat 作为兼容真值。
- survival 链路作为新入口并行存在，不自动替换旧链路。
