# W / T 阶段实现与验收任务记录

## 目标与边界

- 按文档仓库国度规划系统 v1.1 方案，实现 W 粗 Patch 到 T4 `CitySeedRegistry` 的最小可玩闭环。
- W 使用 GIS v1.1 的 `cellStepBlocks` 参数化结果，不把 W / T 调度塞回 GIS 内核。
- T1 / T2 使用带 grid 坐标候选图选点，不兼容 legacy “AI 选簇 / 选方向 / 填低层参数”主流程。
- T3 复用 legacy 多源扩张思想，但重写为 per-run 服务，不使用旧全局静态状态。
- T4 只生成城市种子名册，不创建城市实例、城市内部边界、道路、功能区或结构物化。

## 关键实现

- 新增 `RealmPlanningService`，提供 `runW`、`prepareT1`、`selectT2`、`expandT3`、`buildT4`、`runAcceptance`。
- 新增 HTTP 入口 `RealmPlanningHttpController`，注册 `/realm/status`、`/realm/w/refresh`、`/realm/t1/prepare`、`/realm/t2/select_coordinate`、`/realm/t3/expand`、`/realm/t4/build_registry`、`/realm/acceptance/run`。
- 新增 MCP 工具 `country_designer_mcp/src/realm`，暴露 `realm_status`、`realm_w_refresh`、`realm_t1_prepare`、`realm_t2_select_coordinate`、`realm_t3_expand`、`realm_t4_build_registry`、`realm_run_acceptance`。
- 新增 Forge 命令 `/geomantia realm status`、`/geomantia realm acceptance [radiusChunks] [cellStepBlocks]`。
- 新增开发客户端 smoke 开关 `-PgeomantiaDevRealmSmoke=true`，可进入开发存档后自动执行 realm acceptance 命令。
- 新增 JVM 测试 `RealmPlanningServiceTest` 和 Forge GameTest `RealmPlanningGameTests.realmPlanningPriorAcceptance`。

## 产物与验证

- W / T 验收产物写入 `run/realm_debug/<runId>/`，包括 `world_survey_context.json`、`world_patch_map.json`、候选图、`realm_territory_map.json`、`city_seed_registry.json`、`acceptance_report.json`。
- `acceptance_report.json` 已包含 `durationMs`、分阶段结果、坐标检查、比例归一化检查、预览图清单和失败列表。
- T4 report 已写出 `citySeedCount`、`capitalCount`、`uniqueCitySeedIds`、`allCitySeedIdsUnique`。

## 已执行验证

- `./gradlew.bat test`：通过。
- `country_designer_mcp` 下 `npm run build`：通过。
- `./gradlew.bat runGameTestServer`：通过，2 个 required GameTest 成功。
- 真实 MCP 控制验收：启动开发客户端进入存档 `新的世界 (1)`，通过 MCP SDK stdio client 列出 7 个 `realm_*` 工具，并调用 `realm_run_acceptance`，runId 为 `realm_mcp_client_acceptance`，返回 `passed=true`。
- MCP 验收产物：`run/realm_debug/realm_mcp_client_acceptance/acceptance_report.json` 显示 W、T1、T2、T3、T4 全部为 true；`t4_report.json` 显示 9 个城市种子、3 个首都、ID 唯一。

## 文档同步

- 文档仓库已将 GIS v1.1 收窄为 step 参数化最小闭环。
- 文档仓库国度规划系统新增 W / T 主流程设计、v1.1 开发计划、数据契约、MCP 接口契约、测试入口、真实游玩验收计划。
- 本轮实现后补充国度规划系统 `30_code_guide/代码导览.md`，并把测试入口和真实验收计划更新为当前可执行状态。

## 风险与后续

- 当前 W / T 只覆盖一个 coarse GIS region 的最小闭环，跨 region / 大世界编排仍属于后续消费层或更高层编排。
- 当前默认国度 profile 是调试可玩默认值；正式世界主题下的叙事配置还需要上层 AI / 策划输入。
- 当前真实 MCP 验收确认链路可控和产物完整，但人工仍需查看预览图与实际地形的一致性，再判断审美和可玩性。
