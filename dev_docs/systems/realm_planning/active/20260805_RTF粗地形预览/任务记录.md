# RTF 粗地形预览任务记录

## 目标

为 W 与 T4 Patch Explorer 增加可独立开关的生成器原生粗地形预览。RTF 使用其二维 Heightmap 快速路径；原版、其他生成器和显式关闭场景回退现有 Minecraft prior sampler。T4 粗览只负责城市候选范围与建议粗锚点，D3 仍是最终地形真值。

2026-08-31 扩展目标：W、T2、D3 都输出独立群系总览图；T2 与 D3 默认优先使用 RTF 二维快速采样，RTF 未安装或运行时契约不可用时整批回退 Minecraft prior，不允许逐点混用。D3 地形重采样固定 `cellStepBlocks=16`，但城市物理规划范围仍按 W 来源步长换算，不能因 D3 step 改小而缩水。开发完成后只对 T2、D3 做真实游玩计时与产物验收。

## 当前设计

- 通用 `TerrainPreviewProvider` SPI 隔离具体世界生成器。
- W/T4 请求分别使用默认开启的 `preferGeneratorNativeTerrain`；关闭时记录 `generator_native_disabled`，互不改变对方配置。
- W `prior` 通过 `TerrainPreviewAtlasSampler` 复用 provider；非 `prior` 强制使用 Minecraft sampler。provider 完整身份进入 manifest/context/cache hash，Tag Audit 保留 Minecraft sampler 独立复核。
- W 通过 `GisRefreshService.ArtifactMode.NONE` 复用 GIS 计算内核，不生成逐 tile progress/preview PNG 和调试 manifest；普通 GIS refresh 默认 `FULL`，调试能力不变。
- `realm_t4` 打开探索会话时 lazy ensure 粗地形证据；每个 owned W cell 中心只采样一次。
- 邻格高度差计算 slope proxy 与 local relief，不追加四方向高度查询。
- 输出 `realm_t4_coarse_terrain_evidence.v0.1` JSON 和高度/水体 PNG。
- RTF provider 反射兼容 0.0.5 / 0.0.6，读取当前 `RandomState` 的 `GeneratorContext`，使用 `Heightmap.apply` 与 `Levels.scale`；不依赖 runtime tile cache，不生成 Chunk。
- provider 初始化不可用时整体回退；采样执行中失败显式报错，不逐点混用来源。
- RTF `RandomState.generatorContext()` 尚未初始化时，桥接层使用当前世界 `RegistryAccess` 调用公开 `initialize`，再读取同一个 context；初始化仍失败才整体回退。
- 群系总览使用最终 Minecraft biome id（不是只供诊断的 RTF source biome），W 取 cell 群系直方图主群系，T2/D3 取各自尺度 Atlas cell 的 biome id；三阶段共用确定性色表。
- D3 的来源 W step 只负责旧 grid 坐标、规划半径和领土坐标换算；D3 自己的 GIS/PlanningGrid step 固定 16。
- 产物固定声明 `advisoryOnly=true`、`requiredNextGate=city_d3_site_review`。

## 已知边界

- 当前提供的 RTF 源码版本为 0.0.6，开发运行 jar 为 0.0.5，运行时桥必须以实际 jar 签名验证。
- 半径 32768 的大世界仍会产生大量 Region tile JSON；原生采样消除了主要噪声计算成本，但文件数量、聚合和 PNG 渲染仍需真实验收。
- 首轮半径 32768 实测曾产生 216333 个 tile 文件，其中 149769 张逐 tile PNG；run 最终约 517 MiB，扫描 422021ms。用户确认后已删除正式 run 与 512 半径探针 run；删除不可恢复，共用时 93 秒。
- 粗览高度是生成器二维 estimated surface，不包含 D3 最终地表、结构、植被和完整 surface rule 结果。
- City 固定 NBT 结构已在 RTF 世界现场确认真实落地；地基、削坡和地形融合不属于本任务。
