# 冒险者地图拖动

*需求入口*：冒险者地图当前案；用户要求 UI 可拖动，并确认“拖动地图内容”。

*修改内容*：地图左键平移、保持浏览中心；客户端即时绘制并合并视口刷新，服务端按浏览中心裁剪底图及节点，保留迷雾与 LOD。追加用户要求的玩家面朝向：玩家标记改为带暗色描边的黄色箭头，每帧读取插值 yaw 旋转，坐标文字保持正向，不增加网络请求。

*验证结果*：compileJava 通过；AdventurerMapStatusReaderTest 与 AdventurerMapRetryPolicyTest 共 9 项通过。扩展视口回归验证远处城市进入、原节点离开、负坐标、未开放区迷雾与 W 范围外空底图。朝向追加改动 compileJava 通过，静态核对 yaw 0/90/180/-90 分别朝地图下/左/上/右；两仓 git diff --check 通过；未进行游戏内鼠标交互实测。

打包：用户要求打包，执行 `gradlew.bat jar` 成功，`reobfJar` 完成，产物位于 `build/libs/`。

*剩余问题*：游戏内拖动手感及朝向视觉尚未实测；网络协议由 5 升至 6，联机客户端和服务端需使用同版本。未提交。
