# 冒险者地图基础 GUI

*需求入口*：`docs/systems/realm_planning/10_product/案子/冒险者地图-v0.1/README.md`；用户最新确认地图改为物品入口，不占固定热键，并显示粗略地图与当前人物实时位置，且必须控制性能。

*修改内容*：已移除 `M` 热键，注册 `geomantia:adventurer_map` 物品、工具类创造栏入口和“地图 + 指南针”合成配方；物品使用后由服务端通知客户端打开地图。地图后台读取 W `world_feature_grid.json` 与 `realm_territory_map.json`，按最多 `96×96` 栅格压缩并按文件时间戳缓存，不读取约 69 MB 的 `world_patch_map.json`，也不加载新区块。客户端把底图构建成单张动态纹理，玩家位置每帧单独覆盖；打开期间每 5 秒低频请求最新 artifact，未变化时复用缓存。

*验证结果*：`AdventurerMapStatusReaderTest` 聚焦测试通过，新增覆盖地形/群系粗分类、国境叠色、坐标范围、固定最大栅格与明确不读取 `world_patch_map.json`；`compileJava` 通过，语言、模型和配方 JSON 可解析，源码中已无地图热键注册引用。

*真实游玩验收*：已在 `RTF_beta_validation_01` 中打开基础界面，地图能够显示 W/T 阶段状态；随后通过正式接口完成半径 4096 的 W、三国 T1/T2 与单次统一 T3，地图刷新后的目标状态为 T3 已完成、T4 待处理。详见 `真实游玩调用记录.md`。

*首次登录发放*：新增 `AdventurerMapStarterGrant`。服务端在每名玩家首次进入当前存档时发放一张地图；已有地图时只写领取标记，不重复发放。领取标记写入 Forge 的玩家持久化 NBT，并在玩家 Clone（含死亡重生）时继承，避免重新登录或重生刷取地图；极端满背包时物品掉落在玩家位置且仍记为已领取。

*剩余问题*：尚需在真实客户端验收物品合成/右键、底图朝向与缩放、跨维度玩家标记隐藏，以及持续打开地图时的帧率；旧的基础 GUI 实机记录不能替代本轮物品和动态底图验收。
