# 冒险地图与可选附属拆分

*需求入口*：用户明确授权开发《冒险地图与大陆解锁》《主模组与可选模块拆分》，两案已提升为实现当前案，契约同步至 docs/systems/realm_planning/20_contracts/接口契约/可选模块与大陆调度.md。

*修改内容*：

- 主 Mod 持有 PlanningHost、workflow、统一 MCP 和区域保护；模型配置、凭证与执行循环迁入 Harness 附属，地图物品、网络和界面迁入地图附属，各自独立发布，附属不互相依赖。
- 主包单独携带 MCP Node 运行资源，不依赖 Harness 安装；首次无配置且未安装 Harness 时打开端口设置，保存后记忆。普通 Harness 用户从暂停菜单配置规划助手。
- (0,0) 新手村国度默认圆形半径 2048，可沿用配置调整；立即开放，不建城市；世界与 W 输出描述文件。
- 地理队列按大陆优先，跨国度完成名册和城市设计；保留城市生成计划激活、附属预留和保护区校验后整片大陆与近海开放。
- 地图改为轮廓、国家边界与名称、城市和玩家标记；普通模式隐藏未开放区域，服务端裁剪隐藏数据，Debug 权限受服务器控制。
- 三个 Jar 使用独立 Java 包，地图资源归属附属；新增 coreMcpTest 和 verifyAddonPackaging 防止依赖倒置、共享包和重复 Mixin。

*验证结果*：1197 项 JVM 测试，0 失败，11 跳过；coreMcpTest 两项通过；三个发布包检查通过。仅主包与双附属两种 Forge 环境均通过区域门禁 GameTest（拒绝提前 FULL 加载、无落盘、开放后可重试）。没有调用真实模型完成城市生成链路，隔离世界缺少作者结构源提示不代表该链路已验收。

*剩余问题*：游戏内地图观感、设置界面交互及完整整合包游玩尚待实机验收；运行资源仍限 Windows x64。实现已提交 `791e5b71`，需求文档已提交 `13533e5`；未修改用户既有素材目录和 Structure Studio 工作区改动。
