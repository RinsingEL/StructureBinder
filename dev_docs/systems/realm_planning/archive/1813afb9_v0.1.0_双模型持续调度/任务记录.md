*需求入口*：用户希望高级外部 session 与 Mod-Harness Flash 自动接力，允许换另一个 session；授权完善总调度。

*修改内容*：新增角色感知的持续领取入口，自动等待另一端、执行程序步骤和交接占用，公开内置 Flash 启用/阻塞状态，更新 Agent 续接指引。

*验证结果*：独立 worktree 基于 8c1b8833，仅应用本次六个调度文件；15 项 Java 回归、21 项 MCP 测试通过。覆盖等待 Flash 不占锁、升级后收到高级任务、转回 Flash 释放占用、新 session 不抢锁且可接续、关闭 Flash 的提示、取消等待、MCP 角色/凭据/图片传递。此轮是自动化与 MCP 进程回归，没有重复前一轮游戏内 NPC 生成验收。主模组与 Harness 打包/reobf 成功，并已校验 SHA-256 更新到 PCL 测试端；旧 jar 在版本目录 geomantia-backups/20260926-continuous-dispatch。测试日志与部署清单见本目录。
