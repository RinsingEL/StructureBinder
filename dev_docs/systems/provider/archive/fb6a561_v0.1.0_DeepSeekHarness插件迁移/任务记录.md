# DeepSeek Harness 插件迁移

*需求入口*：用户要求直接替换 Hermes、减小包体，并将 Geomantia 接成 Harness plugin。

*修改内容*：固定官方 Harness 0.1.5-rc.2 + Cordis 4.0.2，Geomantia 注册提示词和宿主限定工具；原生附件贯通初始图及工具返回图，顺序工具调用、24 步上限、宿主完成即停、JSONL 会话恢复。Java 私有 stdio 代替 Gateway；保留原有游戏工具与外部 MCP。默认 runtime 与旧 Hermes 配置归一化为 Harness，DeepSeek 官方预设采用 deepseek-flash/Chat Completions，Go 自定义模型及密钥保留；移除 Hermes/Python 归档与适配。内置 Node、sharp/Koffi 原生库和许可证，新增可重建包、源码指纹校验与真实解压集成测试。

*验证结果*：Harness bundle 的 DeepSeek Chat、通用 Chat、Responses 图片链路、18 万字符长反馈、会话恢复、宿主完成停止通过。实际 Go 模型初始蓝图→工具黄图识别通过，两次模型请求分别附 1/2 张图片，报告见同目录 JSON。首次随机色块测试曾把绿色答成蓝色；直接 API PNG/WebP/JPEG 绿色均正确，后续 Harness 测试正确，因此不将首次错误归因于已确认的传输故障，也不宣称模型视觉判断无误。

Provider Java 回归：98 项，95 通过、3 个依赖现场 fixture 的测试跳过、0 失败；独立内置运行时集成测试 4.3 秒通过。3 项 Node bundle 集成测试通过。Gradle test / jar / reobfJar 通过，最终包约 47 MB，旧包 133 MB；发布包结构与运行时哈希做最终核对。

*剩余问题*：尚未重启开发端游戏，也未在新内核下跑完完整城市；本轮未提交。

## 独立分发验证发现并处理
构建目录测试可通过，却掩盖了本机 node_modules 兜底。独立安装先后发现 sharp 未复制（exports 隐藏 package.json）、上游 createRequire 的包版本路径未随 bundle 重定位、Windows 会话落盘 Koffi 原生库未打包。已修复制策略、构建期静态包版本解析及 Koffi/Windows 原生依赖；新增从内置 ZIP 启动 Java→Harness→HTTP→工具→图片的集成回归，不能以源码运行代替。
