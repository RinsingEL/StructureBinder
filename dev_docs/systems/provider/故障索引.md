## 2026-09-11：D4 编译仍在计算时被 Hermes 转发层45秒超时截断

*现象*：PLANNING_HOST_BLOCKED: request timed out，稍后宿主写入有效草稿。

*首次偏离*：ProviderPlanningToolGateway 构造 D4 submit HTTP 请求。

*根因*：submit 被归为短请求，45秒截止；Node直连MCP使用600秒。约225秒的有效编译被提前认定宿主故障。

*修复*：对齐D4提交截止时间为600秒，其他工具保持原截止时间。

*验证*：延迟46秒的真实HTTP回归通过，完整Gradle build通过。

## 2026-09-14 完成复核后结束模型轮次被误记为无进度

*验证*：新增完成复核续跑/重复复核不计进度测试，全量回归中通过。

## 2026-09-17 Harness 长设计会话超限（修复及副本验证通过）

*首次偏离*：内核迁移组成未挂载自动压缩，同时继承超大输出默认值。
