# GIS 系统包迁移任务记录

## 目标与边界

- 按文档仓库 `docs/00_nav/实现仓库结构规范.md`，把已开发 GIS 从 `world.atlas` 迁移到系统内聚包。
- 清理未开发系统和空公共层占位 package。
- 同步文档仓库 GIS code guide、测试入口和结构规范导航。
- 不改变 GIS v1 行为、不引入 G8 消费者接口、不实现生产级持久层。

## 关键决策

- GIS 系统主包迁移为 `com.rinsing.geomantia.systems.gis`。
- `application.refresh` 承载刷新 workflow / 用例编排。
- `domain.*` 承载 `AtlasCell`、`AtlasRegion`、`LandformPatch` 等核心对象。
- `algorithm.*` 承载指标计算、地貌分类和 Patch 合并。
- `adapter.minecraft`、`adapter.snapshot` 承载 Minecraft prior 采样和轻量快照 IO。
- `preview` 承载 progress、preview 图层和 manifest 导出。
- `testsupport` 承载固定样例、测试 runner 与 Forge GameTest。
- Forge 命令和 HTTP 入口暂留 `platform`、`platform.http`，作为适配边界调用 GIS 系统包。

## 重要修改

- 迁移 `src/main/java/com/rinsing/geomantia/world/atlas/**` 到 `src/main/java/com/rinsing/geomantia/systems/gis/**`。
- 迁移 JVM 测试到 `src/test/java/com/rinsing/geomantia/systems/gis/**`。
- 删除 `city`、`structure`、`world/realm`、`api`、`core`、`debug`、`runtime` 等未开发占位 package。
- 文档仓库新增实现仓库结构规范，并同步 GIS code guide 的包结构表。

## 验证结果

- `./gradlew.bat test`：通过。
- `./gradlew.bat runGameTestServer`：通过，1 个 required GameTest 成功。
- `country_designer_mcp` 下 `npm run build`：通过。
- 源码和当前 GIS 文档已扫描确认没有旧 `world.atlas` 包路径残留。

## 未解决风险

- 本轮是包结构迁移，git diff 会比较大；行为层依赖测试和 GameTest 证明未变。
- `platform` 尚未拆成 `platform/forge`，后续如继续细化适配层，可单独做小迁移。
