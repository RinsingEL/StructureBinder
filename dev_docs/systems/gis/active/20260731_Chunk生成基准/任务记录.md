# GIS Chunk 生成基准任务记录

## 任务定位

- 日期：2026-07-31
- 类型：GIS 调试性能工具，双仓库联动，涉及 HTTP / MCP 接口契约。
- 目标：由服务端主动生成与标准 D3 context 近似同面积的新 Chunk，记录 `50% / 95% / 100%` 完成时间，作为 D3 性能重构的黑盒基线。

## 实现范围

- 新增 `ChunkGenerationBenchmarkJob`：维护 `65 x 65 = 4225` 等方形目标、load 分类、FULL 完成计数、分位时间、吞吐和 cold baseline validity。
- 新增 `MinecraftChunkGenerationBenchmarkService`：建立 / 移除临时 Region Ticket，写 `chunk_generation_baseline_report.json`，保证单服务端同一时刻只运行一个任务。
- 新增 `ChunkGenerationBenchmarkEvents`：读取 `ChunkEvent.Load.isNewChunk()`，并在后续 `ServerTickEvent:END` 确认目标 Chunk 已成为可用 `LevelChunk`。
- GIS HTTP 新增 benchmark start / status；MCP 新增对应启动 / 查询工具。
- 启动必须显式传 `confirmGenerateChunks=true`；默认 `requireFresh=true`，起测前目标范围已有加载 Chunk 时拒绝。

## 边界与风险

- 该工具会真实生成并可能保存 Chunk，不进入 GIS prior、City D3 或服务器启动默认路径。
- cold validity 只有在全部目标均为本轮新生成、无磁盘旧 Chunk、无起测前加载且任务完成时成立。
- 服务端停止、任务超时、失败和正常完成都必须移除临时 Region Ticket。
- 第一版只实现 `view_distance_32_full`；本轮另用正式 `city_plan_d3` 入口完成同中心 `d3_cold_prior` 黑盒测量，但 `base_height_only` 与完整 D3 分项计时尚未实现。
