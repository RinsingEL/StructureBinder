## 实现摘要

- 新增 `com.rinsing.geomantia.world.atlas` 分层：
  - `cell`：AtlasCell、状态位、采样源、表面类型、地貌枚举。
  - `region`：AtlasRegion、RegionStore、坐标换算、轻量 `AtlasRegionSnapshotIo`。
  - `sample`：`AtlasSampler`、Forge `MinecraftPriorAtlasSampler`、synthetic 测试采样器。
  - `metrics`：坡度、局部起伏、粗糙度、小尺度 TPI、大尺度 TPI、水距。
  - `landform`：规则分类、四邻接 Patch 合并、Patch 摘要和 flags。
- `refresh`：RefreshJob、半径规划、GisRefreshService。
- `preview`：progress 图/manifest、预览图层/PreviewManifest。
- `test`：固定样例、测试 runner、Forge GameTest。
- 新增 `/geomantia gis refresh <radiusChunks> [sampleMode]` 和 `/geomantia gis test_run <caseId>` 调试命令。
- Gradle 接入 JUnit 5，并补最小 GameTest 模板 `gameteststructures/gisgametests.empty.snbt`。
- 收口时修正分类 / Patch 合并状态边界：仅 `sampled + metricsReadySmall + metricsReadyLarge` 的格子进入地貌分类，未采样格子在快照回读后仍保持 pending。
