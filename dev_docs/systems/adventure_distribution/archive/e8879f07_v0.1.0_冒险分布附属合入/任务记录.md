*需求入口*：用户要求将怪物分层所在冒险工作树合入、提交并推送，并确认它作为附属功能是否影响主功能。需求以策划仓《冒险内容分布附属模组-v0.1》及当前配置接口为准。

*修改内容*：从 `codex/adventure-distribution` 的未提交实现增量迁入冒险附属源码、测试、五类默认配置及探索试配。源码与作者资料归入 `addons/adventure/`，沿用主构建的独立 adventure source set 与单独 JAR；主模组仅加入地理/结构事件和空间预留接口。保留当前主仓 D4、地图/Harness 和 Realmfolk 改动；不带入旧工作树的 Harness 运行包修改。原工作树保持原样作为来源。

*验证结果*：附属不增加怪物数值，仅按大陆邻接档位选池；默认不启用 adventure。13 项 adventureTest、3 项无附属 classpath 的 coreMcpTest、verifyAddonPackaging 与 verifyAdventurePackaging 全部通过。只加载主模组的隔离区域 GameTest 1 项通过；加载冒险附属的 Forge 事件 GameTest 2 项通过，验证居民区抑制刷怪、占地竞争/撤回、结构起点生成与不强制加载区块。主仓全量 1364 项中 16 失败、13 跳过；从合入前 4b32d0b1 取源码建立独立基线，全量同为 1364 项、同一组 16 失败、14 跳过，无新增失败。额外跳过的是基线未装本地样本的 ApprovedEntranceCatalogTest.installedDevelopmentBundleResolvesWithItsAuthoredEntrances；主工作区该项通过。完整结果见 verification.json、initial-test-summary.json 与 GameTest 日志，不宣称全量测试全绿。
