## 已完成实现

- D4 key、array、cluster、continuous 和 staged workflow 只接受显式 template catalog 与 `templateId/templateRef + variant`；删除 configured identity、envelope facts 和随机 template variant 选择。
- TerraSense catalog 的输入不再要求 footprint/profileType 等几何字段，active 输出收紧为 `city_semantic_profile_catalog.v0.1`；查询响应升级为 `city_structure_catalog_query.v0.2`，只返回 `semanticProfileId` 与 terms，不再返回 `structureId`、`hardFacts` 或任何 profile 几何。D4 不再按 template ID 回查 TerraSense identity；旧源文件 `structureId` 仅作为读取别名。
- D5 只按 exact footprint + clearance 生成 collision，再按 collision + maskMargin 生成 mask。
- D6 使用当前世界 NBT inspector 复核 hash、rawSize、rotation、mirror、footprint、collision、mask 和 owner chunks；D7 对同一 identity 与几何做完整 drift 校验。
- active schema 只保留 `city_template_catalog.v0.1`、`city_template_placement_plan.v0.1`、`city_active_template_placement_registry.v0.1`、`city_template_placement_ledger.v0.1`；piece boxes、start signature、bbox group 和 envelope sample 均退出 active path。
- `tryGenerateStructure` 只保留自然结构 mask；`createStructures` 只注入 City 自有单-piece fixed-template start；所有 catalog 模板冻结为 `structure_start_beard_thin`。
- 预览分层使用 template body、collision、mask；不使用 `StructureStart.getBoundingBox()` 表示建筑实体。
- 删除 envelope profiler/facts/sampler、configured materialization backend、direct FEATURES template placer、retry coordinator、`city_profile_structure_envelopes` 与 `debugLateMaterialize`。
- 旧 configured payload/artifact 在 active endpoint 返回 `CITY_CONFIGURED_STRUCTURE_FLOW_REMOVED`。
