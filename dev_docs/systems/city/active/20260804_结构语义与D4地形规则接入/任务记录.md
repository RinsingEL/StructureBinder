# 结构语义与 D4 地形规则接入任务记录

## 本轮范围

- 实现仓库：StructureProfile 支持 TerraSense v0.2 binder source，保留 `functionTerms/planningRoleTerms/styleTerms`，新增 City 固定 `terrainModes`；删除声明式 Structure Terrain Policy 链，D4 直接对冻结 D3 terrain field 执行 topology gate。
- 运行时配置：把当前 Trek 46 条与 Stubbs 15 条合并目录迁移为 61 条 `terrainModes=[SURFACE]`，删除旧 policy 文件，补 `build_catalog.ps1` 数量与字段校验。
- 文档仓库：同步 City / TerraSense 方案、数据契约、MCP 接口、代码导览、测试入口、影响面与导航。
- 不修改 TerraSense 工程和 2026-08-04 v3 原始导出目录；不提交 Git。

## 决策口径

- `functionTerms`、`planningRoleTerms`、`styleTerms` 继续由 TerraSense 动态词表配置；`styleTerms` 只给 AI / 人工阅读和目录查询，不参与 Java 评分、候选合法性、placement 或 worldgen。
- `terrainModes` 是 City 固定 placement topology 枚举数组，值域 `SURFACE | EMBEDDED | FLOATING`，多值按 OR 解释；旧 `terrainTerms` 明确退役并在导入期拒绝。
- 当前运行时只实现 `SURFACE`。required、fill、connectivity batch 的 transformed collision footprint 覆盖格必须全部存在、已采样且非水；不按坡度、局部起伏或群系 hard reject。
- `EMBEDDED/FLOATING` 单独声明时明确返回不支持；与 `SURFACE` 同时声明时解析为 `SURFACE`。成功 mode 冻结到 trace 和 anchor。
- Group Blueprint 的 `terrainPolicy` 继续表示 patch 排序与适配偏好，不再按 slope threshold 从候选 patch 集合硬删除。
- D4 复用每次 D3 已生成的 `city_land_use_terrain_field.v0.1`，不重新扫描世界、不加载 chunk。

## 实现与数据结果

- 新增 `CityStructureTerrainMode` 与新版 `CityStructureTerrainGate`；目录查询展示 modes，但 term filters 只匹配三组 TerraSense canonical terms。
- prepare MCP/HTTP 不再接收 `structureTerrainPolicySource`，Context/Snapshot 只冻结语义画像与 D3 terrain field。
- Trek 导出器直接生成最小结构画像与 `terrainModes=[SURFACE]`；当前合并运行时目录校验为 Trek 46、Stubbs 15、合计 61，旧 `terrainTerms` 为 0，非法 mode 为 0。
- 合并目录的词表只保留 19 个实际引用词：function 11、planning_role 2、style 6；退役 terrain/quality/usage 等未消费词不再进入运行时词表。
- 原始 `run/jigsaw-import/.../build_catalog.ps1` 与运行目录迁移脚本均已改为新口径，避免重跑后重新引入 `terrainTerms` 或独立 policy 文件。
- 沙漠、沼泽等环境语义仍保留在已有 `styleTerms`，不转成 biome hard gate。
- Blueprint 自动连接调用旧外扩候选器时跳过老的 cliff/steep/water patch 预过滤，由统一逐格 structure terrain gate 决定合法性；独立 Agent Loop 的历史过滤保持不变。

## 当前限制

- `EMBEDDED/FLOATING` 尚未实现实际落地语义，不能因枚举已存在而视为可用。
- `SURFACE` 当前只保证 D3 footprint coverage、sampled 与非水；结构基础适配、坡面切填和群系适配仍属于后续能力。
- 本轮不新增群系预览图；AI 可从画像 `styleTerms` 读结构风格，程序地形门禁直接消费已有逐格 terrain field。
