- 目标：为喷泉、雕像、水井等单点关键 prefab 提供程序生成的合法候选，替代 Agent 手算 offset 和世界点穷举。

## 已确认决策

1. 候选工具读取现有 DecorationProgram v0.4 意图、D3 / LandUse target mask、真实 decoration catalog 和既有 hard obstacles。
2. 首版只处理 local `(0,0)` 单点 rectangle + `grid_repeat` 的关键 prefab；普通 scatter、edge、grid 阵列保持原投影路径。
3. 候选以真实 prefab footprint 和 `max(comfortMargin, conflict clearance)` 做完整面域过滤，不只检查 anchor 点。
4. 候选不得跨出 target mask、压住 D6 / 城墙 / gate / road gateway / LandUse gate 等硬障碍，也必须满足当前同 chunk prefab 限制。
5. 规划阶段不生成或加载目标区块，不声称完成真实地形验证；运行时 terrain preflight 继续作为最终守门。
6. Agent 只选择候选，并把返回的相对 `coordinateFramePatch` 回填到最终 DecorationProgram；最终意图不新增世界坐标字段。

## 风险

- 首版不做真实 block terrain sampling；候选合法表示几何、占地和障碍合法，不代表已通过运行时地形检查。
- 当前运行时只支持 prefab 完整位于 anchor 所属 chunk，候选必须同步遵守该限制，否则会产生规划可选、落地跳过的不一致。
- 首版正式 `grid_repeat` 单点 slot 只能稳定复现 0 度 prefab；不允许 0 度的素材会返回空候选。朝向枚举需另行扩展正式 DecorationProgram 的可回填 rotation 契约，不能只在候选层伪造。
