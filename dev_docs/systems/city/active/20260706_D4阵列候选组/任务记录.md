# D4 阵列候选组任务记录

## 背景

用户提出当前城市缺少“勃勃生机”的批量结构节奏，希望在道路生成前提供阵列算法：AI 指定若干结构模板和数量，程序从 D3 patch 中生成一组组已处理防碰撞的候选点。当前 City 真值要求道路晚于结构落地，因此本轮不沿道路、不提前生成道路。

## 实现内容

- 新增 `CityStructureArrayCandidatePlanner`，支持 `loose_cluster`、`patch_axis_band`、`scattered` 三种阵列候选 pattern。
- 新增 `CityStructureCandidateEnvelope`，让 D4 单点候选与阵列候选复用同一套候选层 envelope 估算逻辑。
- 新增 `city_plan_d4_array_candidates` HTTP / MCP 调试入口。
- 新增 `d4_array_candidate_set.json`、`d4_array_candidate_preview.png`、`quality_report.json` artifact。
- 候选组内每个 item 输出估算 collision / mask / safety envelope，候选组输出 `expandedStructureAnchorPlan`，可直接交给现有 `city_plan_d4`。
- `arrayCount` 必须完整满足；容量不足返回 `D4_ARRAY_COUNT_UNSATISFIED`，不输出部分候选组。
