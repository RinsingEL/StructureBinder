## 实现摘要

- 新增 `CityStructureD6Planner`：导入 TerraSense 导出快照，生成 `StructureProfileCatalog` / `FilteredStructureCatalog`，校验 `StructureChoicePlan` 与 `FixedPlacementSelectionPlan`，生成 `FixedPlacementCandidateSet`、`PlannedFixedPlacementMap`、`StructurePoolMap` 和质量报告。
- D6 强制边界：不调用 `/place structure`，固定结构不接受 AI 坐标 / 占比 / jigsaw 参数，非固定结构才接受 `targetVisibleAreaRatio`，真实候选只允许 `structure_assembly` + `minecraft_place_structure` + 合法 configured structure ID 形式。
- 新增 `CityStructureD7Executor`：优先完整处理 fixed_footprint，程序生成 variable_area 的 `StartCandidateSet`，用 world seed / city / zone / task / structure / attempt 组成稳定 key 做 seeded random，输出 `PlacedStructureMap` 和 `StructureGenerationTrace`。
- D7 强制边界：不接受 AI 剩余结构坐标、AI 重试或逐 piece 决策；固定结构完整放置或结构化失败；variable_area 可少生成但写 trace / failureSummary。
- 新增 `MinecraftStructurePlacementBackend`：dry-run 校验 configured structure registry，真实执行时调用 `/place structure <id> <x> <surfaceY> <z>`。
- D7 Minecraft backend 改为直接调用 vanilla `PlaceCommand.placeStructure` 等价入口，预加载 planned footprint 周边 chunk，并在失败 trace 中写入 surfaceY、biome、commandChunk、loadedFootprintChunks。
- D6 固定候选已按 TerraSense `footprint.origin_offset` 还原 command anchor 与内容 footprint 的关系，并把 rotation 归一为 MC 大写枚举，避免非方形 fixed footprint 旋转错算。
- 新增 `CityStructurePreviewRenderer`：输出 D6 结构选择 / 固定落点预览图，D7 起点候选 / 已放置结构预览图。
- HTTP / MCP 新增 `city_plan_d6` 与 `city_execute_d7`。

## 剩余风险

- 自动化测试已覆盖拒绝 template / jigsaw ID、固定结构不裁切且失败后不继续 variable、seeded random 可复现、失败原因结构化、origin_offset command anchor、rotation 归一和 HTTP artifact / preview 写出。
- 本轮真实验收已达到临时最小可玩口径：至少 1 个 `fixed_footprint` 完整落地；至少 1 个 `variable_area` configured structure 写出 StartCandidateSet 并在 `StructureGenerationTrace.failureSummary` 中给出结构化可解释失败。
- 剩余风险是 RTF 存档与纯 Forge/vanilla 存档对自定义 fixture 的 `PlaceCommand` start 判定不同。当前按用户“尽量原版”要求，以无 RTF 依赖的 `新的世界 (1)` 完成真实验收；若后续要在 `新的世界` / ReTerraForged 存档内验收，需要单独排查 RTF worldgen/mixin 对 configured structure start 的影响。
