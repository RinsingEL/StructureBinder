2026-06-16

## 范围

按 `docs/systems/city/10_product/开发计划-v0.1-City城市构造最小闭环.md` 实现 D2 (C0 CitySiteContext) 和 D3 (C1.5 CityLandformReviewPackage)。

D1 (TerraSense 导出适配器) 不在本轮范围。

## 新建类清单

### Domain Model (`systems/city/domain/model/`)
- `CityScale.java` — 规模枚举，含 T4 兼容映射（capital→CITY）
- `BlockPoint.java` — Block 坐标 record
- `BlockBounds.java` — 包围盒 record，含 overlap/contains
- `PlanningGrid.java` — 局部规划网格，含坐标转换
- `EntryCandidate.java` — 入口候选 record
- `TargetScale.java` — 目标规模 record
- `MetricsSummary.java` — 地貌指标摘要 record
- `CitySiteContext.java` — D2 主输出，含 asJson() 和 14 个字段
- `LandformPatchSummary.java` — GIS patch 摘要，含 mapLabel/areaClass/facts
- `CityLandformReviewPackage.java` — D3 主输出，含 LegendEntry 内部 record

### Domain Config (`systems/city/domain/config/`)
- `CityPlanningConfig.java` — 配置 record，含 ScaleRadius/AreaThresholds/标签映射/defaults()/with*()

### Application (`systems/city/application/`)
- `CitySiteContextBuilder.java` — 从原始参数装配 CitySiteContext
- `CityLandformReviewBuilder.java` — 从 Context + GIS Patches 生成 ReviewPackage

### Infrastructure (`systems/city/infrastructure/json/`)
- `CityJson.java` — Gson 单例

### HTTP (`platform/http/`)
- `CityPlanningEndpointHandler.java` — D2/D3 HTTP 端点实现
- `GeomantiaHttpServer.java` 新增 2 个端点注册
- `RealmPlanningHttpController.java` 新增 2 个 handler

### MCP (`country_designer_mcp/src/realm/`)
- `tools.ts` 新增 `city_plan_d2`、`city_plan_d3`
- `handlers.ts` 新增对应 handler

## 2026-06-16 Codex 复核修正

### 修正内容

- D2/D3 HTTP 入口在未显式传 `cellStepBlocks` 时，从 `world_survey_manifest.json` 恢复 sealed run 的 W/T 采样步长。
- D2/D3 优先使用 T4 `city_seed_registry.json` 的 `anchorBlock`，避免 MCP 默认步长导致真实坐标错位。
- D2/D3 读取 `realm_territory_map.json` 中同 realm 的 `owned` cells，接入 `territoryCheckResult`。
- D3 新增 `CityLandformReviewMapRenderer`，输出 `landform_review_map.png`，并写入 `reviewMapImage`/`debugRefs`。
- D3 facts/planningContext 收回为中性 GIS 事实，不再输出“适合建设”“建议建设区域”等 C2 决策文案。
- 补充 `CityPlanningEndpointHandlerTest`，覆盖 D2 sealed run 元数据恢复。
- 更新 `CityRealDataTest`，使用真实 manifest/registry/territory map，不再用错误的 `gisCellStep=8` 代表真实 run。
