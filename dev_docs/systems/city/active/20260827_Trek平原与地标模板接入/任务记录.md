# Trek 平原与地标模板接入

*需求入口*：用户要求在第一次真实城市设计前，接入已标记的非 Stubbs 建筑，以及实看确认可用的平原喷泉、两座红树林瞭望塔和可选矿业巨爪。

*修改内容*：固定 Trek 导入器扩展为同时支持 configured structure 与经审核的直接单体 NBT，并按显式策略清除 Jigsaw / Trek 生物 marker；manifest 新增平原喷泉、两座红树林瞭望塔和矿业巨爪。四个模板已写入 RTF0810 世界数据包，正式运行配置由 61 扩为 65 个模板、65 份语义画像与 65 个 Blueprint 引用，并新增平原住宅、商业、农业和普通防御四个纯风格 fill pool。喷泉保留四向道路入口；不新增阵列或峡谷专用落地规则。

*验证结果*：Python 导入器 16 项测试通过，24 模板 dry-run 通过；`CityTemplateCatalogTest` 与 `CityBlueprintCompilerServiceTest` JVM 回归通过。真实客户端 RTF0810 中四个 NBT metadata 均可读并冻结实际尺寸/hash；重启后正式 `query_structure_catalog` 从 65 份 approved profile 中检索到喷泉、双塔和矿业巨爪，warnings 与 needsReview 均为空。双仓库 `git diff --check` 通过。

*剩余问题*：无；尚未把这些模板用于下一次完整城市蓝图，等待用户开始真实城市设计。
