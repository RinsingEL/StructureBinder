# LandUse 同类连接 AI 配置任务记录

## 目标

将同类 LandUse 的接触融合和近邻桥接从全局 `mergeSameType` 自动行为，收紧为设计 AI 显式连续性意图。未配置的 group 默认保持独立。

## 本轮边界

- 实现 `continuous_surface`、`logical_district`、`independent` 三种连续性模式。
- 接触融合与近邻桥接只允许相同 `continuityGroupId` 的 `continuous_surface` 主体。
- `logical_district` 保持物理组件分离，但共享稳定逻辑 area ID，便于预览和下游按逻辑区消费。
- 不实现 `road_seam` corridor、道路宽度算法或农业宽桥；这些继续作为后续独立能力。

## 计划验证

- intent v0.2 严格字段、枚举、必填关系、重复与未知目标校验。
- 默认独立、连续地表接触融合、连续地表近邻桥接、不同连续组不桥接、逻辑街区不物理融合。
- LandUse 相关定向单元测试与完整测试回归。

## 完成情况

- `city_land_use_intent_plan` 升级为 v0.2，新增严格 `continuityOverrides[]`；旧 v0.1 明确拒绝。
- `LandUseSeedGroup` 冻结归一后的连续性模式和组 ID。
- `LandUseGeometryCompiler` 只融合同连续地表组；逻辑街区共享稳定 `areaId`，并使用来源组 / 首 span 稳定排序，保证 plan hash 确定性。
- `NearbySameTypeBridgePlanner` 只为同 `ruleRef + continuityGroupId` 的连续地表生成桥，并在 trace 中记录连续组。
- 连续地表在桥接后仍有多个物理组件时以 `LAND_USE_CONTINUOUS_SURFACE_DISCONNECTED` hard fail。
- preview 对同逻辑 `areaId` 使用同色并合并图例，metadata 增加 `logicalAreaCount`。
- 文档仓库已同步产品案、数据契约、接口契约、代码导览、测试入口、影响面和大城镇设计案。

## 验证结果

## 剩余风险

- 当前近邻桥仍是 1 格宽最短路径，不可直接作为农业连续面的最终视觉结果。
- `road_seam / buffer / separate` 尚未进入 intent 契约，RoadWeaver 也尚未消费冻结 corridor。
- 游戏进程不会热加载本次 Java 代码；实机规划前需要重新构建并重启开发客户端或服务端。
