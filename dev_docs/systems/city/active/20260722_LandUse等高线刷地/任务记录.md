# LandUse 等高线刷地

## 目标

- 将刷地从用途枚举特例改为运行时可选算法：`UNIFORM` 批量铺单一方块，`CONTOUR_BANDS` 按地形等高线法向生成 `5 + 3 + 5` 农田与水槽带。
- 保持 LandUse 扩张、自动连接与刷地算法相互独立。

## 关键决策

- 本次 intent 冻结算法与材料，优先级为 group override > intent algorithm default > 内置 fallback。
- 等高线分类先在完整 area 上冻结全局 role spans，chunk 只裁切，不重算相位。
- 新算法直接生成方块 mask；当前代码与契约只保留 SurfacePrintPlan v0.2 的 `UNIFORM|CONTOUR_BANDS`。`CultivateLinedRecipe`、LandUse catalog / prefab / run、旧 active registry 和旧 ledger 兼容全部删除，旧任务状态必须清理后重规划；历史仅从 Git 追溯。

## 实现与文档

- 实现仓库新增等高线分类器，并更新 intent、SurfacePrintPlan、chunk compiler、worldgen registry 及测试；删除旧 SurfacePrintPlan recipe 与运行时迁移分支。activation preflight 只检查编译后实际包含 surface / boundary 操作的 owner，零写入区域和纯 grading context 不再阻断或记 ledger；contour boundary 只在 FIELD 生成，不覆盖 BANK / WATER / END_CAP。
- 文档仓库同步更新 City 产品方案、数据契约、代码导览、测试入口、影响面与导航。

## 验证

- 多轮定向算法与集成测试全部通过；覆盖粗格坐标、旋转坡面、鞍部、排除区相位、跨 chunk、WATER 四连通、闭环与 V 形拓扑，以及 intent / SurfacePrintPlan codec、planning、端点冻结、真实写入 owner 预检、channel-aware boundary、chunk executor / registry 与 HTTP plan / activate。
- 全量 `gradlew.bat cleanTest test --no-daemon`：64 个 suite、485 项测试全部通过，0 失败、0 错误、0 跳过，耗时 43 秒。
- `git diff --check` 通过，仅有换行格式提示，无空白错误。

## 风险

- 二维 WATER 已保证四连通；执行器仍逐格按真实 `surfaceY` 落块，水槽 Y 高度连续性需在未生成区块做 GameTest / 联调验收。
- 本轮移除了新水槽对 prefab/catalog 的依赖，但没有修改失败事务粒度；任一不可替换目标或写入失败仍会使整个 owner chunk 回滚，需继续按既有 bug 计划处理。
