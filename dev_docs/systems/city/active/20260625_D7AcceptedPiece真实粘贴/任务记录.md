# D7 accepted piece 真实粘贴任务记录

## 目标与边界

- 目标：推进 City D7+ bounded jigsaw true-run，从 `start_piece_adapter` 过渡到 `accepted_piece_template_paste`，只把 `BoundedJigsawPlan.pieces[]` / `acceptedPieces[]` 中通过 validator 的 pieces 写入世界。
- 边界：不改 D6；不全局 mixin 原版 jigsaw；不为外部结构注册 wrapper；fixed_footprint 仍完整放置或失败。
- 文档真值：同步到文档仓库 City v0.4 开发计划、README、数据契约、代码导览和测试入口。

## 关键决策

- true-run bounded 后端消费 solver trace 中的 accepted pieces，不再重新遍历 start pool 并在第一块成功后返回。
- paste 前先合并 accepted footprint 并做 chunk preflight；chunk 不足返回 waiting，不写真实 ledger。
- 每个 accepted piece 通过 `poolId`、`templateId`、`rotation`、`anchorBlock` 和 footprint 解析回真实 `StructurePoolElement`。
- 无法解析、解析歧义或 template paste 失败时写结构化 reasonCode，不伪装成功。
- `start_piece_adapter` 只作为旧过渡模式的 ledger 回归口径保留；`accepted_piece_template_paste` 可以把多条真实 accepted pieces 写入 `appliedPieces[]`。

## 重要修改

- `MinecraftStructurePlacementBackend`
  - bounded true-run 设置 `worldPasteMode=accepted_piece_template_paste`。
  - 新增 accepted piece 收集、footprint union、piece runtime resolver、paste status 标记和多 piece paste 流程。
  - 失败 reasonCode 增加解析失败、解析歧义、template paste 失败和 partial world mutation 口径。
- `CityStructureD6D7Test`
  - 新增 `d7BoundedJigsawAcceptedPiecePasteLedgerAppliesAllAcceptedPieces`。
  - 保留 `start_piece_adapter` 不把未 paste child piece 入账的回归测试。
- 文档仓库
  - 新增 v0.4 计划。
  - README / function_map / 数据契约 / 代码导览 / 测试入口同步 accepted piece paste 口径。
