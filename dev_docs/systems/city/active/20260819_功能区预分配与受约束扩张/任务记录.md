# 功能区预分配与受约束扩张

*需求入口*：`docs/systems/city/10_product/案子/City功能区预分配与受约束扩张-v0.1/README.md`；用户要求按案子开发。

*修改内容*：D4 编译前新增基于 D3 Patch 成员格的连通功能区容量预留；按最低/目标/上限面积计算道路预留，执行组间 12 格缓冲和 D3 terrain-field 采样过滤；普通建筑候选限定在预留域内，`BETWEEN_GROUPS` 延后处理。GroupExtentMap 改为预分配域包络，预览增加精确功能区预留格显示；同步 compile trace、GroupExtentMap 契约与测试。

*验证结果*：`./gradlew.bat test` 通过，全部 JVM 测试通过；`git diff --check` 通过。真实启动 `RTF0810` 后，复用既有 `rtf0810_medium_city_20260810_01 / city_rtf0810_platform_terrain_21` 调用正式 `city_compile_d4_blueprint`；调用有效但返回 `CITY_BLUEPRINT_GROUP_DISTRICT_CAPACITY_UNREACHABLE`（`admin_core` 到达 10 个功能区格，最低要求 11），随后正常停机。MCP callId：`60ebec3d-785e-4358-ad0e-d70a07e8516b`。
