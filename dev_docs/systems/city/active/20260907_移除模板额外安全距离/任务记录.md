# 移除模板额外安全距离

*需求入口*：用户要求原型和 Java 同步删除模板安全距离，确认这是过度设计。

*修改内容*：废弃 template clearance 的额外几何扩张，保留真实模板占地碰撞、入口与道路避让；兼容读取旧目录，不修改历史冻结产物或世界。

*验证结果*：Java 定向测试 `CityTemplateCatalogTest`、`CityStructureAnchor*Test`、`CityStructureArray*Test` 通过；原型 18 项几何测试和 Edge 浏览器交互回归通过。回归覆盖旧 clearance 被忽略、字段可省略、0 间距贴合且真实占地不重叠、间距动态变化及撤销重做。

*剩余问题*：未打包替换测试端 jar，未启动 Minecraft；不是关闭全部间距、软庭院或道路宽度配置。Java 建筑地块余量仍独立保留；历史冻结布局和已生成城市不自动重排。旧 clearance 字段仅保留读取与数据结构兼容，执行统一为 0。
