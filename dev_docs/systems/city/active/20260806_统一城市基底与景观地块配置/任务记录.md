# 统一城市基底与景观地块配置

## 目标

- 城市主体只生成一块连续的通用基础地板，不再由 LandUse 生成道路式连接线。
- RoadWeaver 成为建筑入口与城市道路的唯一权威，最后覆盖基础地板和景观冲突。
- 农田改为核心建筑与填充建筑驱动的独立 Parcel 组团，并保持逐块边界。
- 将基础地板、Parcel 数量、面积、间距、分叉、材料和等高线参数配置化。
- 提供农田、花田、绿化带和林场的可引用景观 Profile。

## 破坏性边界

- CityBlueprint 与引用目录升级，不兼容读取旧户外契约。
- SpatialGround 不再携带 LandUse rule 或 Surface recipe，不再产生入口、MST 或跨组关系线。
- 正式户外规划按基础地板与景观覆盖两个层级编译，不保留旧自动连接回退。

## 验收重点

- 城市基础地板只有一个连续主体，无法闭合时明确失败，不生成多个默认城镇。
- 基础地板内部无原群系残余，且没有道路形态的细长 LandUse 连接。
- required/core 农业建筑生成较大 Parcel 组团，fill 建筑生成较小 Parcel 组团。
- 每个 Parcel 保留独立边界，后续 Parcel 可从原建筑或已有 Parcel 分叉。
- RoadWeaver 仍在最后阶段拥有覆盖和清障权。
- 新增 Profile 与全部形状/材料参数进入冻结 catalog snapshot。
