# 结构标签检索接口

## 目标

为 City 设计阶段增加只读结构检索：按 TerraSense canonical term、冻结词表中文标签或 alias 查询已导入的 `StructureProfile.jsonl` / debug catalog，不进入 D4-D7 或世界写入。

## 实现

- HTTP：`POST /realm/city/query_structure_catalog`
- MCP：`city_query_structure_catalog`
- 条件：`allOfTerms[]`、`anyOfTerms[]`、`excludeTerms[]`、`limit`
- 词表：仅消费 `terrasenseProfileSource.vocabularySnapshotPath` 指向的冻结快照；未知和歧义 term 明确失败，不回退旧 C3.5 或 City 语义表。
- 输出：结构 ID、命中 canonical terms、完整 terms、footprint / rotations 等硬事实、画像来源和已有质量 terms。

## 限制

- 正式 source 应显式带 `vocabularySnapshotPath`；缺失时仍能按 catalog 中存在的 canonical termId 查询，但不能解析中文 display label / alias。
- debug catalog 仍可能含未审核画像；响应保留 `catalogMode` 和 `qualityTerms`，调用方不可将 debug 结果当作正式筛选结论。

## 验证

- `./gradlew.bat test`：通过。
- `country_designer_mcp` 的 `npm run build`：通过。
- `CityPlanningEndpointHandlerTest` 覆盖词表中文 label / alias、canonical term、AND / OR / exclude、未知 term hard fail 与只读响应字段。
