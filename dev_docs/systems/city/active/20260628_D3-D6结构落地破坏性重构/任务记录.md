# 2026-06-28 D3-D6 结构落地破坏性重构任务记录

## 范围

本轮按用户确认的破坏性重构方案推进 City active path：

```text
D3 地形 patch 真值
  -> D4 StructureAnchorPlan
  -> D5 reservation mask / feature 抑制
  -> D6 configured structure dry-run bbox 校验
  -> city_execute_d7 true-run materialization
```

不兼容旧 FunctionZone / BuildableArea / PlannedFixedPlacement / StructurePool 主链。

## 实现要点

- 新增 `CityStructureProfileCatalog`，导入 TerraSense `StructureProfile.jsonl` / debug catalog，拒绝 compat catalog 和旧 `functionTags` / `function_candidates` 字段。
- 新增 `CityStructureAnchorPlanner`，校验 anchor 在 D3 patch / grid 内，计算 fixed / jigsaw `reservedEnvelope`，并做 envelope 防撞。
- 新增 `CityReservationMaskPlanner`，生成 `reservation_mask_plan.json`、`road_access_plan.json`、`build_operation_plan.json`。
- 新增 `CityReservationMaskRegistry` 与两个 mixin hook：
  - `ConfiguredFeature.place` 抑制 mask 内植被 feature。
  - `ChunkGenerator.tryGenerateStructure` 抑制 mask 内原版自然结构抢占。
- 新增 `CityStructureMaterializationPlanner` 与 `MinecraftCityStructureMaterializationBackend`：
  - D6 dry-run 生成 `StructureStart` bbox / piece boxes / `startSignature`，不写世界。
  - true-run 重新生成后校验 `startSignature`，再用同一个 in-memory `StructureStart.placeInChunk` 落地。
  - `executeStructurePlacement=false` 不写真实 ledger。
- 新增 `CityStructureLandingPreviewRenderer`，输出 D4/D5/D6/D7 新主链预览图。
- 替换 HTTP / MCP active endpoint：
  - `city_plan_d4` required `terrasenseProfileSource` + `structureAnchorPlan`。
  - `city_plan_d5` 读取 `structure_anchor_map.json`。
  - `city_execute_d5` 激活 mask registry。
  - `city_plan_d6` 读取 D4/D5，不再收结构选择 payload。
  - `city_execute_d7` 保留入口名但执行 D6 true-run。
- 旧字段 / 旧 artifact 进入 active endpoint 时返回 `LEGACY_CITY_FUNCTION_ZONE_FLOW_REMOVED`。

## 2026-06-28 时序修复：Late Paste -> Worldgen-Time Placement

触发原因：

- 真实游玩目视发现 village street / 屋顶部分方块贴到树上，符合“树先生成、结构后 paste”的表现。

实现调整：

- `CityReservationMaskRegistry` 扩展为 active mask + planned structure registry + worldgen placement ledger。
  - `city_execute_d5` 写 server-root `geomantia_city_masks/active_planned_structure_registry.json`。

- `ChunkGeneratorStructureMaskMixin` 新增 `createStructures` TAIL 注入，调用 `MinecraftCityWorldgenStructurePlacer`。

## 2026-06-29 D6 锁形态与 D7 真实边界道路

目标：

- D4 只负责 anchor / envelope 候选，不再让 dominant bbox group 直接决定最终落地形态。

- D5 execute 必须读取 D6 locked plan 后才能激活 active mask / planned registry。
- D7 不再使用 D5 预先猜出的道路，等 worldgen ledger 完整后按真实 `actualFootprint` 生成道路 / 边界。

- `MinecraftCityWorldgenStructurePlacer` 在 worldgen 阶段校验 expected signature、D6 locked envelope 和 ledger overlap 后再记录成功 ledger。
- `city_execute_d7` 在 ledger 完整后构造基于真实 footprint 的道路后处理计划，输出 `roadPostprocessSource=worldgen_ledger_actual_footprint`、`roadAvoidanceMarginBlocks=3`、`boundarySource=actual_footprint_union`。
