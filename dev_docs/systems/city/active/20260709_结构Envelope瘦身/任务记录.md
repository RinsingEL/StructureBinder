# 结构 Envelope 瘦身任务记录

## 背景

本记录对应 `结构Envelope瘦身-v0.1` 的分步推进。当前已完成范围需要收敛表述：本轮只完成 `01_Envelope瘦身` 主体收尾；`04_D4阵列形态` 仅有部分工作区实现和测试探索，不能视为完整案子完成，也不纳入本次 01 收尾提交口径。

`01_Envelope瘦身` 的目标是将 D4/D5/D6 结构 envelope 口径从旧 safety / 大 mask 语义收敛为：

- D4 结构硬防撞只使用 `collisionEnvelope` / body envelope。
- `safetyEnvelope` 仅保留 JSON、预览和诊断信息。
- `maskEnvelope` 从 `collisionEnvelope + maskMarginBlocks` 派生，默认 8 blocks，用于 D5/D6 衔接。

## 实现仓库改动

- `CityStructureCandidateEnvelope` / `CityStructureAnchorPlanner`：新增默认 `maskMarginBlocks=8`，mask 从 collision 派生；旧 `vegetationMarginBlocks` 保留为兼容/输出字段，不参与 D4 硬防撞。
- `CityReservationMaskPlanner`：D5 预案忽略旧 D4 `maskEnvelope`，改用 `collisionEnvelope + maskMarginBlocks` 生成 noVegetation / noVanillaStructure mask。
- `CityStructureMaterializationPlanner`：D6 locked plan 的 `maskEnvelope` 改由 `lockedCollisionEnvelope + task.maskMarginBlocks` 派生，继承 D4 anchor / task 的 5-10 block 小边距配置。
- `CityStructureLandingPreviewRenderer`：红色冲突判定改为 collision envelope；safety 仅淡色诊断。
- `country_designer_mcp/src/realm/tools.ts`：更新 D4 / D4 candidate selection 描述，明确非固定结构走 P95 collision，mask 由 collision + maskMargin 派生。
