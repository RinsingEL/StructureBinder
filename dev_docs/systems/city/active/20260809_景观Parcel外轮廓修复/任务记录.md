# 景观 Parcel 外轮廓修复

## 目标与边界

- 修复正式 Blueprint Landscape Parcel 外轮廓在等成本地形上近似固定圆/菱形、并普遍长满 `maxAreaBlocks` 的问题。
- 只改变正式 `FOUNDATION + LANDSCAPE` 分层路径的 Landscape 外壳扩张；不改变 Foundation、Parcel 内区域接力、SurfacePrint、RoadWeaver 或 legacy/debug STANDARD 扩张。
- 保留 core 共同竞争、optional 对冻结 claims 逐个准入，以及既有最小可执行面积失败口径。

## 当前计划

1. 新增 Landscape 专用逐格 frontier 外壳扩张器，以 `preferredAreaBlocks` 为正常停止目标、`maxAreaBlocks` 为硬上限。
2. 用地形代价、局部聚合、稳定多尺度噪声和方向关系共同排序 frontier，保持确定性并打破固定距离场轮廓。
3. 增加专用算法与正式路径集成回归。
4. 同步产品案、数据契约、代码导览、测试入口、影响面和当前故障案。

## 关键决策

- `StableLandUseExpander` 保持 legacy/debug 行为；正式 Landscape 使用独立实现，避免改变 STANDARD group 的自动连接与旧调试语义。
- 可用空间足够时 Parcel 精确达到 `preferredAreaBlocks` 后停止；受地形、边界、结构、竞争或 action budget 阻断时允许停在 `min..preferred`，低于最小值仍沿用 required hard fail / optional 零占地 skip。
- 外轮廓必须保持四邻接单源生长，不使用圆、菱形、矩形、bbox 或固定 mask 作为生成或兜底。

## 重要修改

- 新增 `LandscapeParcelExpander`，严格只接受 `LayerRole.LANDSCAPE`，每个 GrowthRegion 要求唯一根 seed。
- 正式分层 `LandUsePlanningService.expandPrioritizedLandscapes` 改用专用扩张器；required 共同竞争、optional 顺序准入与最小可执行面积口径保持不变。
- 新扩张器以完成比例公平调度多个 frontier；候选得分综合局部地形成本、同 Parcel 邻接数、稳定双尺度 value noise、稳定方向漂移和 growth bias，并继续尊重结构 footprint、reserved claims、规划边界、可通行阈值和 action budget。
- 新增 `LandscapeParcelExpanderTest`，并在 `CityOutdoorBlueprintCompilerTest` 正式分层集成场景锁定 `claimedAreaBlocks == preferredAreaBlocks`。
- 文档仓库已同步产品案、`CityLandUseAreaPlan` 数据契约、代码导览、测试入口、影响面和当前故障案；用户此前新增的 AI 组合 / `contentWeights` 功能缺口报告保持不变。
- 实现仓库故障索引新增 `CITY-DL-20260809-01`，保留真实 run 的 max 命中数据作为回归证据。
