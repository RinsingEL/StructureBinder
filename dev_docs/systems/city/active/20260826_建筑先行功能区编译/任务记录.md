# 建筑先行功能区编译

*需求入口*：`City单次递归蓝图与自愈编译-v0.1`；用户最新原话要求“所有的区域本来就应该是由建筑形成的”“优先建筑再管功能区面积”，并再次强调必须严格按本案继续开发。

*修改内容*：已删除正式 Blueprint 路径的 `CityDistrictCapacityPlanner` 和全部预留格候选裁剪；required 与第一批填充建筑先按显式 Patch、阵列关系、真实地形和占用落位。显式 Patch 现在只锁定首个核心起点，首栋成功后同一 required/fill 阵列可连续跨越相邻 Patch 标签，禁止搬家只禁止整组改投其他起点。景观容量规划移到第一批建筑之后，并与建筑候选搜索解耦，不再因景观容量结果反向重选建筑。按占比扩张时，建筑只补 `buildingShare`，Landscape 只补 `landscapeShare`；实际 Landscape reservation spans 与建筑 collision envelope 共同形成 `functionArea`。D4 总览及逐功能区局部图以独立半透明颜色和虚线边界绘制精确 `formationSpans`，终审失败也绘制失败尝试位置。COMPACT 删除正弦长轴，改为围绕真实首栋逐圈八方向找位，同圈换角优先于扩大半径；巷道按可达最近节点连接。LINEAR 精确槽位改为单 pivot、有序落点：理论点失败才微调，首个合法即停止；模板只检查当前街道前沿附近两个槽位。失败预览按世界坐标聚合模板和原因。

*验证结果*：Patch 起点/跨界生长与功能区半透明渲染新增聚焦回归，编译器和渲染器共 49 项通过；本轮 LINEAR 单候选/前沿搜索与失败位置聚合新增聚焦测试，并再次完成 `gradlew test` 全量通过。新增用例证明首栋仍来源于选定 `patch:plain:1`，第二栋可沿同一 COMPACT 阵列落到相邻 `patch:plain:2`，并记录 `continuous_growth_from_selected_patch`。最新真实同案重编质量 100：行政 8、农业 3、商业 4；商业 selection `82→10`、失败记录 `122096→18`、唯一失败坐标 `85→6`、trace `63991603→348954` bytes，耗时 33.844 秒。

*剩余问题*：本轮 Patch 起点、三区功能区范围、COMPACT 换角和 LINEAR 候选膨胀均已完成自动与真实同案复验；无本任务内已知未修问题。
