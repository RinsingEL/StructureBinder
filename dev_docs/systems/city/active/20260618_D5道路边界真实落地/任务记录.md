- 构建层新增 Curse Maven 与 WorldEdit 依赖，`mods.toml` 增加 mandatory `worldedit` 前置。
- D5 模型新增 `RoadIntent`、`BoundaryIntent`、`BuildOperationPlan`、`WorldMutationReport`。
- `CityRoadBoundaryPlanner` 会选择核心区和入口，生成确定性 L 型主路、功能区接入路、边界 / 缓冲区意图和操作计划。

- HTTP/MCP 新增 `plan_d5` / `execute_d5`；执行入口要求 `confirmWorldMutation=true`、已存在 D5 plan、已加载 `ServerLevel`。

## 风险与后续

- 首版道路算法是确定性折线，不做 A* 或避障。
- 小模板缺失只 skipped + warning，不阻断道路 / 缓冲区。
- 首版不提供持久化 rollback；后续接 WorldEdit history 或 mutation journal。
- D5 只落地道路、边界、缓冲区和小型基础设施模板，不进入 D6 结构池或 jigsaw / prefab 功能建筑。
