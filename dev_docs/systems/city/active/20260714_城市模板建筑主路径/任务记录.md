# 城市模板建筑主路径 v0.1 任务记录

## 任务范围

- 将 City 固定建筑的规划真值从 configured structure / `StructureStart` / Jigsaw 迁移到 `StructureTemplate` NBT。
- 以模板真实尺寸、rotation、mirror、template hash 和 transformed road entrances 贯通 D4-D7。
- D5 道路连接使用 RoadWeaver mod 接口；缺 mod 时沿用 auto 跳过、roadweaver hard fail、显式 worldedit_debug 才允许旧调试道路。

## 本轮实现

- 新增模板目录、确定性变体选择和旋转 / 镜像几何：`CityTemplateCatalog`、`CityTemplateCatalogLoader`、`CityTemplatePlacementGeometry`。
- 新增 `MinecraftCityTemplateReader`，通过 `StructureTemplateManager` 读取模板并使用 `StructureTemplate.getSize()`。
- D6/D7 `CityStructureMaterializationPlanner` 增加 template identity、footprint、hash drift 和无 StructureStart preflight 分支。
- D4 `CityStructureAnchorPlanner` 增加完整模板 placement 分支，使用 template footprint 派生 collision/mask，不进入 TerraSense envelope/Jigsaw fallback。
- `CityRoadWeaverBridge` 改为消费 transformed `roadEntrances[]`，不再从 bbox 伪造入口，并增加注册预校验和 partial registration 报告。
- 新增模板 fragment placer，并把模板 owner-chunk 写入挂到 `applyBiomeDecoration`；旧 StructureStart 注入分支跳过模板计划。
- 双仓库同步模板专项方案、数据契约、代码导览和测试入口。

## 验证

- 通过模板 catalog、template reader、template worldgen placer 专项测试。
- 通过 City D6/D7 结构落地回归测试。
- 通过 RoadWeaver transformed entrance、缺失模板入口和 provider hard-fail 测试。
- `git diff --check` 通过。
- City 全量定向回归中已有装饰测试 `handlePlanCityDressingWritesV02ArtifactsAndAvoidsHardObstacles` 在 planned road corridor 断言处失败；该失败落在本轮之前已有的装饰改动范围，未归因于模板主链。

- 现有历史 StructureStart/Jigsaw 类和测试保留为兼容 / 历史保护，必须继续禁止 active template endpoint 调用。
- 尚未执行新存档的 Forge + RoadWeaver 实机验收。
