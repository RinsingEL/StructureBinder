# 城市建筑空间与地表重构

## 目标

- 用建筑组团关系和城市层次取代逐建筑 LandUse 占地。
- 城市内部形成连续的共享空间与地表，不再把原群系残余当成默认设计结果。
- 农业等景观以完整庄园/片区组织，仅在有明确空间意义的外缘生成边界。
- Blueprint 一次给出全部语义；程序根据 D4/D6 几何生成最终空间。

## 破坏性边界

- `CityBlueprint` 升级为 `city_blueprint.v0.6`。
- 删除正式契约中的 `structureGrounds`、逐组生长参数和 `residualPolicy`。
- 新增 `spatialGrounds`，用共享空间类型和层级表达城市空间。
- 不提供 v0.5 兼容读取或回退链路。

## 验收重点

- 入口、组团、城市主脉在同一空间网络中可达。
- 城市包络内部不存在未解释的原群系地表。
- 城市共享空间不生成逐建筑围栏或矮墙。
- 农业景观覆盖各附属建筑并只形成片区外边界。

## 完成情况

- Blueprint 已升级为 v0.6，Codec/Validator/fixture 全部切换到 `spatialGrounds`。
- SpatialGround 已使用建筑入口、组内最小连接树和 Group 关系生成共享空间 seed。
- 城市 SpatialGround 强制 `boundaryPolicy=OPEN`，不再继承 civic/residential 的矮墙或树篱。
- 城市包络 residual 固定吸收；旧 growth max 不再触发自然地表回退。
- 正式 `city_plan_land_use` 要求已接受 Blueprint，拒绝请求级旧 intent 和无 Blueprint fallback。
- 户外意图升级为 v0.2，planning completion 升级为 v0.3。
- 产品方案、Blueprint 契约、AreaPlan 契约、代码导览、测试入口和影响面已同步。
