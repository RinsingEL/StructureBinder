# 建筑群生活感设计

## 本轮范围

- 继续使用现有 D4 阵列点位和 LandUse，不新增功能区协议。
- 增加模板自动朝向和农业、商业、行政类默认装饰。
- 首个实机样本选临河 / 海、带平缓陆地的区域；只使用 D3 已有水体、岸线、平原与坡度事实。
- 不修改 RoadWeaver、GIS 核心、旧 FunctionZone，也不做全城全局优化。

## 实现结果

- 阵列项支持 `orientationPolicy`。未显式给 rotation 的模板在原候选点枚举目录允许旋转，可朝阵列中心、最近水体或 cardinal 方向；最终 item、anchor 和 trace 写 `orientationDecision`。
- 后续规划的 `geomantia:` 城市模板在目录模型与 D6 统一冻结为 `structure_start_beard_thin`；D5/worldgen 仍只消费冻结值，当前已生成样城不迁移。
- 默认 Decoration catalog 增加农业生产、商业交易 / 物流、行政公共设施内容，并补充相应聚合语义映射。
- 农业、商业、行政的主次关系继续由现有阵列分组、执行顺序、patch 选择和 D6 后 LandUse 表达，不另建 schema。
- LandUse 栅栏边界不再写入默认断开状态：落地前按现场邻居求 BlockState，写入与回滚都触发原版邻居更新；Decoration NBT 的 `StructureTemplate` 路径原本已具备内部和边缘状态刷新，无需重复修改。
- 新默认 LandUse palette 为 PAVE 增加 `MICRO_FILL_SUBGRADE=minecraft:dirt`。owner fragment v0.2 携带同 area 只读 halo，只把 1..3 格深、面积不超过 16 且跨度不超过 4x4 的封闭小坑补到 7x7 局部中位高度，再铺原 PAVE 表层；深坑、长沟、跨 mask 低洼和水边保持原地形。旧 active palette 没有保留键时关闭，不迁移。

## 验收边界

- 自动测试覆盖朝向排序、显式 rotation 优先、最近水体目标、阵列碰撞与默认装饰目录加载。
- 实机临水样本仍需从当前 NBT 素材建立包含农业和行政建筑的固定模板 catalog，之后才能完成完整截图验收。
- 已存在的运行时 Decoration 配置不会被 bootstrap 覆盖；要使用新增默认内容需显式迁移或在新配置目录验证。
