# 农田 Catalog 与冻结容量传递修复

*需求入口*：真实城市 D7 验收时，农业区只有大面积石砖地板、没有任何农田；用户要求先定位并修复 Bug，修复后继续复用当前地块验证大片田地。

*根因*：本次冻结 Blueprint 将 `FARMLAND` 景观错误绑定到 `urban_core / PAVE` LandUse 规则与 `stone / stone_bricks` SurfaceRecipe，Reference Catalog 只校验引用存在，没有校验景观类型与地表语义是否相容，因而错误配置合法通过。另有独立阶段传递缺陷：D4 已为四块 required 农田各冻结 3864 格容量，Outdoor 编译却重新随机生成 `preferredAreaBlocks`，实际只要求 873/932/396/174 格；父块未生长到 D4 冻结的子块接力界面后，LandUse 又把 required 子块级联移除并只写警告，最终只剩一块 873 格石砖面。修正上述路径后，真实 3864 格 Parcel 又暴露两项规模问题：`RelayRegionGrowthClassifier` 用递归 Tarjan DFS 求割点，直接触发 `StackOverflowError`；Foundation 的闭合半径搜索反复以对象 Set 做 16/128/二分半径的膨胀腐蚀，且 `BlockPoint` 默认 `31*x+z` 哈希会把规则网格压成对角碰撞带，真实规划约需 140 秒并可能超过 HTTP 120 秒超时。

*修改内容*：Reference Catalog 现在要求 `FARMLAND` 必须引用 `CULTIVATE` 规则和启用且带作物材质的 SurfaceRecipe，`urban_core + stone` 在 Blueprint prepare 阶段即拒绝。D4 容量一旦冻结，D6/LandUse 的最小、首选、最大面积全部等于该 Parcel 的真实冻结格数，不再二次随机缩水；required Landscape 接力失败直接终止规划，不再删除后代并降级成警告。Parcel 接力的自然一格路隙与 D4 口径对齐：只有 `GROUND_PATH / GROUND + CORRIDOR` 触发，路隙允许位于两个冻结 Parcel 之外且保持不认领；灌溉沟岸 `BANK` 不再误触发田间路。割点计算改为显式栈迭代 Tarjan，避免面积增长转化为 Java 调用栈深度。`BlockPoint` 使用完整二维坐标混合哈希；Foundation 的曼哈顿闭合改为仅覆盖局部工作包围盒的布尔栅格形态学，保留原边界与二分半径语义。大坐标 claim 快照使用只读 `LinkedHashMap`，避免 `Map.copyOf` 的开放寻址在碰撞数据上退化。

*自动验证*：新增回归覆盖 `FARMLAND + PAVE` Catalog 拒绝、冻结容量三值完全相等、全部 required Parcel 均保留、D4 外一格自然路隙、required skip 不再出现、3968 格 Relay 分类不爆栈、5.5 万格 claim 快照，以及城市尺度规则网格哈希分布。最终全量 `gradlew test` 共 102 suites、776 tests，0 failure/error/skip。

*真实规划验证*：`realm_w_mte38ltl_f1964c5a / city_realm_green_court_2_capital` 已按正常 Blueprint → D5 → D6 → LandUse 流程重编。质量报告 `pass`、`skippedRequiredParcelCount=0`、warnings 为空；四块 Agriculture Area 均精确认领 3864 格并使用 `CULTIVATE / minecraft:farmland / minecraft:wheat`，内部 `GROUND_PATH` 使用 `minecraft:dirt_path`。优化前后 AreaPlan hash 均为 `7a4507f74ae9381e91ff2e541d648c62efa9813399f640dbac09fa4435ecf11c`，证明性能改动未改变几何；同请求由约 140 秒/120 秒超时降为 38.47 秒（另次 41.62 秒）。

*真实 D7 边界*：旧石砖已经落入存档。正常 D5 对新计划返回 `CITY_LAND_USE_CHUNK_ALREADY_AT_FEATURES`，303/303 owner chunk 均已越过首次 FEATURES，属于正确的首次 worldgen 拦截，不能把当前规划冒充新区块验收。复用同一地块前需离线精确重置目标 chunk 及其城市 registry/ledger，或改用新区块；本任务未擅自删除存档。
