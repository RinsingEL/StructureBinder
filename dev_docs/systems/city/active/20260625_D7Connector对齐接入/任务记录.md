# 20260625 D7 Connector 对齐接入

## 目标

- 在已完成子 pool discovery 的基础上，推进 D7+ bounded jigsaw 到 child piece connector 对齐切片。
- 当前切片只负责把 child pool prototype 按父 connector 对齐为可校验 solver candidate，不负责真实多 piece paste。

## 真值入口

- `docs/00_nav/地貌驱动主线Workflow.md`
- `docs/systems/city/10_product/开发计划-v0.3-D7计划驱动Jigsaw拓展.md`
- `docs/systems/city/20_contracts/数据契约/城市规划数据契约.md`
- `docs/systems/city/40_tests/测试入口.md`

## 实施结果

- 新增 `BoundedJigsawConnectorAligner`，根据父 connector 的前方 block 和 child compatible connector 计算 anchor / footprint / connector worldBlock 平移。
- `BoundedJigsawSolver` 在展开 child pool prototype 时按当前 branch connector 执行对齐；对齐失败写 `JIGSAW_CONNECTOR_ALIGNMENT_FAILED`。
- consumed parent connector 会标记 `consumedByParent=true`，避免 solver 反向继续展开。
- `BoundedJigsawPoolAdapter` 读取 child pool 时生成四个 rotation 的候选 prototype，便于 solver 找到可对齐方向。

## 剩余风险

- 当前对齐切片按 RIGID / 同高几何平移处理，尚未复刻原版 terrain adaptation / projection 高度逻辑。
- 多 piece paste 后端仍未实现；真实世界写入仍需要后续 P6 切片。
