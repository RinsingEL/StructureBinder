# RoadWeaver / 地形诊断 / 城墙闭环任务记录

## 任务范围

本轮在 City D3-D7 结构落地主线后接入三块 v0.1 能力：

- RoadWeaver optional adapter：D5 execute 阶段根据 D6 locked footprint 注册道路端点和连接。
- Terrain adaptation / Beardifier 诊断：D7 trace 汇总每个 placed structure 的 terrain adaptation 观察状态。
- CityWalls：D7 ledger 后基于真实 actualFootprint union 生成临时城墙 plan、preview、NBT 模板并支持 vanilla setBlock 执行。

文档真值同步到 `E:\Mod_Dev\designer_territoryMod\docs\systems\city\`。

## 外部依赖结论

- RoadWeaver 支持 Forge 1.20.1。
- `maven.modrinth:roadweaver:2.2.2-1.20.1` 会解析到 Fabric 包，不适合 Forge dev runtime。
- 当前开发依赖使用 Modrinth Forge 文件直链下载到 `libs/local/roadweaver/`，并校验 jar 内必须存在 `META-INF/mods.toml`。
- RoadWeaver Forge 包的嵌入依赖在 userdev 下仍需显式补 `architectury-forge` 与 `cloth-config-forge` 的 deobf runtime 依赖，否则会在 mixin / Architectury 注入阶段失败。
- RoadWeaver API 以反射调用，避免缺 mod 时类加载失败。
- RoadWeaver 道路不能可靠补进已生成 chunk，因此注册点放在 `city_execute_d5`，早于目标 chunk 首次生成。

## 实现要点

- Gradle 增加 `geomantiaDevUseRoadWeaver=false` 开关和 `downloadDevRoadWeaverForge` 下载校验任务。
- `mods.toml` 将 RoadWeaver 标为 optional。
- `CityRoadWeaverBridge` 生成 `roadweaver_connection_plan.json`，并调用 `RoadNetworkApi.registerStructureEndpoint` / `ensureConnection(..., false)`。
- `city_execute_d5` 新增 `roadProvider=auto|roadweaver|worldedit_debug|none`。
- `city_execute_d7` 在 RoadWeaver registered 时跳过 WorldEdit debug road fallback，并输出 `terrainAdaptationReport`。
- `CityWallPlanner` / `CityWallTemplateLibrary` / `CityWallPlacementBackend` / `CityWallPreviewRenderer` 实现临时城墙闭环。
- 城墙 NBT artifact 为 vanilla structure-template 风格压缩 NBT；当前执行后端仍为 `vanilla_setblock`。

## v0.2 增量：D3 patch 贴边墙带 + RoadWeaver 裁门

- `city_plan_d5` 默认 `wallVersion=v2`，新增 `CityWallReservationPlanner`，从 D3 patch、D4 source patches 和 D6 locked plan 生成非矩形 `wall_reservation_plan.json`。
- `wallCorridorMask` 会合入 `noVegetationMask`、`vegetationLimitedMask`、`noVanillaStructureMask`，用于生成期抑制墙带植被和自然结构抢占。
- `city_plan_city_walls` 默认读取 D5 wall reservation、D7 placed ledger 和世界实际方块，新增 `CityRoadMaskScanner` 产出 `actual_road_mask.json`。
- `CityWallPlanner.planV2` 会在 wall-road intersection 处生成 `WALL_GATE_FROM_ROAD` gate；道路贴墙时生成 skip reason，避免墙体覆盖 RoadWeaver 道路。
- `CityWallPlacementBackend` 执行时保护 actual road mask、gate gap 和 structure actual footprint；墙段按最高地面作为基准，对低洼处补 foundation。
- `CityWallPreviewRenderer` 现在能分别预览 wall reservation corridor 和最终 city wall plan，并显示 actual road mask。

## 已知风险

- Terrain adaptation v0.1 目前是诊断聚合，不是完整 Beardifier observation hook；trace 会明确 `CITY_TERRAIN_ADAPTATION_HOOK_UNAVAILABLE` 或 not applied。
- RoadWeaver adapter 的真实道路质量需要在启用 RoadWeaver 的新存档中验收。
- CityWalls v0.2 已使用 D3 patch 外缘和 actual road mask，但首版 patch 贴边仍是粗粒度 memberCells / patch bounds 外缘；真实视觉效果需要新存档验收。
- actual road mask 首版使用方块白名单扫描，不读取 RoadWeaver 内部 graph；道路材质变化时可能需要补白名单。
- 城墙执行为 setBlock 几何后端，后续可切换到 `StructureTemplate.placeInWorld`。
