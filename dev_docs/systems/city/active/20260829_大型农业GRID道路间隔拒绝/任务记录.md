# 大型农业 GRID 道路间隔拒绝

*需求入口*：用户要求换到更大的新区块，真实测试大片田地，并把农业区做大。

*修改内容*：在 GRID 建筑候选提交前按实际 collision 与逻辑行列联合预留连续街巷净空；为同一地块提供四个 1 格微调点，冲突候选在提交前留空并继续后续槽。最终区内路只为实际占用的相邻行列生成，覆盖实际 GRID 范围以保持交叉连通；旧非法 gap 降级跳过，不再抛异常。同步更新当前产品案、City 入口、代码导览与测试入口。

*验证结果*：GRID 预留、区内路、布局器与编译器聚焦回归通过；全量 `gradlew test` 通过。复用 `realm_w_mte38ltl_f1964c5a / city_realm_green_court_2_capital` 的已接受 Blueprint 真实复编，最终 `ok=true`，农业 25 个 anchor、初始 GRID 12 个、8 条街巷连通，最大格点误差 1，road/body overlap 0，原 `CITY_INTERNAL_STREET_WIDTH_EXCEEDS_COLLISION_GAP` 不再出现。D4 预览与正式 artifacts 已生成；未进入 D5/D7。

*剩余问题*：同一 Blueprint 仍有行政 required 缺失、COURTYARD 不完整及农业—商业连接受地形阻断 warning，均不是本 GRID 道路净空故障；后续按各自问题处理。

*后续口径*：2026-08-30 用户确认田野内部不应使用城市 GRID 道路。本记录中的 8 条连通街巷继续证明普通城市 GRID 修复有效，但该农业组现已由 `功能区景观归属与农业田埂` 接管为 `LANDSCAPE_GAPS`，最新真实 D4 中农业正式区内路为 0。
