# D3 Patch 群系摘要任务记录

## 背景

用户确认 Plan 阶段 patch 首版只补群系信息，不补温度信息。理由是城市规划语义更需要 Minecraft biome，温度在当前结构落地 Plan 阶段暂时没有直接决策价值，且 Minecraft 群系本身已经承载了环境结果语义。

## 本轮实现

- 新增 `BiomeSummary` 领域模型，表达 patch 级群系摘要。
- `LandformPatchSummary` 增加 `biomeSummary` 字段，并保留旧构造入口兼容既有调用。
- `CityLandformReviewBuilder` 从 AtlasRegion cell 的 `biomeId` 聚合 patch 级群系直方图，生成 `dominantBiome`、`biomeHistogram`、`mixedBiome`、`sampledCellCount`。
- `CityLandformReviewPackage` 的 JSON 输出/读取补充 `landformPatches[].biomeSummary`，缺省旧 artifact 时回落为空摘要。
- `CityLandformReviewBuilderTest` 补充群系聚合和 JSON roundtrip 断言。

## 明确不做

- 不在 D3 patch artifact 中输出温度字段。
- 不改变 D4/D5/D6/D7 的主链准入逻辑。
- 不把群系摘要作为强约束；当前只是 Plan 阶段可读环境语义。

## 文档同步

- City README 登记 D3 patch 输出含群系摘要。
- `结构落地交接契约.md` 补充 `biomeSummary` 字段契约，并说明不输出温度。
- `代码导览.md` 补充 builder 和 artifact 映射。
- `测试入口.md` 补充群系摘要验收项。

- 实现仓库和文档仓库均执行 `git diff --check`，仅有既有 LF/CRLF 提示。

## 风险

- 旧 D3 artifact 没有 `biomeSummary` 时会被读取为空摘要，兼容性风险低。
- 如果上游 AtlasRegion cell 没有可靠 `biomeId`，输出会是 `unknown` 空摘要；后续可在采样链路补齐 biome 来源。
