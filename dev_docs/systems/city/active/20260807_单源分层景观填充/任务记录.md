# 单源分层景观填充

## 目标

- CityBlueprint 允许 AI 从冻结目录选择一个或多个景观填充方案，并提交方案选择权重、面积角色占比和内容权重。
- 引用目录向 AI 提供严格字段、合法范围和可直接参考的填充示例。
- 景观 Parcel 在实际面域冻结后，以稳定单源增长顺序生成连续角色层，不再把固定 `5+3+5` 当作唯一农田表达。
- 保持 SurfacePrint 全局冻结、owner chunk 裁切执行、跨 chunk 不重算和 owner 事务回滚语义。

## 本轮边界

- 首个完整执行切片为 `SINGLE_SOURCE_LAYERS`。
- 农田支持以 `CULTIVATED` 为主角色，并以 `BANK/WATER/BANK` 或其他白名单角色作为间隔。
- 花田与其他景观先进入同一 Blueprint / catalog 契约和示例能力；复杂聚类噪声、树木 feature 散布和林间路网不在本轮伪装为已完成。
- 旧 Blueprint、reference catalog、SurfacePrintPlan 和运行期 active artifact 不迁移，升级后必须完整重规划。

## 成功标准

- 固定 Blueprint、catalog、D3、D6 与 generation seed 得到相同方案选择、角色 spans 和 plan hash。
- 每个填充方案的角色占比严格命中目录白名单与范围，主角色必须存在，权重和占比非法时 hard fail。
- 单源角色 spans 精确覆盖 Parcel member mask 扣除 exclusions，无重叠、无 chunk 相位重启。
- 预览能够区分不同角色，并报告目标占比、实际占比和所选示例 / profile。
- Java / Node 契约、分类器、SurfacePrint 与 chunk compiler 专项测试通过，并完成全量回归。

- 已完成实现仓库与文档仓库联动更新，并通过 Java / MCP 全量测试及专项预览导出。

## 实现结果

- `SingleSourceLayeredFillClassifier` 以精确 member mask 扣除 exclusions，使用稳定八邻域距离从合法单源扩张；断开分量也会被完整覆盖，输出压缩 role spans。
- `CityOutdoorBlueprintCompiler` 对每块景观 Parcel 使用 Blueprint seed、Parcel 与 fill profile 派生稳定 seed，并按 AI 方案权重选择 fill profile。
- `CityLandUseSurfacePrintPlanner` 根据 Parcel 实际可用面积和角色目标占比分配 10..32 格的非固定重复周期，冻结 effective source、layer bands、role definitions、content weights 与全局 spans。
- `CityLandUseChunkCompiler` 按 `PRIMARY_CONTENT | BANK | WATER | GROUND` 映射 surface、crop、bank overlay 和 water；跨 chunk 只裁切冻结 spans，不重启算法。
- `CityLandUsePreviewRenderer` 使用 SurfacePrintPlan 叠加真实角色色层，并逐块报告所选 fill profile、目标占比、实际块数和实际占比；正式 Blueprint endpoint 已传入该 plan。
- Blueprint reference catalog 要求每个 fill profile 提供完整 AI 示例，示例同时受到角色、占比、内容白名单和类型兼容校验。
- 现用本地 `run/config/.../blueprint_reference_catalog.json` 已迁移到 v0.5：农田提供灌溉 / 旱地两种方案，花田、绿地、林场各提供一种；目录暴露的每种 LandscapeType 必须至少有一个兼容 Fill Profile。旧池塘 profile 因只有不可执行的 preserve surface，本轮不再暴露给 v0.8 AI。

## 保留边界与风险

- `contentWeights` 已进入 Blueprint、SurfacePrint 与 trace 的冻结链，但当前 `PRIMARY_CONTENT` 仍由 SurfaceRecipe 的单一 surface / crop 材料执行；多花种、多树种的逐块或 prefab 散布仍需 Decoration / 后续算法消费。
- 本轮林场只验证可用“树木主区 + 灌木带 + 石子空隙”的角色面域；真实随机树、灌木 prefab 与林间路网不在本轮伪装为完成。
- 单源距离层会形成可读的环带 / 岛带形态；更自然的多源聚类、噪声边界和路径图算法应作为新的 `LandscapeFillProfile.algorithm` 变体加入，不修改已冻结的首版语义。
- 旧 Blueprint、catalog snapshot、SurfacePrintPlan、active registry 与 completion 不迁移，必须完整重新 prepare / submit / plan。
