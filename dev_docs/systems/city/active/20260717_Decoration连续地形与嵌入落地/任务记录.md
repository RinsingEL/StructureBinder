# City Decoration 连续地形与嵌入落地

## 任务边界

- 双仓库联动：实现仓库承载 Java、测试和本记录；文档仓库同步产品案、数据契约、接口、代码导览、测试入口和影响面。
- 只升级 City Decoration，并收紧 LandUse 农业 surface 边界。
- 不修改建筑 Template、StructureStart、Jigsaw 或建筑地形适配主线。
- 连续 terrain run 首期只支持 `cross_section_repeat` 与 `parallel_rows`。
- foundation 首期仅支持显式 `fill_only`，不切山、不桥梁、不隧道，不宣称与 RoadWeaver 噪声期路基等价。

## 契约决策

- catalog 新增 `groundPlaneLocalY`、`embedDepthBlocks`、`clearanceMode` 和 `embed_surface`；字段参与 content/catalog hash。
- v0.2 catalog 保持只读兼容且不自动改用户配置；受管默认目录只允许显式备份升级。
- Program terrain policy 新增连续累计落差和浅层 foundation 严格字段；`fill_only` 只允许连续带 pattern。
- `terrainDropFallbackContentRef` 泛化为连续带 termination end-cap，不新增第二套 fallback 引用。
- run identity、terrain classification、termination、fallback、foundation 和 reason 必须进入 trace / preview / worldgen ledger。
- LandUse `CULTIVATE` 不再映射为 farmland surface operation；农业 area / spans / boundary 继续保留。

## 测试矩阵

- catalog v0.3 未知字段、必填字段、非法 mode/policy/ground plane/embed/clearance 与 hash 漂移。
- v0.2 只读兼容与显式受管升级，不静默写自定义目录。
- `above_surface`、`replace_surface`、`embed_surface` 的统一 origin Y。
- `clear_template_air` 可清沟口，`preserve` 不清模板空气，硬占用拒绝。
- 连续带 1x1 邻接落差、窗口累计峡谷落差、水岸 terminate、确定性 end-cap、跨 chunk run identity / ordinal 一致。
- `fill_only` 浅坑与 shoulder 填充、深沟 / 水体 / 峡谷拒绝；重复 worldgen outcome 幂等。
- crop / water / scarecrow 现有回归；LandUse 农业不再预铺 farmland。
- 最后执行 City 定向回归与 HTTP handler 回归。

## 当前风险

- foundation 已改为 D5 activation 时用 generator base height / column 冻结，Noise 阶段 Beardifier 正密度塑形；FEATURES 不填柱。仍需新存档真实验证 mixin 注入和第三方 terrain generator 下的实际肩部效果。
- active v0.2 文件中的连续 plan 会在重载时停用并要求重新执行 D5；非连续 plan 才可为空冻结计划兼容启动。旧 activate overload 也明确拒绝连续 plan 绕过 sampler。
- Decoration 仍依赖 biome decoration / feature 生命周期触发 NBT placement；无 configured feature 的 owner chunk 是既有未解决限制。
- foundation 只做浅层填方，不削坡、不架桥、不打隧道；RoadWeaver 与其他模组的额外 Beardifier 密度会与本模块贡献相加，需组合环境实测。
