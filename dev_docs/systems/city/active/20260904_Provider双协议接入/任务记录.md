# Provider 双协议接入

*需求入口*：用户希望将游戏内 Player Provider 从 OpenCode Responses API 切换到智谱 BigModel 官方 `glm-5.3-flash`；要求协议可配置，并保留现有 Provider 兼容性。

*修改内容*：Provider 配置新增 `apiProtocol`，支持 `responses` 与 `chat_completions`；旧配置缺少该字段时继续按 Responses 读取。设置界面新增协议切换并同步升级网络包版本；为避免增加一行导致界面纵向拥挤，模型厂家与协议按钮并排放在顶部同一行。连接测试、单次多模态分析及自动规划工具循环均按协议选择端点、请求体与响应解析；Chat Completions 路径支持标准函数工具定义、assistant/tool 历史回传、智谱 GLM-5.3 思考参数及工具截图转换。配置 schema 升至 `geomantia_player_provider.v0.2`。

*验证结果*：Provider 配置存储、连接测试、多模态调用和工具循环共 11 项聚焦测试通过；完整 `gradlew test` 与 `gradlew build` 均通过，已生成 `build/libs/geomantia-0.1.0.jar`；旧五参数配置构造仍默认使用 Responses。

*剩余问题*：尚未使用用户的智谱 API Key 进行真实远端请求，也尚未部署新构建到实际游戏实例验证界面与完整自动规划链。
