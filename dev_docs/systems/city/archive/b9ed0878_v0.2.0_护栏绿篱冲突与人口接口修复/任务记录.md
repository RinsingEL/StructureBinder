# 学院护栏绿篱冲突与人口接口修复

*需求入口*：用户要求核对 DeepSeek Harness 本轮学院规划报告的 Bug，随后授权“嗯嗯都改改吧，然后本地提交呗”。本轮仅本地修复与提交。

*修改内容*：

- `CityPublicGreeneryPlanner` 为共享台地护栏保留植物净空，同时让护栏列地面继续参与整平；保留重复占位校验。`CityDesignedPublicSpacePlanner` 整理花坛时只清除植物，不误删护栏。
- `ProviderPlanningToolCatalog` 为分区初版/修订及 integrate 补齐 `population`；可填写职责、居民数、岗位及用途、住房组。预算本身可省略；提供时提交完整预算。完整重交 districtDesign 时带上需保留的预算；integrate 的 changes 省略预算时保留，提供时整体替换。
- `CityD4Workflow.validateExpansion` 同步允许本区人口预算，仍要求实际阵列/嵌套修改，仍拒绝引用其他区住房。单独重做分区设计沿用 `city_d4_district`。Node MCP Schema 同步职业标识与岗位用途限制。
- 新增 4 项 Java 回归及 1 项 Node MCP 回归，更新两条故障记录。未改变本轮 D4 蓝图、游戏存档、实例配置或已安装 JAR。
