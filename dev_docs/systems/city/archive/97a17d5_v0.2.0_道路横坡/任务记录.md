# 道路横坡与横向楼梯

*需求入口*：学院用户试玩 R01“奇怪的下坡”；路线图 0.3.0 用户试玩修复第 6 项。

*修改内容*：`CityTerraceRoadGradePlanner` 原先让每个道路格各自等于脚下台地高度，再按四邻高差逐格放楼梯；台地 72/68 的分界顺着主路落在路面中间时，整条路宽被劈成两层并出现横跨路面的楼梯。现改为：

- 按连通道路组件的跨度判断主方向（沿 X / 沿 Z），把垂直于主方向的每一排路格视为同一横断面。
- 横断面在定坡前取众数高度统一；定坡后再统一一次，避免钳制重新造成横向台阶。含入口钉的断面保持精确高度不动。
- 楼梯只允许出现在道路方向上：沿 X 的路只看东西邻格，沿 Z 的路只看南北邻格；横向高差由断面统一消掉，不再铺楼梯。

*验证结果*：新增 2 项测试——宽 5 的道路跨越 72/68 台地时每一排路格只剩一个高度且没有南北向楼梯；东西向道路的楼梯只朝东西。原有 3 项（入口高度、过渡空间不足、等高平台保持冻结）全部通过；`compileJava`/`compileTestJava` 通过。

*剩余问题*：台地边界本身仍可能落在路面内，本分支只保证路面横断面水平并让楼梯沿路；长远仍需把边界吸附到路缘外（路线图记为后续）。全城另外 13 段同类道路要重跑 D4→LandUse 才能实机确认，本分支暂未做真实游玩验收。
