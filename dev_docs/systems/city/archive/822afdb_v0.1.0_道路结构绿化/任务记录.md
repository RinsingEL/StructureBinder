# 道路结构绿化

*需求入口*：City道路沿线绿化与照明案；用户要求按树素材大小计算间距、碰撞，树优先级低于结构。

*修改内容*：导入三份去展示地面与杂物的树 NBT，保留来源 hash、实际尺寸与树根坐标。D6 在建筑、道路、D5 城墙预留之后按旋转后完整树冠尺寸安排可选路树，混用树形并避让入口、路口、景观、水体及陡坎。可选树预检失败可跳过，排序保证建筑优先。树使用无 terrain adaptation 的 StructureStart，不生成建筑台面；树根定位与保护范围持久化，LandUse 建设面扣除路树占地。需求案提升为实现当前案并同步入口、相关契约；按规则仅标记下一 Session 清理到期。保留此前未提交城区与城墙改动。

*验证结果*：compileJava 通过。City 与 HTTP 回归运行 835 项：初次新增测试夹具缺失容量/掩码字段，修正后最终聚焦回归 107 项全通过（0 失败、0 跳过），覆盖规划尺寸/旋转、确定性混用、结构优先、入口/道路/城墙/景观避让、缺失素材/地形、水体和桥面跳过、NBT 本体与树根、无地形适配、存档重载、自然生成保护、LandUse 避让与 HTTP。两个仓库 diff --check 通过。

*剩余问题*：尚未游戏实测；树根贴地、坡地及沿街观感待实际世界验收。本轮新增道路树结构，路灯继续使用既有 SurfacePrint 能力。修改未提交。
