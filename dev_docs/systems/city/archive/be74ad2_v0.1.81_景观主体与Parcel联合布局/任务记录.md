# 景观主体与 Parcel 联合布局

## 目标

- 以显式 Landscape 主体替代 required/fill anchor 派生小地块。
- required 建筑候选与 required 景观容量在 D4 联合求解并原子提交。
- D6 后按精确实例数、Parcel 数和冻结父子拓扑生成互斥可接壤的独立 Area。
- 保留 `20260809_景观Parcel外轮廓修复` 的单源自然外轮廓与 preferredArea 停止语义。

## 固定决策

- required 景观同级，不抢占、不缩减、不降级；穷尽有限候选允许无解。
- 每实例 16 个稳定方向/父子拓扑容量候选；联合 DFS 上限 100000 节点，耗尽与无解使用不同错误码。
- fill/connectivity 不拥有景观且完全避让 required 容量。
- 同实例和跨实例均允许接壤；最终格互斥，共享边界单侧一格且唯一写入。
- optional 自由景观逐实例准入，成功实例仍必须达到精确 Parcel 数。

## 阶段

1. 同步产品、契约、代码导览、影响面和测试入口。
2. 升级 Blueprint/Context/Catalog/Snapshot 和下游计划 schema。
3. 实现 D4 联合候选搜索与容量预留产物。
4. 实现 D6 后父子 Parcel 与共享边界冻结。
5. 自动回归后结束开发角色，再独立验收。

## 实现结果

- Blueprint/Context/Snapshot/Reference Catalog/compile trace 已破坏性升级至 v0.10/v0.9/v0.10/v0.8/v0.10；Java codec、validator、MCP schema 和正式 catalog 同步。
- `CityLandscapeCapacityReservationPlanner` 输出 v0.1 容量计划；required 结构候选与 16 个方向/父子拓扑候选共享 100000 节点预算，成功后才原子进入 fill/connectivity。
- D4 anchor 冻结 planned/collision/mask 几何；容量预留只与结构实际/planned 方块互斥，fill/connectivity 的 collision 对预留 spans 硬避让。
- D6 强制读取并校验容量计划 hash、Blueprint identity、owner anchor 和真实 footprint；required 缺失或漂移不再允许域外兜底。
- `CityOutdoorIntentPlan` v0.4 和 Resolution 贯穿实例 ID、Parcel ID、真实 `parentParcelId`、root source、capacity domain；非链式父子树不再退回 ordinal-1。
- optional FREE_STANDING 按实例原子准入；成功实例全部 Parcel 达标，失败实例整体丢弃并按 instance ID 记录 `skipped_insufficient_space`。
- AreaPlan v0.2 / SurfacePrintPlan v0.6 冻结单侧共享边界；真实父子边固定 child owner，跨实例按非 OPEN 优先和规范化 instance ID 选 owner；chunk 只裁切冻结 spans。
- 保留外轮廓任务的自然逐格 frontier、`preferredAreaBlocks` 停止、一 Parcel 一 Area 和 Parcel 内区域接力。
- 真实 `RTF0810` D4 预览暴露首个 `direction=0/topology=0` 可行候选被立即接受，10 Parcel 退化为单向狭长直链。容量搜索现已改为比较预算内全部完整可行联合方案，按长宽比、树深、方向覆盖、分叉和包络择优，generation seed 只负责同分稳定择一；容量计划同步冻结 `selectionPolicy/layoutScore`。

## 2026-08-10 D4 扇形扩张力修复

- 真实预览确认此前的多方向修复仍会退化为两条正交直链；根因是 D4 容量候选继续以方向枚举和相邻矩形构造逐块形状，D6 只能在精确冻结域内复现该结果。
- D4 Parcel 容量改为从主体或父 Parcel 边界选择单一根点，以优先队列 frontier 逐格生长到精确容量；候选代价综合坡度、起伏、水体、preferred patch、局部聚合、向外投影和稳定双尺度噪声。
- 16 个确定性候选保留为 4 个主朝向乘 4 个扇面宽度；父子拓扑最多三条主枝并继续向外接力，避免单链、双直链和四向环抱主体。
- 每个候选仍严格保证单 Parcel 四邻接连通、父子最小共享边界、非父 Parcel 不接壤、最终 mask 互斥和 AI 提交的精确 Parcel 数/面积；地形或空间不足时拒绝该候选，不生成矩形兜底。
- D6 对冻结根 Parcel 不再取容量域最小坐标，而是选择与 required 主体真实 footprint 四邻接的容量格；子 Parcel 继续从冻结父 Parcel 真实边界接力。
- 新增回归锁定 10 Parcel 至少三向、根节点至少三条主枝、最大树深不超过 3、至少 8 个非矩形轮廓，并验证高坡带绕行后每块仍精确 192 格。
