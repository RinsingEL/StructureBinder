*修改内容*：
- D3 冻结 terrain field 提取岸线、等高线与高侧崖边；断线独立、未知格不造岸，Context 只提供引用/方位/端点/长度摘要，编译器消费同一地形。
- LINEAR 组可选择 layout.natural=TERRAIN_LINE；沿线按真实尺寸、间距与排数排布，合法正方向朝水面/低地，后排向陆侧退。沿线道路接入现有障碍与入口检查，地形线根不能被父组合搬动，也不接受第二个 anchorBlock。
- GRID 根组合可选 SCATTER，以完整小阵列/小组合作为单位，在平坦近水已采样地形内大间距散布。实际单位由最短连接树形成三格宽乡间路，SIMPLE 也支持；城内接入仍显式设计。完整包络、版本和冻结边界仍适用。
- 独立景观 growth.ruralMosaic 在可用域内多源分块；乡野外轮廓采用八方向与连续变化的地形成本，减少旧四方向生长的菱形倾向，块间留一格田埂。没有放宽建筑/道路避让或地形安全条件。逐块 fillSelection 复用作者内容；preserveVegetation 仅保留乡野原生林块，不下发清理或补种。
- 两侧 cliff_ 线组的显式 CONNECTION 可在同轴、近等高、已知完整地形及既有 100 格桥限内跨干峡谷；统一桥面与护栏冻结到 SurfacePrint，其他坡地失败不自动架桥。
- Java/MCP schema、手册、Context 投影及两仓契约/路线图同步；未修改测试端运行配置或用户存档。未修改建模素材，新的风车/谷仓/码头等素材依旧由建模任务补充。
