# 全城整体性复核告警

*需求入口*：学院用户试玩 C01“城市整体审美”；路线图 0.3.0 用户试玩修复第 11 项。

*修改内容*：`CityArrayVisualQualityGate` 在既有逐组检查之外增加全城复核告警：

- 参与成组的根组团超过 3 个时写 `CITY_REVIEW_TOO_MANY_ROOT_GROUPS:<n>`。
- 同一模板重复 ≥8 次且占全城建筑 ≥20% 时写 `CITY_REVIEW_TEMPLATE_REPEATED:<templateRef>:<count>`。

两条都只进质量报告 warnings（随 `arrayVisualGeometry` 进入 compile acceptance），不阻断编译，让 AI 在审阅时据此修订。

*验证结果*：`CityArrayVisualQualityGateTest` 新增 2 项（4 根组 + 9 次重复模板命中；3 根组 + 模板各异不告警），该测试类其余用例通过；`CityBlueprintCompilerServiceTest` 通过；`compileJava`/`compileTestJava` 通过。

*剩余问题*：组团间距全相同、内院超尺度这两类还没有量化告警（需要阵列间距与 publicSpaces 的尺寸数据）；学院城要重跑 D4 才能在新质量报告里看到这两条。
