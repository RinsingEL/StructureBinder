# 20260625 D7 Start Pool 适配 Solver

## 背景

City v0.3 P5 已有 `BoundedJigsawSolver` 核心，但上一轮 solver 输入仍是测试构造的 JSON candidate pool，真实 MC `StructureTemplatePool` 还没有进入 solver。为了推进真实验收，需要先把 start pool 的真实 elements 归一成 solver input，同时保持边界清楚：子 pool 递归读取与多 piece paste 仍未完成。

## 本轮改动

- `BoundedJigsawPoolAdapter`
  - 新增 MC start pool -> solver input 适配器。
  - 从 `StructureTemplatePool` 的 start elements 生成 `startPieces[]`。
  - 复用 `BoundedJigsawTemplateInspector` 读取 templateId、connectorRefs、footprint 和 visibleAreaCost。
  - 为 piece 标记 `connector_ready`、`terminal_piece`、`unsupported_pool_element`。
  - unsupported element 保留 `templateId=unresolved`，不把 `StructurePoolElement.toString()` 或诊断字符串当 templateId。
- `MinecraftStructurePlacementBackend`
  - bounded dry-run 改为通过 `BoundedJigsawPoolAdapter` 构造 solver input，再调用 `BoundedJigsawSolver` 生成 trace。
  - trace 补充 `poolAdapterStatus=start_pool_adapter` 与 `worldPasteMode`。
  - true-run 仍保持 start-piece adapter paste，避免在子 pool 递归和 template paste 后端完成前伪装多 piece 真实写世界。
- 测试
  - 新增 `BoundedJigsawPoolAdapterTest`：
    - connector-ready piece 保留 templateId、footprint、visibleAreaCost。
    - 无 connector 的 inspectable piece 标为 terminal。
    - unsupported element 标为 unsupported，不使用诊断字符串伪装 templateId。
- 文档仓库
  - 数据契约说明 MC start pool adapter 已接入 solver input，子 pool 递归和多 piece paste 仍待后续。
  - 代码导览登记 `BoundedJigsawPoolAdapter.java`。
  - 测试入口登记 pool adapter 测试。

## 验证

- `.\gradlew.bat test --tests "com.rinsing.geomantia.systems.city.infrastructure.world.BoundedJigsawPoolAdapterTest" --tests "com.rinsing.geomantia.systems.city.infrastructure.world.BoundedJigsawTemplateInspectorTest" --tests "com.rinsing.geomantia.systems.city.BoundedJigsawSolverTest"`：通过。
- `.\gradlew.bat test --tests "com.rinsing.geomantia.systems.city.*" --tests "com.rinsing.geomantia.platform.http.CityPlanningEndpointHandlerTest"`：通过。

## 风险与后续

- 当前 adapter 只接 start pool；connector 指向的子 pool 递归读取仍待实现。
- true-run 仍只 paste start piece；P6 template paste 后端完成前不得宣称多 piece 已真实落地。
- 后续需要把 connectorRefs 中的 pool ID 查回 MC registry，生成 `candidatePools` 后再让 solver 输出真正多 piece plan。
