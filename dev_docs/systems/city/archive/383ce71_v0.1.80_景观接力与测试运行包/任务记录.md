# 区域接力景观填充

## 背景

上一版 `SINGLE_SOURCE_LAYERS` 使用单源八邻域距离和周期取模分配角色。它虽然把菱形距离改成近似圆形距离，但仍属于“从共同中心生成固定等距轮廓”，实际预览形成同心环，未满足自然景观诉求。本轮破坏性替换该默认算法，不保留固定图形 fallback。

## 已锁定硬契约

1. 扩张算法唯一：所有景观格必须由可追溯的逐格扩张产生；严禁菱形、圆形、矩形、同心环、预制 mask 或其他固定图形作为正式算法、快速路径或失败保底。无法完成扩张时 hard fail。
2. AI 负责多样性：Blueprint 只配置填充方案、选择权重、角色 / 类型、目标占比和内容权重等语义参数；AI 不提交坐标、逐格 mask、固定图形或自由算法脚本。
3. 区域接力生长：第一块区域从景观起点扩张；后续区域必须从上一块或明确父区域的局部边界选择新起点继续扩张。所有区域必须冻结 `regionId/parentRegionId/start/sourceFrontier/targetArea/actualArea` 等 provenance。

## 实现边界

- 保留上一版已经建立的 Blueprint 方案选择、角色占比、内容权重和稳定 seed 思路，但将其字段语义升级为区域接力，不再表达距离层宽和重复周期。
- SurfacePrint 继续冻结全局 role spans，owner chunk 只裁切执行，不能在 chunk 内重跑扩张。
- 农田首个验收序列为主题耕地 -> 田埂 -> 水渠 -> 田埂 -> 新耕地；每一步从父区域局部边界接力，不形成完整闭环。
- 花田以多个大小不同的花区和局部叶带接力；林场本轮至少形成树木主区、灌木区与石子地面区的非同心面域。树木 / 花种内容的真实多 prefab 散布仍遵守 Decoration 职责边界。

## 质量阻断

- 任一默认或 fallback 路径仍调用 `SingleSourceLayeredFillClassifier`。
- 使用到共同中心的全局距离、距离取模或固定几何公式决定角色。
- 后续区域没有父区域或不是从父区域局部边界邻接起步。
- 为完成覆盖而对断开分量静默重新播种，或用 bbox / 固定图形补齐残余。
- 相同 Blueprint 参数和 seed 不确定，或输入集合遍历顺序改变结果。
- 预览仍呈完整同心环、统一菱形 / 圆形模板，且 trace 无法解释每块区域如何接力生长。
