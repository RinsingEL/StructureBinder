# 绿地去碎台阶

*需求入口*：学院用户试玩 G03“绿化区要不要保留原始地形”；路线图 0.3.0 用户试玩修复第 10 项。

*修改内容*：

- `CityLandUseChunkExecutor` 为公共绿地的 `GREEN_GROUND` / `GREEN_PATH` 列计算整平目标：取 3×3 邻域的原地形高度众数，平局取较低值；与原地形高差 ≤2 格时填/挖到位，超过 2 格保持原地形，由边界收边处理。
- 整平使用现有 `MICRO_FILL` / `MICRO_CUT` 准备流程，同样受 owner 写权限与失败回滚约束；绿地特征随后按整平后的高度落位。
- 新增 `greenerySectionTargets` 作为可测的纯函数，`ColumnKey` 提升为包内可见。

*验证结果*：新增 `CityLandUseChunkExecutorGreeneryTargetsTest` 3 项（小台阶归并到众数、大高差保留原地形、植物不单独成为整平目标）；`CityLandUseChunkExecutorTest`、`CityLandUseChunkCompilerTest`、`CityPublicRealmPlannerTest` 通过；`compileJava`/`compileTestJava` 通过。

*剩余问题*：内院与广场的整平仍依赖公共地表自身的高差分布，没有按“大坡向”做整体塑形；学院城需重跑 LandUse/D7 才能实机看到效果。
