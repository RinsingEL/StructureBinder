# 镜潮学院城 · 城市设计说明

## 一、城市定位

- **名称**：镜潮（city_jingchao_capital）
- **国度**：镜潮（jingchao），全国唯一城市，学院国度都城
- **规模**：town，规划半径 512 格
- **锚点**：(-2928, 5392)，镜潮岛中央连续平原
- **风格**：魔法学院新制（作者审核素材 `style:studio_07_arcane_academy`），木石为主，与桦木林协调
- **地面/道路**：石砖地面、石砖半砖路面，台地挡墙用圆石、栏杆用橡木栅栏
- **设计蓝图哈希**：`sha256:9c0d449e169f30fb952454b1ac96436d971378a155c928834dea6a048602bc69`（校验 `valid: true`）

## 二、空间序列

岛屿东岸公开迎客 → 中央教学庭院 → 北缘藏书街 → 高台观测 → 西南生活街坊 → 中央偏北药草田。
从岸边到深处逐步收束，教学与仪式居中，安静研究靠林缘，观测塔独占高处。
