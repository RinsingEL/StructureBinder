# LandUse 近邻同类桥接

## 任务边界

- 在 D6 后的 LandUse 常规行动力扩张结束后，连接同 `ruleRef` 的近邻区域，改善商业、住宅等功能区的视觉连续性。
- 只取得未归属、已采样、非水体、平缓自然 block；不恢复旧 FunctionZoneMap，不改写异类 LandUse、结构 footprint、gate corridor 或旧 chunk。
- Decoration 继续只消费最终 LandUseAreaPlan，因此桥接区域会在 Decoration 前进入同一 area。

## 规则与算法

- `city_land_use_rules.v0.2` 新增 `nearbyMergeMaxBridgeBlocks`；默认商业 / 工业 24、农业 / 林场 32、广场 / 行政 16、住宅 / 通用聚落 20、鱼塘 0。
- 既有 v0.1 profile 兼容读取，按相同 ruleRef 默认值补齐，不覆盖用户配置；重跑 LandUse 后以 v0.2 ruleVersion / profile hash 激活。
- `NearbySameTypeBridgePlanner` 在稳定快照上枚举候选，按路径长度、用途与组件 ID 稳定排序，以并查集跳过已连通组件，并拒绝已被先前候选占用的路径，避免重复和环。
- `[商业] [行政] [商业]` 中行政 claim 是硬障碍；仅当存在阈值内的自然空地路径时商业才能绕开形成连续区域。
