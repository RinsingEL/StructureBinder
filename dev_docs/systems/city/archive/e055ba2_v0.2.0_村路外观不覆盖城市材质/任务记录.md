# 路面材质不再被村路覆盖

*需求入口*：学院用户试玩 R02“违和的道路”；路线图 0.3.0 用户试玩修复第 1 项；诊断结论 R02。

*修改内容*：村路外观（`CityVillageRoadPlanner`）原先在城市材质之后无条件替换所有 `COMPACT_ALLEY` 路面，AI 在蓝图里选的石砖被换成土径。现改为：

- `CityVillageRoadSettings` 新增 `scales`（生效的城市规模），默认只含 `village`；旧配置缺该字段时按村庄规模补齐，不因升级重新编译出不同路面。
- `CityVillageRoadPlanner` 新增带城市规模的入口并返回 `Result(plan, notes)`：规模不匹配时整段跳过并记录 `VILLAGE_ROAD_SKIPPED_CITY_SCALE:<scale>`；蓝图按道路类型在 `selections.roads` 里显式给了材质时，逐 kind 跳过并记录 `VILLAGE_ROAD_SKIPPED_EXPLICIT_MATERIAL:<kind>:<streetBandId>`。旧入口保留为“未提供规模”，行为不变。
- `LandUsePlanningService` 新增带 `cityScale` 的重载，把跳过原因写入 quality warnings；`CityPlanningEndpointHandler` 的两条 LandUse 入口从 `city_seed_registry.json` 的 `theoreticalScale` 取值传入。
- 默认配置 `village_roads.json` 增加 `"scales": ["village"]`。

*验证结果*：`CityVillageRoadPlannerTest` 5 项通过，其中新增 `townScaleKeepsBlueprintMaterialsAndRecordsSkip`、`villageScaleAppliesButExplicitRoadMaterialWins`；`LandUsePlanningServiceTest`、`CityPlanningEndpointHandlerTest`、`CityRoadsideTreePlannerTest` 通过；`compileJava`/`compileTestJava` 通过。镜潮学院城种子为 `theoreticalScale=town`，按新规则不再套村路外观，路面保留蓝图石砖；村庄规模仍保留村路混铺与装饰。

*剩余问题*：已冻结的旧 LandUse 计划不会自动重算，学院城需重新编译 LandUse 才能在游戏内看到；合并前仍需跑全量测试；本分支未做真实游玩复验。
