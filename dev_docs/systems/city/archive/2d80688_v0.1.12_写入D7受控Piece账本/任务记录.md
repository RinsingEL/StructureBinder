# 20260625 D7 受控 Piece 账本

## 背景

City v0.3 的 P6 要求 accepted bounded jigsaw piece 在真实写世界后进入 `ChunkMaterializationLedger.appliedPieces[]`。上一轮已经把 `CityMaterializationJob` 和 job 级 ledger 显式化，但 `appliedPieces[]` 仍为空占位，无法证明 bounded start-piece 真实落地后具备 piece 级可重入证据。

本轮按最小兼容切片推进：不实现 connector 多 piece solver，不改变 bounded backend 的 start-piece 行为，只在 D7 已有 `boundedJigsawTrace.plan.pieces[]` / `acceptedPieces[]` 基础上，把真实成功的 accepted piece 落到账本。

## 本轮改动

- `CityStructureD7Executor`
  - `PlacedStructureMap.placedStructures[]` 为 bounded variable 记录保留 `materializationMode` 与 `boundedJigsawTrace`。
  - `ChunkMaterializationLedger.appliedPieces[]` 从 `worldMutationApplied=true` 的 bounded placed record 抽取 accepted pieces。
  - piece ledger 记录 `jobId`、`placedId`、`pieceId`、`idempotencyKey`、`templateId`、`poolId`、`anchorBlock`、`rotation`、`footprint`、`requiredChunkRange`、`visibleAreaCost` 和 `worldMutationApplied`。
  - dry-run 即使带有 accepted piece trace，也不会写入 `appliedJobs[]` 或 `appliedPieces[]`。
  - replay 读取 previous placed map 时保留 bounded trace，避免 piece ledger 证据丢失。
- 测试
  - 新增 `d7BoundedJigsawLedgerRecordsOnlyRealAcceptedPieces`：
    - bounded dry-run 返回 accepted piece trace 时 ledger 仍为空。
    - bounded true-run 成功后写入 1 条 `appliedPieces[]`。
    - `PlacedStructureMap.chunkMaterializationLedger` 与 `StructureGenerationTrace.chunkMaterializationLedger` 保持一致。
- 文档仓库
  - `城市规划数据契约.md` 补充 `appliedPieces[]` 和 `appliedPieceCount` 字段口径。
  - `测试入口.md` 同步 D7 materialization job / ledger 测试覆盖范围。

## 验证

- `.\gradlew.bat test --tests "com.rinsing.geomantia.systems.city.CityStructureD6D7Test"`：通过。
- `.\gradlew.bat test --tests "com.rinsing.geomantia.systems.city.*" --tests "com.rinsing.geomantia.platform.http.CityPlanningEndpointHandlerTest"`：通过。

## 风险与后续

- 本轮只把 bounded start-piece accepted piece 写入 ledger，不代表 connector 多 piece solver、endcap 或 terminal 收尾已经完成。
- `appliedPieces[]` 的 idempotency key 当前以 placed record + pieceId 组合生成；后续多 piece solver 接入后应继续保持稳定，不允许用运行时诊断字符串作为 pieceId。
- 后续 P5/P6 仍需让 solver 输出多 piece `BoundedJigsawPlan.pieces[]`，并由 paste backend 只写 accepted pieces。
