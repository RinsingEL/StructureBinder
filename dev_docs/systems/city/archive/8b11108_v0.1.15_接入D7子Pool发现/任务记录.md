## 本轮边界

- 允许：从 start piece connector 的 `pool` 字段发现子 pool，读取 pool elements，写入 solver input 的 `candidatePools` 和 adapter report。
- 允许：对子 pool candidate 标记 `child_pool_prototype` / `prototypePlacementStatus=connector_alignment_pending`，使 trace 能解释后续还欠 connector 对齐。
- 不允许：把子 pool prototype 伪装成已正确定位的 accepted piece。
- 不允许：把未真实 paste 的 plan pieces 写入 ledger。

## 验收计划

- 补 adapter 纯单测：从 start piece connectors 递归发现 pool、限制重复与深度、写 adapter report。
- 补 D7 ledger 单测：`worldPasteMode=start_piece_adapter` 且 plan 有多 piece 时，ledger 只记录 start piece。
- 跑 City / D7 相关自动测试。

## 实施结果

- `BoundedJigsawPoolAdapter` 增加子 pool discovery：从 `connectorRefs[].pool` 递归读取 pool，填充 `candidatePools`，输出 `poolAdapterReport`。
- `BoundedJigsawSolver` 对 `prototypePlacementStatus=connector_alignment_pending` 的 child pool prototype 返回 `JIGSAW_CONNECTOR_ALIGNMENT_PENDING`，防止未定位 piece 被误 accepted。
- `MinecraftStructurePlacementBackend` 在 bounded 模式下通过 `Registries.TEMPLATE_POOL` 查真实子 pool，并把 report 写入 trace；真实 paste 模式仍明确为 `start_piece_adapter`。
- `CityStructureD7Executor` 修正 ledger：`worldPasteMode=start_piece_adapter` 时 `appliedPieces[]` 只记录真实 paste 的首块 piece。
- 文档仓同步 README、数据契约、代码导览和测试入口。
