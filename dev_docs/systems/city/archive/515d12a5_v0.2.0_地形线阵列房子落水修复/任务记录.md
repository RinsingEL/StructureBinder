# 地形线阵列房子落水修复

*需求入口*：Rin 2026-11-23 来信：验收 Astra 的乡野片区与地形线阵列时，临海部分出现很多直接把房子放进水里的情况。2026-11-24 来信同意修改方案（逐格检查干地，不干就继续往陆地退）。

*修改内容*：`CityNaturalLayoutPlanner.line()`。原先每栋房子从岸线采样点沿该段边的法向后退固定距离（setback + 半个跨度 + 排数偏移），之后不检查落点。现在：后退方向取前后各 3 个采样点法向的平均；以原后退距离为起点，继续往陆地退（每次 2 格，最多一个跨度加两格地形格）并沿岸线小幅滑动（每次 4 格，最多半个间距），直到占地加 2 格余量全部落在已采样、非水、高度有限的格子上，占地内高差不超过 8 格，在规划范围内，且不与已放下的房子重叠。找不到位置时抛出 `CITY_TERRAIN_LINE_NO_DRY_SLOT`，提示减少排数、减少数量或换线。乡野片区（`scatter`）与分田（`CityRuralMosaic`）未改。

*验证*：`CityNaturalLayoutPlannerTest` 新增两项：斜岸线上所有落位的整块占地逐格为干地；两格宽沙嘴上一排可以放下、两排时报 `CITY_TERRAIN_LINE_NO_DRY_SLOT` 而不是退到对岸水里。原有用例中，斜岸线起点位于规划边界、旧算法会让第一栋半出界，第三栋沿台阶法向退进水里，新算法下通过。`systems.city` 全部 1036 项测试通过（云端，跳过 LFS 资源打包任务）。未在游戏内实机复验。

*剩余问题*：真实存档中的岸线落位效果待 Rin 实机验收；滑动会让个别房子比原定位置沿岸线挪动最多半个间距。田地形状问题等 Rin 定方向后另做。
