# 不留残缺的原生树

*需求入口*：学院用户试玩 G01“除草不干净”；路线图 0.3.0 用户试玩修复第 8 项。

*修改内容*：

- `CityReservationMaskPlanner` 增加城市域无植被掩码：墙线 `wallBounds` 优先，没有墙时用结构包络外扩 `DEFAULT_MASK_MARGIN_BLOCKS` 的并集。新生成的城区不再长出原生树，从根上避免“树伸进掩码被裁一半”。
- `CityLandUseChunkExecutor` 的公共地表清理从“只清本列”改为向四周各 2 格扩展（仍受本 owner 写权限限制），把树冠和树干一并清掉，已生成的存档不会留下悬空树叶。
- 窄条（道路/护栏 ±2 格被排除出绿化的区域）紧邻绿化列，由整棵树清理覆盖；墙内用地外的空地由城市域掩码覆盖。

*验证结果*：新增 `CityReservationMaskPlannerCityDomainTest` 3 项（墙线生成城市域掩码、无墙时结构并集外扩、空输入不写）；`CityLandUseChunkExecutorTest`、`CityLandUseWorldgenRegistryTest`、`CityPlanningEndpointHandlerTest` 通过；`compileJava`/`compileTestJava` 通过。

*剩余问题*：旧存档里远离任何绿化/路面列的空地原生树不会被执行器二次清理（只能靠新世界重生成）；城市域掩码会把城内自然植被全部交给 LandUse 规划，需重跑 D5/D7 实机确认不影响农田、林场与景观 Parcel。
