# 建筑地形异常占比

*需求入口*：用户「哦，我想到一个重要的问题，对于巨构，会不会因为一个小水塘，一个小峡谷，就直接拒绝掉进入啊」「对，咱们加上异常占比这个概念呗」。需求已补入固定模板唯一落地主线当前案。

*修改内容*：CityStructureTerrainGate 按 footprint 与采样格实际交叠面积计算异常占比，默认 <=10% 允许基础适配；保留原浅封闭坑豁免。面积加权高程中位数用于定位局部高差异常，避免最高最低值直接否决整体。缺失/未采样、未知或过深水体、超过四倍 policy 的极端地形、八邻接异常分量贯穿相对边仍拒绝。trace 保留异常比例、硬拒绝与贯穿诊断；同步 Blueprint 契约。10% 与严重程度上限为本轮实现默认参数。未改动工作区已有的阵列等其他变更。

*验证结果*：Gradle 聚焦 CityStructureTerrainGateTest（14）与 CityBlueprintCompilerServiceTest（63），共77项全部通过。覆盖10%边界、超限水塘、局部沟壑、高程双侧异常、极端/缺失采样、贯穿异常和边格实际面积。双仓 git diff --check 通过，仅换行提示。

*剩余问题*：尚未进行真实世界巨构落地验收；本轮验证为准入算法与编译回归，10%默认值后续可按现场效果调整。
