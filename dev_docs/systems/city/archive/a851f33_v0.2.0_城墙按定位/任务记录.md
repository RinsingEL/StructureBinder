# 城墙按城市定位与临水段

*需求入口*：学院用户试玩 C03“城墙是否必要且突兀”；路线图 0.3.0 用户试玩修复第 7 项。

*修改内容*：

- `CityWallReservationPlanner` 增加 `WallPolicy`：`none` / `gate_only` / `low_wall` / `land_side_only` / `full`。种子显式写时优先，否则按 `theoreticalScale` 推断：capital→full、city→land_side_only、town/village→none、未知→full（保持旧行为）。
- 不建墙的形式返回结构完整的空计划：wallLine / wallCorridorMask / gateSlots / wallNodeSlots 为空，保留 D3 覆盖范围让出城道路规划仍可执行，但不给墙带预留。
- 建墙时逐段检查 D3 水面 patch：整段超过一半格在水里就整段跳过，并写 `wallSkippedWaterSegments`；全部段都在水里时退回空计划。
- `CityPlanningEndpointHandler.handlePlanD5` 读取种子 `wallPolicy`，缺省按规模推断；形态与原因写进 `wall_reservation_plan.json`。
- 测试准备：`CityPlanningEndpointHandlerTest` 的 10 处种子显式补 `wallPolicy: full`，保留既有建墙断言；新增 `CityWallPolicyTest`。

*验证结果*：`CityWallPolicyTest` 4 项通过；`CityWall*Test`、`CityPlanningEndpointHandlerTest` 全部通过；`compileJava`/`compileTestJava` 通过。学院城 `theoreticalScale=town`，按新规则默认不建墙。

*剩余问题*：`gate_only` / `low_wall` 还没有可执行的墙型，目前降级为不建墙并在计划里写明原因；“城门只开在门外接有城外道路的位置”这一过滤本次未改（依赖出城道路计划）；实机需重跑 D5 才能看到学院城不再出现墙。
