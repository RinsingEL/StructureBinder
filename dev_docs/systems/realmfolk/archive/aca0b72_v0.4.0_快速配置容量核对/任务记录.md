# 快速配置看得见容量并在提交前核对

*需求入口*：学院用户试玩 L01/L02“配置时看不到床位和工位数、群体上限之和低于目标”；路线图 0.3.0 用户试玩修复第 4 项。

*修改内容*：

- 新增 `FacilityCapacity`：读取 Studio 导出的 `realmfolk_facility_catalog.v1`，按模板统计床位数与工位数；文件缺失或格式不符时返回 EMPTY，不阻断既有流程。
- `CityWorksheet.Evidence` 携带模板容量；`CityWorksheet.capacity(...)` 按住房功能命中的建筑汇总床位，并给出工位与预计人口（床位 × `housingOccupancy`）。
- 城市表审查 `review` 输出 `capacity`（housingBeds / workSites / expectedPopulation / basis）与估算说明；`errors` 在“群体上限之和 < 预计人口”时阻止提交并给出具体差额。
- `CityPlanningExtension` 的 evidence 从 run 目录读取设施目录：优先 `planning_source/realmfolk_facilities.json`，否则取 `config/structureTemplate/terrasense/*/` 下最新的 `realmfolk_facilities.json`。

*验证结果*：`FacilityCapacityTest` 2 项（解析与缺失/非法回退）；`CityWorksheetTest` 新增 2 项（容量可见并拦下 4 人上限 vs 9 人预计人口、缺目录时保持旧行为），该测试类原有 9 项全部通过；`QuickCityPlanTest` 通过；`compileJava`/`compileTestJava` 通过。

*剩余问题*：学院城需要按新规则重新跑一次快速配置（实机 MCP），本分支没有运行游戏；运行时 `realmfolk_quick_city` 仍以加载后的物理床位为准，未接入模板估算；模板设施目录缺失时保持旧行为，只是额外给出“无法估算”提示。
