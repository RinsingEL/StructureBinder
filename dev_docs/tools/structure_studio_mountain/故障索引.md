# 山腹锻炉建模故障索引

## 出檐屋面与柱顶缺少连续承托

*现象*：主代理图审确认 hip 铜屋顶的墙线屋面下有一格空层；扩查 gable 长侧同层缺承檐梁，独立棚柱顶与上半砖棚顶之间有半格间隙。

*首次偏离*：屋顶向墙外扩一格，首圈屋面起于 top+2，但墙线屋面在 top+3；独立棚柱到 roofy-1 而顶半砖位于 roofy+0.5。

*根因*：屋顶坐标按外檐设置，未核对真实墙线及柱顶接触面。

*修复*：仅在山腹自有 hall 的 hip/gable 墙线 top+2 补连续云杉承檐梁；自有 canopy 棚顶改下半砖，与原柱顶直接接触。公共 components 未改。

*验证*：撤回受影响资产冻结，按最终 NBT 差异列清单；重建、重拍、实际查看全套视图后重新发布双哈希证据。完成状态见任务记录。

*记录*：[任务记录](archive/63ffef49_v0.12.0_山腹填充完成/任务记录.md)。

## 工具间与料棚复合入口标记重名

*现象*：独立构建 MF-F03-v04 时验证器报告两个 entry 标记重复。

*首次偏离*：工具间调用 front 自动增加 entry，料棚末尾又使用同一 ID。

*根因*：复合结构入口未区分所属空间。

*修复*：料棚统一改用 shed_entry，保留工具间 entry。

*验证*：重建后标记唯一、导航无警告，最终入口标记图已实际查看。

## MF-10 守护者厨房站位落在后墙

*现象*：初次离线检查 kitchen 不可达，Y=2/3 站位为深板岩墙。

*首次偏离*：厨房放在 Z=26，通用厨房组件把站位设在 Z+1，恰为后墙 Z=27。

*根因*：紧凑后房的家具深度与使用方向未同时预留。

*修复*：厨房前移一格到 Z=25，Z=26 留作使用站位。

*验证*：修复后重建，导航与站位无警告；最终截图与双哈希验收通过。

*记录*：[任务记录](archive/63ffef49_v0.12.0_山腹填充完成/任务记录.md)，主代理统一提交。

## 作者角色字符串超出契约

*现象*：主代理交叉检查确认 MF-11 的 `planning_role.special` 与填充初稿的 `planning_role.filler` 不在项目角色白名单。

*首次偏离*：作者模型构造时把文档类别直接写成运行时之外的自由角色名。

*根因*：未沿用项目规定的 `key/anchor/fill/structure/self_contained` 角色；初版离线验证未设白名单。

*修复*：MF-11 改为 `structure`，填充统一 `fill`。主代理负责公共白名单校验。

*验证*：重新导出作者记录并重拍全部视角，重新实际查看后发布；不沿用旧作者哈希验收。

*记录*：[任务记录](archive/63ffef49_v0.12.0_山腹填充完成/任务记录.md)。

## 两层小屋梯井护栏不连续

*现象*：最终俯视切片显示两层宿舍、匠宅初稿只在梯井单侧放护栏，其余边缘开放。

*首次偏离*：独立楼梯组件挖穿二层板，楼层装修只手工补单边栏杆。

*根因*：楼梯组件未同时生成上层洞口围护。

*修复*：组件补齐上层两长边和低端短边护栏，只保留到达平台端；统一用于宿舍、匠宅、旅舍及书铺。

*验证*：四项最终重建后通路无警告，重新截图实际查看梯井三边护栏。

*记录*：[任务记录](archive/63ffef49_v0.12.0_山腹填充完成/任务记录.md)。

## 组合低屋与两层宿舍边界

*现象*：低屋去顶图仍显示低檐天花板；MF-04-v06 初次构建山墙屋脊超出模板高度。

*首次偏离*：组合结构使用高屋屋顶层，及双层基高加屋顶跨度未计入总高。

*根因*：去顶阈值未取最早天花板/棚顶；总高只按楼层而非最终屋脊确定。

*修复*：厅组件维护最低天花板；双层模板总高扩为25格，逐层切片单独保留；矮棚手动阈值设在Y=7。

*验证*：最终NBT数据和站位检查通过；修正模型或作者记录后重新拍摄与看图。

*记录*：[任务记录](archive/63ffef49_v0.12.0_山腹填充完成/任务记录.md)。

## 商业开间缺少完整业务空间

*现象*：主审看到 MF-06-v01 宽面前店仅三组宝石和小柜台，后工坊仅角落设备，开间尺度与业务布局不相称。

*首次偏离*：商业初稿只布置象征设备，未分配验货、顾客、加工中间作业、原料及成品的完整空间。

*根因*：业态完成度只按存在设备判断，未按房间尺度核对作业流程。

*修复*：trade20按各自业态加入连续工作台及具体服务/储存区；新功能同步工作站位与房间用途，保留主运道和门前通路。

*验证*：20项最终NBT/作者数据与碰撞通路全部通过、零警告；完整截图实际查看，发布状态见任务记录。

*记录*：[任务记录](archive/63ffef49_v0.12.0_山腹填充完成/任务记录.md)，Git由主审统一。

## 梯井U形栅栏角臂断开

*首次偏离*：导出显式方块状态，没有运行Minecraft邻居更新来补全转角。

*修复*：trade局部stair包装补两端south臂，MF-08-v03与MF-F01-v05应用。主审随后授权life有界修复，同样补齐短边两端连接；全12项临时导出对比确认只有MF-04-v06和MF-05-v02字节变化，其余10项NBT与作者数据均未变。未修改公共helper。

*验证*：trade两项已随商业批次重导出、完整重拍与发布。life两项重新数据及导航检查零警告，分别17张共34张图全部实际查看后发布；最终二层图确认U形护栏转角连续。贸易与户外冻结内容未改。
