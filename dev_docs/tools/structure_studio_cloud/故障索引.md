# 云海建模故障索引

## 2026-09-22 独立亭盖柱顶未接到内缩屋面层

*现象*：继续检查填充截图时发现若干独立亭盖的柱顶与铜屋面有细小竖向间隙；回查核心CN-03/10/12同样存在。

*首次偏离*：以屋檐基准层减一作为柱顶，未计算hip屋面在向内一到两格柱位处上升后的实际层高。

*根因*：没有按每个柱/墙所在的屋面内缩量计算实际层高；独立亭盖柱顶不足，普通房屋天花板之上也缺少承檐层，山墙顶低一格。首次核心视觉检查漏判了间隙，原验收结论撤回。

*修复*：各亭盖柱延伸到对应柱位的实际屋面层，普通房屋补连续承檐梁、山墙填至坡顶下方，补充/保留连续横梁；核心全部已通知主任务暂缓整合。

*验证*：7项核心重新导出、数据/全部标记通路无警告；重新拍摄133张最终图并全部实际查看后再次publish。修订后的屋面与墙梁、亭柱连续接触，泊塔侧栏底板同时补齐。填充受影响部分已重新导出并开始重拍，未宣称完成。

*记录*：[任务记录](archive/63ffef49_v0.12.0_云海填充完成/任务记录.md)，待主任务统一提交。

## 2026-09-22 斜阶栏杆缺少连接属性

*现象*：主审发现CN-03外阶看似完全开敞；再次加高栏段拍图仍主要看见细立柱。

*首次偏离*：斜阶直接放置 `dark_oak_fence`，没有像水平 railing helper 一样显式填连接属性。

*根因*：离线NBT保留默认四向false的栅栏状态，单格逐级落差也没有同高重叠横栏。不能把“有栅栏方块”视为“有连续扶手”。

*修复*：云海所有独立外阶显式设置南北连接，采用重叠两格高栏段，实体侧托填回主平台。核心只影响CN-01/03；填充影响12个有外阶的变体。

*验证*：撤回受影响证据，重新导出、拍摄并实际查看最终全视角后再publish；其他5核心保持冻结。

*记录*：[任务记录](archive/63ffef49_v0.12.0_云海填充完成/任务记录.md)，待主任务统一提交。

## 2026-09-22 作者角色误用非契约取值

*现象*：主任务交叉审查发现废塔/回收营用了 `planning_role.landmark`，居住填充用了 `planning_role.filler`，不在角色契约白名单中。

*首次偏离*：创建作者模型时由用途名称推导角色枚举，没有使用既有取值。

*根因*：作者选项错误；已有离线验证器当时未检查该字段白名单，因此数据校验未拦截。

*修复*：专项改 `structure`，填充改 `fill`；主任务统一增加公共校验白名单，本代理不修改公共工具。

*验证*：CN-11/12 已重新导出、重拍35张最终视角、实际逐图查看并重新发布；两项专项作者角色与双哈希现均匹配。居住填充已统一改为fill并重导出，拍图验收继续进行。

*记录*：[任务记录](archive/63ffef49_v0.12.0_云海填充完成/任务记录.md)，待主任务统一提交。

## 2026-09-22 组合建筑去屋顶阈值遗漏低层屋盖

*现象*：首轮 CN-01 外观截图正常，但 `roof-off` 仍保留两翼候船房屋顶。

*首次偏离*：作者记录以高架泊台的高层设施计算 `roof_min_y`，未采用最低天花板层。

*根因*：组合建筑错误沿用了最高设施的剖切阈值；分层最大高度也覆盖了低层屋盖。

*修复*：泊塔、修造库及导航塔统一取低层天花板 Y=14，主层切片停在 Y=13，高层另用独立切片；同步修正地形示意坡向并补泊台北缘护栏。

*验证*：核心7项最终NBT与全部标记通路无警告；133张最终截图实际看图后正式归档，组合屋顶问题已闭环。

*记录*：[任务记录](archive/63ffef49_v0.12.0_云海填充完成/任务记录.md)，待主任务统一提交。
