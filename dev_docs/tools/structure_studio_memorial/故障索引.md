# 哥特建模故障索引

## 双车湾屋盖范围及后支承

*现象*：ML-02 首轮源码剖面检查发现车棚屋盖比静态车体短，未安排后端落地柱。

*首次偏离*：屋盖沿 Z 只延伸 8 格，而车体从湾内第4格延伸至第10格。

*根因*：车棚跨度参数没有和车体完整占地对齐。

*修复*：屋盖延长为12格，前后两端均有落地柱；坡面逐级两格厚相接。

*验证*：重建后数据与导航零警告；当前截图批次使用修复后 NBT，23张最终截图已实际查看并归档。

*记录*：[核心任务](active/20260922_哥特核心建模/任务记录.md)。

## 低翼去顶阈值与陵寝坡向

*现象*：低翼去顶图残留坡盖；陵寝首轮场地示意没有按高前低后方向贴合旧路。

*首次偏离*：统一 roof_min_y=13 未随低翼屋面 Y=11 调整；坡地误用了前端不读取的 high_y/high_start_z 参数。

*根因*：作者标记未与各屋面最低高程及实际场地示意契约同步。

*修复*：每建一翼取最低屋面阈值；陵寝改用 land_surface_y=9、run=8、rise=-1，另加上口观察点及石阶房间。

*验证*：五项重建数据/nav零警告并重拍；以最终截图重新实际全图审查后发布，不复用旧作者哈希。

*记录*：[核心任务](active/20260922_哥特核心建模/任务记录.md)。

## 填充住宅床柜与共用被服柜站位重叠

*现象*：ML-03-v02/v05 首轮导航提示 linen 站位被桶占用。

*首次偏离*：床脚后两格个人柜与墙边共用被服柜的前站位落在同一个 X 坐标。

*根因*：两套储物组合分别布置，没有避让服务站位。

*修复*：共用被服柜横向移一格，保留原寝室与个人床柜布局。

*验证*：两项重新导出导航，最终截图以修改后双哈希为准。

*记录*：[填充任务](active/20260922_哥特填充建模/任务记录.md)。
