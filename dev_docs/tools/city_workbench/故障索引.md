# 建筑工作台故障索引

## 公共空间场景含农田地块时生成崩溃

*现象*：配置 `publicSpaces` 且含 CONTIGUOUS 试种田/苗圃的场景生成失败，`KeyError: 'roadEntrances'`。

*首次偏离*：`designed_landscape.apply_public_spaces` 为每个成员背面种植时读取 `roadEntrances[0]`。

*根因*：功能地块不接入道路，没有入口字段；R31 等旧场景没有农田地块，未覆盖该组合。

*修复*：无入口的地块跳过组团边缘种植。

*验证*：星穹学院示范（含试种田与苗圃）完整生成。

*记录*：[任务记录](../../systems/city/archive/60999be8_v0.1.0_D4构图手法与学院示范/任务记录.md)，提交 dcb52aaf。

## D4 工程预览中的中心广场落入水体未起台地

*现象*：用户提供的新一版 D4 学院工程预览中，教学区东侧的中心广场一部分落在 D3 水域上，广场所在位置没有抬起台地，显示为水面上的空旷灰色铺地。

*首次偏离*：工程预览消费台地施工列时，没有对非建筑公共地面执行逐列天然水体裁切。原2026-10-14截图未找到可对应的冻结版本。

*根因*：粗平台范围与实际水面可重叠，合成器直接画入铺装，公共空间再消费这些承载列。

*修复*：本地修复分支保留实际天然水列，裁掉非建筑、非显式桥梁的公共铺装；冻结D4旧版本仍原样展示，不伪造旧证据。D4规划同时增加触水告警。

*验证*：新增“粗平台覆盖真实水面”回归及8项工程预览测试通过；原截图场景仍待对应版本/游戏复验，未启动游戏。

*记录*：[学院试玩剩余修复](../../systems/city/active/20261017_学院试玩剩余修复/任务记录.md)，保留原2026-10-14截图反馈的历史状态。
