# 学院小型绿化素材

*需求入口*：用户要求补充通用绿化素材，保留风格特色，本轮只做魔法学院；遵循作者资产与验收证据契约。

*修改内容*：新增 academy_greenery.py 与 MG-50～61 的源码和 NBT：6 种树、3 种灌木/绿篱、2 种花丛/花带、1 种花箱。注册 build 入口，提供 greenery-pools.json 的七个作者子池、建议权重、尺寸、根点、树冠、地面基准和双哈希。素材目录 README、清单与实际图册同步；学院现有场景未修改。

*验证结果*：12 件导出与 validate 无错误/警告；3 项约束测试覆盖树枝连通、无清场空气、叶片持久、花朵土壤与小型尺寸。每件拍摄 8 个视角，实际查看前后、俯视、贴地四视角，使用 publish 归档 12 件双哈希证据；无浏览器错误或缺失纹理。无行走目标，未把空目标的通路报告当作通行证据。

*剩余问题*：作者素材池不等同于运行时生成器已接入；尚未做真实游戏内放置、随机刻或光照验收。稀疏花丛土层须按地面基准嵌入，不能悬空铺在街面。
