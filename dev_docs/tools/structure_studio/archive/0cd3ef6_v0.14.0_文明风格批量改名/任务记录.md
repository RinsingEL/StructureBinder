# 文明风格批量改名

*需求入口*：用户确认风格以族群或国度命名，并要求“嗯先批量改一下吧”；建模保持暂停。

*修改内容*：12 类文明工作命名更新清单、相关 README、生成源码及现有 384 份 author.json 的 civilization；跨文明公共分类不变。新增文明命名表，说明历史路径不是地形限制。NBT、图片、ID、地形与全部空间标记不变。旧双哈希匹配的证据记录追加显式 metadata_migrations，保留原图审状态、作者、结论和旧哈希；过期或缺失证据不提升状态。正式契约记录本次严格限于文明文本的迁移。只暂存原已跟踪文件的改名，既有未提交进度与新增资产保持原状态。

*验证结果*：384 份作者文件仅 civilization 改动，反向还原可精确重建旧 SHA-256；6,719 个 NBT/PNG 字节不变；624 份归档 capture/review 迁移链一致（另有运行时捕获元数据同步）；2 项既有测试通过（过期作者标记拒绝、确定性导出往返）；修改的 Python 源码语法通过；HTTP 目录新名称及 MF-01-v01 模型/验收双哈希通过；两仓 staged diff --check 通过。运行报告与验证脚本保留 tools/structure_studio/runtime/civilization-rename-report.json、verify_civilization_rename.py、rename_civilizations.py。

*剩余问题*：本轮不恢复建模。名称为素材库工作命名，不新增正式世界观设定。原未提交资产与进度仍待后续原任务验收提交；旧整页 workbench 图保留历史名称，不是归档视口证据。此前楼梯护栏预览问题仍属暂停的原任务，不在本次修改范围。
