# 设施导出提示床位与工位缺口

*需求入口*：学院用户试玩第 13 项“模板床位与工位检查”（路线图：开发 agent → 作者）。

*修改内容*：`tools/structure_studio/studio/living.py` 的 `extract` 增加用途检查：

- 按 `planning_role`、`name` 与 `rooms[].purpose` 识别用途；命中住宿类但没有可用床时写 `REALMFOLK_FACILITY_MISSING_BEDS`，命中商店/教室/工坊等但没有工作设施时写 `REALMFOLK_FACILITY_MISSING_WORKSITES`；装饰类不提示。
- 提示随既有 `living_facilities.json` 的 `warnings` 导出，作者在导出结果里直接看到缺口。

*验证结果*：`tests.test_living` 10 项通过，新增用例覆盖住宿、商店与装饰三种用途；`python -m unittest tests.test_living` 在 `tools/structure_studio` 下运行通过。

*剩余问题*：提示只覆盖导出阶段，工作台界面还没有把 warnings 标红；学院城需要作者按提示补床位与工位后重新导出模板，开发侧无法代替补素材。
