## 2026-09-24：北欧公共选址说明把内陆候选统一绑定海湾

*现象*：50 个北欧作者资产全部标记“稳定的寒地海湾背风岸台”，包括越冬仓和普通长屋；风格说明却允许内陆使用。

*首次偏离*：模型创建时直接继承北欧 base() 的套系场景作为单体选址。

*根因*：northern_seafarers.py:base 无条件写入寒地海湾描述，仅部分专用设施另加岸线条件，通用建筑没有分离推荐场景与必要条件。

*修复*：50 份北欧作者记录的通用选址改为稳定承载地面及真实入口要求，寒地、海湾降为推荐情境；逐项保留水岸设施自身的岸线、水深、接驳条件。集中作者语义规则接入 Model.export，后续导出同样修正已知的原始描述。

*验证*：回归检查普通仓储的内陆可用描述及船运设施的岸线、水深、高程条件；498 份全量迁移与 NBT、旧证据哈希核对通过，重复迁移无变化。尚未进行运行时选材或放置复验。

*记录*：[建筑标签情景检查](archive/0d261066_v0.1.0_建筑标签情景检查/任务记录.md)，未提交。
