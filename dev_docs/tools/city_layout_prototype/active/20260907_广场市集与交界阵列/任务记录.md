# 广场市集与交界阵列

*需求入口*：用户要求在原型中区分公共广场、内部/边缘市集，并增加沿 Patch 交界排布。

*修改内容*：公共广场可选核心；内部市集按排与过道落位；边缘市集保持沿边紧凑；交界支持 A/B 集合、真实共享边追踪、陆水侧与作者入口朝向、退让与区段范围，非法候选跳过但不足报错。新增 UI 和黄色/蓝色集合及橙色轮廓预览。仅独立原型，不修改 Java 或游戏存档。

*验证结果*：23 项几何测试、原浏览器回归及新增 scenes.browser.test.cjs 通过。新浏览器覆盖真实喷泉核心、无核心广场、内部排布、真实 p.25/p.29 交界、落位介质失败、导出与重载。截图在原型 evidence/public-plaza.png、market-geometry-only.png、patch-boundary.png。市集/交界测试体使用小住宅真实尺寸，仅验证几何，不宣称功能素材或游戏验收。

*剩余问题*：当前快照无水深、工作端、靠泊侧；不可将二维粗检冒充船只/起重机落地验收。
