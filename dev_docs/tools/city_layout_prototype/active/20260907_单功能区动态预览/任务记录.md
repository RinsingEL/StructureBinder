## 行政院落纠正（2026-09-07）

用户明确行政示意图是院落而非轴端街带。本轮新增独立 COURTYARD 实验并作为新会话默认：主楼一侧、左右配楼向内、末两栋夹对侧开口，中心保持公共空间，通路沿院边而非贯穿前庭。宽度、进深、入口净宽独立可调，缺配楼或院落过小明确失败，不跳成其他算法。旧轴端方案保留并标“非院落”，用户已保存配置不覆盖，通过“载入行政院落示例”切换且能撤销。默认仍用同一批 7 栋素材和真实地形粗检。
