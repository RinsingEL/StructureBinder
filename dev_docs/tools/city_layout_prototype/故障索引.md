# 城市布局原型故障索引

## 行政示例被误实现为轴端街带（已修正）

*现象*：原行政区院落示意被原型理解成“轴端主楼＋两列配楼”，道路穿过前庭。

*首次偏离*：默认实验算法选择与空间语义。

*根因*：只保留主次／对称，遗漏院落围合要求，不是素材或模型调用问题。

*修复*：院落实验独立实现，主楼位于边侧、配楼向内、入口位于对侧、道路沿边；默认示例改院落，旧排布明确标“非院落”。

*验证*：14 项几何测试及真实 Edge 交互回归通过，院落中心无建筑与贯穿道路，桌面截图已核对。

*记录*：[单功能区动态预览](./archive/e81149b_v0.1.0_单功能区动态预览/任务记录.md)，提交 e81149b。

## 无核心公共空间无法适应视野（已修复）

*现象*：关闭核心后只有广场，适应布局仍按旧建筑位置；交界轮廓也未纳入视野。

*首次偏离*：新场景的视野边界计算。

*根因*：原 fit 仅汇总建筑和景观边界。

*修复*：纳入公共空间及真实交界线段，无建筑时也可定位。

*验证*：新场景 Edge 测试及截图核对通过。

*记录*：[广场市集与交界阵列](./archive/e81149b_v0.1.0_广场市集与交界阵列/任务记录.md)，提交 e81149b。

## 状态恢复后的旧失败明细残留（已修复）

*现象*：修改起点造成失败，再撤销回成功布局，状态栏通过但详情栏仍保留旧失败文本。

*首次偏离*：重新计算成功后的详情显示。

*根因*：只在失败分支更新详情，没有在成功分支清除旧失败说明。

*修复*：成功重算清除旧选择和失败明细，恢复当前结果提示；撤销重做持久化当前配置，并保存可重新计算的上次有效配置。

*验证*：浏览器回归检查成功恢复后不包含“本次尝试”；失败后重新加载仍能恢复上次有效布局。

*记录*：[单功能区动态预览](./archive/e81149b_v0.1.0_单功能区动态预览/任务记录.md)，提交 e81149b。
