# TerraSense 故障索引

## binder 导出放过空风格及未批准词表引用（2026-09-05）

*现象*：语义审核 approved 时可导出空 styleTerms 或不在批准词表内的功能/风格引用，与 Binder 作者语义准入不一致。

*首次偏离*：`buildBinderProfile` 仅收集字符串，未校验 style 非空与词条状态/类型。

*根因*：binder 分支未复用正式词表的准入约束。

*修复*：非空风格、功能/规划角色/风格词条存在且类型一致并 approved，否则明确 skipped reason。

*验证*：Studio 22 项回归通过，Binder 作者语义定向回归通过。

*记录*：[入口预标记接入](active/20260905_入口预标记接入/任务记录.md)，未提交。

## 入口审核旧数据缺 note 时切换意图导致页面异常（2026-09-05）

*现象*：隔离 UI 验收切换“无需接路”后页面空白。

*首次偏离*：按钮禁用条件对缺省 note 调用 trim。

*根因*：已有入口对象绕过字段级默认值，合成旧数据未带 note。

*修复*：入口审核对象按字段补齐默认值再渲染。

*验证*：同一浏览器 fixture 重载后，切换意图、填写原因、确认保存全部通过。

*记录*：[入口预标记接入](active/20260905_入口预标记接入/任务记录.md)，未提交。
