# TerraSense 故障索引

## binder 导出放过空风格及未批准词表引用（2026-09-05）

*现象*：语义审核 approved 时可导出空 styleTerms 或不在批准词表内的功能/风格引用，与 Binder 作者语义准入不一致。

*首次偏离*：`buildBinderProfile` 仅收集字符串，未校验 style 非空与词条状态/类型。

*根因*：binder 分支未复用正式词表的准入约束。

*修复*：非空风格、功能/规划角色/风格词条存在且类型一致并 approved，否则明确 skipped reason。

*验证*：Studio 22 项回归通过，Binder 作者语义定向回归通过。

*记录*：[入口预标记接入](archive/8fe6216_v0.1.0_入口预标记接入/任务记录.md)，Binder 8fe6216 / TerraSense 91d6a31。

## 入口审核旧数据缺 note 时切换意图导致页面异常（2026-09-05）

*现象*：隔离 UI 验收切换“无需接路”后页面空白。

*首次偏离*：按钮禁用条件对缺省 note 调用 trim。

*根因*：已有入口对象绕过字段级默认值，合成旧数据未带 note。

*修复*：入口审核对象按字段补齐默认值再渲染。

*验证*：同一浏览器 fixture 重载后，切换意图、填写原因、确认保存全部通过。

*记录*：[入口预标记接入](archive/8fe6216_v0.1.0_入口预标记接入/任务记录.md)，Binder 8fe6216 / TerraSense 91d6a31。

## 新审核门槛阻断明确保留的旧素材池测试（2026-09-05）

*现象*：旧 65 模板素材池没有入口 sidecar，托管规划在模型调用前被拦住。

*首次偏离*：ManagedCityPlanningSources 无条件要求 sidecar。

*根因*：入口审核接入未提供用户明确选择的旧目录兼容路径。

*修复*：默认严格审核，source 可显式选择 legacy_catalog；不伪造审核、不在已声明/安装的 sidecar 失效时降级。开发端旧包单独启用。

*验证*：10 个端口 NBT 路径核验完成，兼容准入与实际 65 模板包 resolve 通过；JVM 全量 758 tests、0 failures/errors、2 optional skips。

*记录*：[旧素材池入口修正](archive/50d9c9c_v0.1.0_旧素材池入口修正/任务记录.md)，后续改动未提交。

## Stubbs 原门坐标直接用作接路点导致向内穿过建筑（2026-09-05）

*现象*：5 个入口方向指向室内障碍，另 5 个虽朝外但接路点仍在模板内部。

*首次偏离*：template_catalog roadEntrances 写入门方块位置/朝向，未区分门与模板边缘接路口。

*根因*：入口元数据混淆方块朝向与室外接路几何。

*修复*：依据实际 NBT 的地面和两格净空，把 10 项接路点移到连续门外通路的边缘；不改源建筑，不靠关碰撞门槛修复。

*验证*：只读脚本验证 10 端口/67 通路格，完整源文件哈希均不变。

*记录*：[旧素材池入口修正](archive/50d9c9c_v0.1.0_旧素材池入口修正/任务记录.md)，未提交。
