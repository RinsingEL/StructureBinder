# 入口预标记接入

*需求入口*：用户确认在 TerraSense 接入开局前人工入口标记，并打通 StructureBinder。

*修改内容*：TerraSense 新增创造模式 `/ts_entrance open/mark/remove`，在既有扫描 workspace 采集真实模板边缘朝外出口，绑定与 Binder 相同算法的完整 NBT SHA-256；只写候选，不写人工审核。扫描忙时拒绝编辑，退出服务器清理会话。Studio 增加独立入口审核、刷新采集、多个入口选择、明确无需接路及原因，保存端与导出端均验证采集摘要/身份/坐标/朝向。binder 导出增加已审核入口 sidecar，并补齐风格与词表批准准入。Binder 托管规划读取 sidecar、核对模板身份/hash/rawSize、合并到冻结上下文，不修改原模板目录、不沿用旧门坐标。支持 binder source descriptor，双 descriptor 拒绝歧义。两份契约和 Studio 使用说明同步更新。

*验证结果*：TerraSense Java build/reobfJar 成功（无 Java 测试源）；Studio build/check:server 成功，22/22 Node 测试通过；Binder 全量 755 tests、0 failures/errors、2 optional skips，最后 source 错误提示与路径更新后的定向回归再次通过。隔离 Studio 31327 浏览器实测：旧采集摘要失效提示、反向端口保存拒绝、明确无需接路+原因成功保存并刷新仍保留；修复旧审核 note 缺省时切换 intent 导致页面异常，最终样式截图复核无横向溢出。测试使用临时合成 workspace，未触碰原 PCL 存档或真实作者审核。

*剩余问题*：首版限定 localY=1、模板边缘朝外、脚下完整支撑+两格无碰撞无液体净空，多 palette/台阶/架空出口明确拒绝。室内到出口的完整路径由作者确认，当前程序只验证端口局部，不宣称支持立体接路。游戏内命令的真实采集验收、实际 65 个模板的作者入口审核及 GLM 首城联调尚未完成；不能据编译和合成测试宣称首城已修好。旧测试包缺 sidecar，重新托管规划会在模型调用前要求补审核，不能绕过。原首城预算保持 2/5，Provider 关闭。本次没有提交，也未部署到 PCL。
