# 场地构图控制台

*需求入口*：用户要求在控制台新增可高度自定义的场地阵列，并提供广场、花园、祭坛等示例。

*修改内容*：独立场地构图页面和通用嵌套构图解释器，真实 NBT、可配置素材池、入口绕障连通；三个可编辑示例，不覆盖学院岛。

*验证结果*：6 项测试通过，含三套真实 NBT 场景各自的碰撞通行审计、种子确定性、嵌套平移、碰撞/留白/入口失败。前端构建通过；浏览器切换全部三个示例，并实际把环形树从 8 改为 6（成员数 13→11），完整 JSON 同步正确，无渲染错误/缺失贴图。已查看三例立体截图。证据位于 runtime/space-composer/。

*实现入口*：space_composer.py、space-examples.json、/spaces 页面；学院侧栏增加入口，预览接口不写学院 state.json。范围和接口记录在 SPACE_COMPOSER.md。

*剩余问题*：本轮独立场地实验，未接正式游戏或替换学院公共空间。
