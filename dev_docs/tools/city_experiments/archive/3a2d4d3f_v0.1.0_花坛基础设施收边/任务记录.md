*需求入口*：用户同意试用基础设施标签的花坛收边模板，先用于当前教学与生活区示例。

*修改内容*：补充石质直段、内外转角、端头 NBT 消费件；通用程序沿实际种植轮廓选择和旋转模板。院落与广场花坛完整收边，小间隙只处理近道路的一侧，保持自然地面，避让通路、构件、树木。
