# 近邻连接台地

*需求入口*：用户要求近邻小间隙纳入台地，连接两侧城区，并询问小间隙距离阈值。

*修改内容*：新增 connection_terraces.py 与 CONNECTION_TERRACE 模式，衔接近邻间隙的承载面、石砌支撑、外围与真实高差防护，撤除同高内部接缝栏杆。保持核心与道路规划；读取通用 styleRef。smallGapMaxBlocks 默认 32，可在网页调 4～64；判定含道路的实际边界格路径距离，32/33 格有明确回归。

*验证结果*：R24 发布；4108 格承载、143 个同高内部防护方块撤除、131 格暴露边缘防护。6 项间隙测试、1 项连接支撑/内边栏杆回归、4 项实际 Java/NBT 集成通过；22 条实际输出步行路线全部通过。前端构建与 diff/语法检查通过。实际浏览器无错误与缺纹理，已目视检查 connection-terraces/road-gap.png。阈值不代表核心距离；不同高程仍分段、有真实落差则保留防护。

*剩余问题*：离线工作台适配，不代表正式 MC 世界验收。
