# 阅读花园植物层次

*需求入口*：用户希望植物更多，并仅参考所附园林图的设计思路。

*修改内容*：阅读花园增加分层种植区，沿步道、边界和小庭周边布置灌木与花丛，保留开敞草地；复用学院模板池和现有控制台样式。

*验证结果*：阅读花园在原 16 成员基础上新增 108 处植物，默认共 124 成员。7 项回归通过，包括实际方块通行、开敞区避让、固定种子复现、0 丰度关闭且通路不变。前端构建与三个示例浏览器验证通过，实际操作丰度 100→0→100 成功，无缺失贴图/脚本错误；已查看新花园实图。证据 runtime/space-composer/captures/garden.png。

*实现入口*：space_planting.py、space_composer.py、space-examples.json 与 spaces 界面。矩形、椭圆和沿路种植区均为配置，不增加学院特定分支。未更改参考图中的界面、池塘或亭架；仅采用植物分层与围合的设计思路。

*剩余问题*：沿用独立平地场地实验边界。
