# 道路两侧间隙同高

*需求入口*：用户明确小间隙应与道路同高，使两个邻近城区与道路形成整体；原地貌绿化未解决突出道路的问题。

*修改内容*：按真实道路表面高程整平邻近核心间的小间隙，再铺设地表和绿化。道路沿线高程作为基准，保留建筑与核心台地，避免填埋水域和深谷；收边模板改用整平后的高程。

*验证结果*：R23 成功发布，处理 945 格连接地表，其中 383 格实际改变高程；5 项间隙测试与 4 项真实 Java/NBT 集成测试通过，验证道路实际高程作为目标、路面与台地不改写、绿化关闭保留地表。22 条真实方块步行路线全部通过。前端构建、语法与 diff 检查通过；浏览器无脚本错误或缺纹理，近景 runtime/campus-workbench/road-level-gaps/road-gap.png 已目视检查。

*剩余问题*：工作台离线实验适配，未接正式 MC 世界整地与原版树清理。
