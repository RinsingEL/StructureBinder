# 草原行旅建模故障索引

## 备物棚座席、车轴及圆帐边缘挤占使用点

*现象*：SC-10灶前被座椅占据、SC-11弃车站位落在车轴、SC-12水槽靠近圆帐弧形墙，离线检查出现净空与不可达警告。

*首次偏离*：首轮具体家具组合导出验证。

*根因*：局部组合未给座椅外侧扶手、车轴外伸及圆墙收窄留足站位。

*修复*：备物桌后移并延长棚；弃车标记移到轴外；巡路厨房移到圆帐内侧。

*验证*：5项零警告导航与数据通过，110张最终视图全部实看；确定性重建与双哈希、逐图一致性复核通过。

*记录*：[草原行旅核心建模](archive/431b5cef_v0.13.0_草原核心完成/任务记录.md)，实现提交 `431b5cef`、文档提交 `294b070`。

## 守护者水槽与帐柱叠位

*现象*：SC-10使用点实看发现水槽上方被帐柱直接压住，导航虽通过但用途不合理。

*首次偏离*：守护帐内固定家具摆位。

*根因*：水槽占用了圆帐内部承柱基点，覆盖柱脚但留下上部柱段。

*修复*：水槽移至相邻独立位置，保留完整帐柱。

*验证*：重新零警告导出、20张全视图重拍实看并publish；当前双哈希一致。

*记录*：[草原行旅核心建模](archive/431b5cef_v0.13.0_草原核心完成/任务记录.md)，实现提交 `431b5cef`、文档提交 `294b070`。

## 填充家具占用站位与独立包装帐内饰不足

*现象*：四床客帐隔屏占用行李柜站位，乳品/皮革操作岛默认使用点落在台内；双帐型包装帐空间偏空。

*首次偏离*：填充家具组合后的导出检查与作者去顶图审。

*根因*：家具实体与默认站位未一并调整，独立包装功能仅分帐而未布置完整耗材、复核和发货流程。

*修复*：隐私屏后移缩短；主操作点显式落在岛北侧；包装帐增加耗材柜、复核台和出货柜及标记。

*验证*：生活10项221图、工坊28项517图、农牧8项147图全部最终实看publish；修复的双帐两项各25图，数据与导航零警告。

*记录*：[游牧填充建模](active/20260922_草原行旅填充建模/任务记录.md)，待主审集中提交。

## 生活平面同构及弧墙遮挡工位

*现象*：主审退回生活10项，住宅和客帐沿用横隔墙公式，暗家具与地面混同；返修图审另发现六床帐登记和饮水目标上方被弧墙遮挡。

*首次偏离*：按床数和尺寸变体复用同一生活布局；弧墙工位仅检查站位。

*根因*：把尺寸变化当作生活组织变化，功能目标净空未同时视觉核查。

*修复*：重做十种火塘、床榻、家务与公共服务组织，使用浅木家具及织毯；弧墙工位内移。

*验证*：新215张全图实看publish，确定性与数据/navigation零警告；待主审。

*记录*：[游牧填充建模](active/20260922_草原行旅填充建模/任务记录.md)。
