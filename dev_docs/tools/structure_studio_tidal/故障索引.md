# 潮汐珊瑚离线建模故障索引

## TC08 入站梯首级落差

*现象*：首次导航从水上入口仅遍历75节点，全部海床舱点不可达。

*首次偏离*：Y=16入口平台后第一梯级放在Y=15，平台顶到首级顶有一格落差。

*根因*：下行梯序列以平台底面而非平台顶面计算，首级错低一格。

*修复*：梯级整体提升一格，从Y=16降至Y=4，接Y=3舱地板。

*验证*：最终重导出数据/navigation零警告，全部当前截图已实看发布。

*记录*：[任务记录](active/20260922_潮汐珊瑚核心建模/任务记录.md)，未提交。

## TC11 旧书柜观察站位落在护栏

*现象*：观察点 clearance 与 navigation 检查失败。

*首次偏离*：站位Z=34与横桥后护栏相同。

*根因*：观察站位直接指定到桥边，未保留栏杆内一格。

*修复*：站位改至Z=33，保留完整护栏；旧层房间边界同时收紧至实际旧藏区。

*验证*：最终重导出数据/navigation零警告，全部当前截图已实看发布。

*记录*：[任务记录](active/20260922_潮汐珊瑚核心建模/任务记录.md)，未提交。

## 实看补齐边护与塔顶轮廓

*现象*：首轮图中港内横桥、议事庭侧岸、旧馆前缘与旧塔观测平台有局部无护栏边缘；旧塔外壳高墙未表达内部升高路线。

*首次偏离*：边护仅沿主要纵边制作，未覆盖连接段和平台边。

*根因*：初版只核对可达点，漏核周边防落水及楼梯平台边护。

*修复*：补齐边护；旧塔阶顶随实际楼梯上升，后段才保留高观测层。水下站交接舱及生活柜、学馆标本台和阅览柜同步补齐。

*验证*：6项重导出数据/navigation零警告，133张最终图已实看publish，双哈希匹配。

*记录*：[任务记录](active/20260922_潮汐珊瑚核心建模/任务记录.md)，未提交。
