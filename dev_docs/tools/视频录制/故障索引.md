# 视频录制故障索引

## 2026-11-09 草稿模式字幕框过窄

*现象*：第三段在 --preview 下生成 960×540 视频，5 秒位置字幕框过窄、每行文字明显少于 1920×1080 定格画面。

*首次偏离*：record.js 的 preview 模式输出；原尺寸页面截图未见同样问题。

*根因*：字幕框"收紧到文字宽度"时用 getClientRects 量宽度；preview 给 body 加了 zoom 0.5，量出来的是缩小后的宽度，再当成页面像素写回 width，框就窄了一半。

*修复*：量出的宽度除以实际缩放比（getBoundingClientRect().width / offsetWidth）再写回，第二段 act2.html 和 common/stage.js 都已改，提交 `9ef04f1b`。

*验证*：十秒草稿 120 帧完整解码成功，但画面复查发现字幕换行异常。

*记录*：[本地环境与十秒试录](archive/1ac98244b_v0.2.0_第二版视频渲染与故障登记/任务记录.md)，提交 `1ac98244b`。

原尺寸补验：1920×1080、24 fps、十秒 240 帧完整解码通过，5 秒字幕框布局正常，可暂用原尺寸录制。

修复后补验：第三段 4–6 秒草稿，960×540 画面上字幕换行与原尺寸一致。
