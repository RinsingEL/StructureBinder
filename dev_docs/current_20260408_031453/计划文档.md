# Agent 排障 Skill 与 MC 重启占位 Skill 计划

## 本次任务标题

沉淀一套长期可复用的 bug 排查 skill，并新增一个用于后续扩展的 MC 重启进入存档占位 skill。

## 最终计划摘要

本轮不改业务实现，重点沉淀 agent 工作流资产。第一部分是在本机 skills 目录下新增一个面向当前项目的排障 skill，固定“分层真值、阶段闸门、何时需要业务确认、何时 agent 可自行放行”的排查流程，后续排 bug 统一按该 skill 执行。第二部分是新增一个 MC 重启并进入存档的占位 skill，只定义触发场景、边界和未来扩展接口，暂不实现实际自动化。

## 实施步骤

1. 创建本轮 `dev_docs/current_...` 文档并明确本轮只处理 skill 资产，不改业务逻辑。
2. 读取 `skill-creator` 规范，定位本机 skill 安装目录和初始化脚本。
3. 初始化 bug 排查 skill：
   - 明确触发词
   - 明确分层真值顺序
   - 明确 agent 默认自行放行事项
   - 明确必须用户拍板的业务决策点
4. 初始化 MC 重启占位 skill：
   - 明确用途
   - 明确暂不实现自动化
   - 明确后续要补的能力边界
5. 运行 skill 校验脚本，确认结构合规。

## 验收标准

- 本机 skill 目录中新增两个 skill。
- bug 排查 skill 能清楚指导后续按统一思路排查问题。
- MC 重启 skill 已作为占位建好，可后续继续扩展。
- 两个 skill 通过基础校验。

## 关键假设

- 本轮 skill 默认安装到 `C:\\Users\\Rinsing\\.codex\\skills`。
- 本轮输出重点是 agent 自用流程资产，不需要同步到文档仓正式方案。
