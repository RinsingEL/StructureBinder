# Agent 排障 Skill 与 MC 重启占位 Skill 需求

## 用户本次需求摘要

用户希望把本次沉淀出的 bug 排查思路整理成长期可复用的 skill，后续遇到问题统一按该思路排查；同时新增一个“重启 MC 并进入存档”的 skill 占位，留待后续开发。

## 用户特别强调的约束

- 遇到需要业务确认的事情要及时问用户。
- 如果只是工程执行动作，例如打日志、重新测试、重复抓 trace，这类 agent 可以自行放行。
- MC 重启 skill 这次只做占位，明天再继续开发。

## 不做的事情

- 本轮不继续改 solver / catalog / TerraSense。
- 本轮不实现真正的 MC 重启自动化。
- 本轮不扩展无关的新 workflow。

## 当前决定的工作边界

- 重点产出本机 skill，而不是业务代码。
- bug 排查 skill 面向当前项目的多层真值排查流程。
- MC 重启 skill 只先建结构和说明，不接自动化实现。
