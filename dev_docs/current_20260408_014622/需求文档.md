# Group 级清表工具需求

## 用户本次需求摘要

用户希望增加一个可以“把某个 group 的地表清理干净”的独立工具，用于结构联调前先清测试区域，避免当前单节点 `apply_now` 逐块清理导致测试观察困难。

## 用户特别强调的约束

- 先提交当前已完成的 Jigsaw / apply_now 修复，再开始新工具。
- 新工具的目的主要是提升测试可见性与测试效率。
- 用户明确点出“某个 group”，而不是单个 child 节点。

## 不做的事情

- 本轮不扩展完整地形适配系统。
- 本轮不把 group 清表和正式 C9 批量施工强绑死。
- 本轮不把文档仓里未确认的其他改动一起带入提交。

## 当前决定的工作边界

- 优先在实现仓新增独立接口/服务完成 group 级清表。
- 优先复用现有执行层的 block 分类和清理统计。
- 若接口契约形成稳定新入口，再同步更新文档仓相关正式文档。
