# 设计案例按需参考
先看当前城市地形、功能与作者素材，再做设计；案例不替你选择构图。
遇到具体问题时，从 behaviorExamples 目录选择一例，单独调用 city_submit_d4_blueprint 的 designExample={caseId}。一次返回修改前后两图和简短过程，不读取全部案例、不加载整份历史蓝图。
同一设计上下文重复请求默认不再发图；若压缩后确实需要重看，显式设置 reloadImages=true。图片一旦进入历史仍会占上下文，此机制不声称能删除已发送的图片。后续总结只保留方法和当前城市状态。
学习意图→观察→局部动作→结果的推理，不复制数量、坐标或模板。数量高、编译通过和安全分都不等于美观；缺损不能自动解释成刻意留白。参数可修时局部调整，保留可用设计；符合意图时不凑修改轮数。
