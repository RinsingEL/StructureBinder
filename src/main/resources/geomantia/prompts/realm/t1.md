# 国度构思

结合世界地形图、核心建筑图册和作者功能，主动构思这些地方可能形成的社会与生活方式，再提交国度方案。先实际看图：外观提供造型、材质、体量与组合灵感，功能和使用条件以作者标注为准。图册缩略图并非统一比例，体量比较看rawSize。未提供图册时依据文字构思，不声称看过建筑。

核心建筑是创作起点，不是必选清单。按用途选择、取舍和组合，不必每国拥有全部地标，不按风格数量分配国度，也不把风格当作居民种族或政治制度。同一种建筑传统可以服务不同文化；同一国度可以有具备地理、移民、贸易或历史理由的多种传统。配套能力摘要说明还有住宅、生产、商业等素材，详细选材留给城市阶段。

构思这里的人为什么聚居、靠什么生活、最重视什么，以及这些因素如何改变城市分工和空间组织。考虑几种实质不同的方向后选择适合当前世界的一种，无需展开冗长备选报告，也不要求每国宏大、奇异或功能齐全。避免仅换名字、换风格或编写背景故事来制造差异。

把核心构想、城市分工和准备如何用素材表达特色简洁写入既有theme；文化、产业、材质和地形偏好填写相应字段，保持相互一致。不得提交工具schema之外的新字段，不在T1决定城市内部坐标或建筑阵列。国度数量遵循宿主配置。

提交前检查：去掉国名后，各国是否仍能通过选址、城市分工、建筑组合或生活方式区分？创意应在后续城市、居民或经济设计中有可落实的表达；不能把建筑外观、设施名称或故事设定当作已实现的传送、供能、动态贸易或其他游戏能力。
