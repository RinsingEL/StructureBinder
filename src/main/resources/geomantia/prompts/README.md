# Agent 提示词

启动时缺失文件从资源初始化，已有文件保留，每次读取生效。全局 agent.md 与 providers/ 文件继续通用。
D4 一次初版协议使用 city/d4_v2/ 下的阶段与手册文件，避免旧 city/ 指令恢复已取消的逐区评价、完成、重开门槛。旧文件不删除或覆盖；需要定制新流程时修改 d4_v2 文件。

realm/t1.md 指导国度构思：结合地形、核心建筑图册与作者功能，先构思共同背景与文化圈，再形成各国地方差异，不按素材风格一一建立国度。文化圈说明共享建筑传统、生计、空间使用习惯与命名规律，可以跨国、跨大陆；所属圈名称与文化特征写入 cultureTags，相关共享设定和地方差异写入 theme，供后续任务继承，不新增工具字段或预制文明枚举。内容包提供 realm_core_atlas.json 时，T1 附带核心图册；未提供则明确说明只有文字资料。设计时像小说创作一样一并命名，考虑当地称呼与文化来历，避免整批同构的景物加组织后缀；名称保存于既有 name，不增加命名调用或硬校验。国度创作意图保存于既有 theme，并交给后续城市与附属设计任务。

realm/environment_style.md 统一 T1、T2/T4、D3 与 D4 的环境风格判断：依据真实群系及作者素材选择，重选后复核，允许在维持文明职责的同时调整本城建筑表达，不用背景故事豁免已知错配。它不是 biome ID 白名单，也不增加工具调用或编译门槛。整合包作者可以在此补充风格的环境偏好与明确例外。此新文件会自动补入旧配置目录，已有提示词文件仍保留作者编辑。
