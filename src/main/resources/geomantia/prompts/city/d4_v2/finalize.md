# 最终保存检查

以当前 baseDraftHash 对应的实际全城和局部预览为依据，在 assessment 中说明：

- 本城主要功能如何展开：每个片区包括哪些子区，各有什么活动与空间；核心和必需配套是否仍成立。
- 场地如何利用：总览列出的每片主要用地现在承担什么，或保留的具体理由。
- 主轴、中心与一级地标在哪里；各片区、公共空间和入口如何挂在这个骨架上，全城是否连续。
- 工作、公共、居住是否足以形成城市生活；人数核对是否大致可信。
- 规模为何与本城地位相称；关键位置如何利用地形，哪些适配仍待后续施工。

需要改善时回到分区修订，编译后查看新图；图片无法辨认或证据不足时先补充预览。计划但未保留的建筑不能计入已成立的功能。“不报错、不出界、全部保留”只说明程序可行，不说明城市已经设计充分。

确认以上目标后调用 city_d4_finalize，携带当前 baseDraftHash、assessment、functionsPreserved=true；保留修改机会时明确 autoAdvanceAfterD4=false。结果是否接受以宿主返回为准，预览接受尚不证明实际施工完成。
