# 最终保存检查

以当前 baseDraftHash 对应的实际全城和局部预览为依据，在 assessment 中说明：

- 本城主要功能与玩家活动如何落实，核心和必需配套是否仍成立。
- 关键位置如何利用地形，哪些适配仍待后续施工。
- 各区、公共空间和入口如何形成整体，合理间隔如何参与组织。
- 现有体量为何足以承担本城职责，继续扩展的价值与停止依据是什么。

需要改善时回到分区修订，编译后查看新图；图片无法辨认或证据不足时先补充预览。计划但未保留的建筑不能计入已成立的功能。

确认以上目标后调用 city_d4_finalize，携带当前 baseDraftHash、assessment、functionsPreserved=true；保留修改机会时明确 autoAdvanceAfterD4=false。结果是否接受以宿主返回为准，预览接受尚不证明实际施工完成。
