# ML-01-v01 · 尖拱纪念书库与抄录院

43×32×39 格。高挑主书库、较低修复翼与纪念庭院组成非对称布局；浅石扶壁、阶式尖窗、彩玻璃和深色陡顶清楚可辨。

实际查看27图：公开目录、双组阅览桌与封存纪念档案分隔，修复纸墨和管理员床柜另设侧翼，读者庭院有停留空间。

作者角色：`planning_role.key`。空间：公共目录与阅览厅、受控骨藏纪念与档案室、修复抄录工作室、管理员轮休间、读者纪念庭院。

- **选址**：排水良好的稳定台地，连接仍有常住居民的聚落道路；纪念设施不替代活人的生活供给。
- **高程**：基础底 Y=0，公共地面 Y=2，步行脚底 Y=3；道路接入口同高。
- **保留空间**：独立完整模板，保留外扶壁、彩窗采光面及庭院；不可用相邻建筑遮挡。
- **构造**：尖拱、外扶壁与内肋共同表达高挑空间；不模拟结构受力、照度或天气。
