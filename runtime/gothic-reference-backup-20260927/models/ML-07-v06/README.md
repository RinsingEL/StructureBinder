# ML-07-v06 · 通廊三间值守家庭宅

23×29×38 格。窄长宅采用宽前厅、侧廊和两个独立双床间，四人家庭夜间进出不穿过他人床位；廊侧工具与记录成套设置。

狭长宅用侧廊连接两间独立双床房，前宽餐厨厅及侧廊记录工具均有使用空间。

- **选址**：稳定、排水良好的居民地块，日照与通路按具体用途保留；哥特是建造风格而非地形限制。
- **高程**：基础底Y=0、常规地面Y=2、脚底Y=3；抬高或双层版本另记。
- **边界**：完整独立模板，保留外扶柱、檐口、采光和门外站位，不默认邻居补齐。
