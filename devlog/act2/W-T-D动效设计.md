# W → T → D 动效设计说明

设计：Claude，2026-10-26。实现交给 Astra（GPT）。本文只规定观感、节奏和文案口径，技术细节由实现方决定。

## 一句话方向

**不是幻灯片，是一张地图和一个镜头。**

整场只有一张持续存在的地图。观众看到的是一个慢慢推近的镜头：世界 → 国度 → 一座岛 → 一座城 → 实机。场景之间不翻页、不转场，只移动镜头、增减图层。

参照物：老测绘图册、野外考察手账。不要参照：产品发布会、宣传片、数据大屏。

## 现在为什么像广告

| 现象 | 例子 | 改法 |
|---|---|---|
| 每页都有大标题和副标题 | 「看一次真实的设计迭代 / 工具反馈改变下一步，地图也随之改变」 | 删掉标题。只留左上角小号阶段标签 |
| 文案在升华，而不是在陈述 | 「这条路，终于回到玩家脚下」「地图上的选择，成为脚下的空间」 | 只写名词、数字、地名、坐标 |
| 信息装在卡片和面板里 | 左侧调用卡片 + 右侧图 + 底部导读 | 地图铺满，文字作为图注贴在地图上 |
| 示意图冒充过程 | 7×11 假网格扩张 | 用存档真实数据驱动 |

## 画面版式（16:9）

```
┌──────────────────────────────────────────────┐
│ W · 扫描                                      │  ← 阶段标签，左上，12–14px
│                                              │
│                                              │
│               地图（铺满上部 ~78%）            │
│                                              │
│                                              │
│ 图注一行                       来源 · 真实数据 │  ← 左下图注 / 右下来源角标
```

- 没有页眉、页脚、进度条、Logo。
- 底部安全区内不放任何内容。

## 色彩与字体

纸面而非屏幕。整体低饱和，像墨和矿物颜料。

| 用途 | 颜色 |
|---|---|
| 纸 | `#F2EEE4` |
| 墨（文字、边界线） | `#2B2A26` |
| 次要文字、网格 | `#2B2A26` 30–45% 透明度 |
| 海 | `#A9BCBC`，深水略深一级；可加极细水平排线 |
| 陆地高程 | 4 级：`#E6E1CC` → `#D6CCAF` → `#C4B594` → `#A8987A` |
| 七个国度 | 石青 `#5E8C9A`、赭石 `#B07A4F`、藤黄 `#C9A63E`、胭脂 `#A65E66`、松绿 `#5F8A6A`、黛紫 `#6E6487`、灰绿 `#8A9478`；填充 30–40% 透明度，边界用墨色 1.5px |

- 地名、国名：衬线中文（思源宋体 / Noto Serif SC）。
- 数字、坐标、工具名：等宽（JetBrains Mono / IBM Plex Mono），小号。
- 不用渐变、发光、阴影、毛玻璃。

## 动效原则

1. **数据决定节奏。** 扩张快慢来自真实认领代价，不按"好看"的曲线随便调。
2. **慢，稳，停得住。** 缓动统一 ease-in-out；不弹跳、不过冲、无粒子、无光晕、无闪烁光标。
3. **每一拍结束于静止画面。** 讲解可能聊很久，画面必须能一直停着。
4. **演讲者控制。** → 下一拍，← 上一拍，F 全屏。不自动播放。
5. **镜头连续。** 推近时保留上一层的淡影（例如推到城市时，国界线仍以 15% 透明度留在背景）。

**节奏原则：一组讲透，其余快放。** 只拿南宿院一个组团，把"选素材 → 写规划 → 展开阵列"慢慢走一遍，让观众学会这套画面语言；之后的修改沿用同一套语言，最后其余各区一起快速展开。不逐组重复，也不整城只放一遍。

- **展开** = 虚线框逐个变成实心轮廓（墨线 + 浅填色），之后再补院子和路。

> 先核对存档或日志里有没有展开后的真实占地数据（建筑轮廓和位置）。

> 素材小卡同理：能从素材目录取到真实俯视轮廓就用真实的；取不到就只写建筑名和用途，不画假轮廓。

## 文案规则

**只写"是什么"，不写"意味着什么"。** 意义交给对话去讲。

- 每屏最多一行图注，不超过 18 字。
- 可以写：名词、数字、地名、坐标、工具名。
- 不写：抒情句、对仗句、问句、破折号金句。
- 不用这些词：终于、每一步、成为、旅程、走进、回到、见证、诞生。

| 不要 | 要 |
|---|---|
| 地图上的选择，成为脚下的空间 | 镜潮 · (−2928, 5392) |
| 每靠近一步，前面的选择都留下线索 | 局部地形 |
| 国度和城市，逐层有了位置 | 七个国度的起点 |
| 这条路，终于回到玩家脚下 | （实机图，不放字） |

## 真实性角标

右下角统一格式：`来源 · 类型`，类型只有三种：

- **真实数据**：直接由存档或日志渲染。
- **近似**：用真实数据，但顺序或时间经过简化。
- **示意**：没有对应数据，只解释原理。

字号 11px，墨色 40% 透明度。只放在角标里，不进图注，也不进台词。
