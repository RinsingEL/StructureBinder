## 文件与检查结果

- 40 张都是独立单人 RGBA PNG，实际输出 **1254 × 1254**，保留原生透明通道。不是旧标准里的 1024 × 1024；合成显示时可等比缩放，尚未另外导出 1024 版本。
- 初批 listen / d4 两张图尺寸一致；以 alpha > 128 的外接框检查，四边位置差最大 2 像素。外接框稳定不等于内部轮廓像素完全相同，切换仍需通过预览检查。
- 逐张检查了人物身份、主要道具、开闭嘴和全身完整性。不同人物的头部大小、脚底高度未做精确统一，预览页按原图同尺寸展示，不掩盖这些差异。
- 透明边缘在放大时仍可能见到少量彩色细点；本批未进行破坏原 alpha 的绿幕去色。正式成片前需在实际显示尺寸下复核边缘。
- 两种比例的名字用于比较，不代表头身数已逐人严格测量验收。
- 预览页已生成；自动浏览器因本地文件协议限制未能打开，尚未完成浏览器内交互及白／深灰背景视觉验证。可在本机手动打开 `previews/compare.html` 检查。

这是素材预览，不是小克最终 D4 测试画面。无 TTS、无字幕节奏、无成片验收。
