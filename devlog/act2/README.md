# 山水间的异世界

Geomantia 社团开放日第二幕的动态网页 PPT。打开 `index.html` 即可离线播放。十一段画面从 W 世界粗扫、T 国度与城市规划走到 D 单城设计和实际落地，普通段落四步，D4 调用回放九步，附台词：前三段为茶话会现场记录，后八段保留 Claude 预写并补入 Astra 连续讲解稿（尚未录制）。预计 12～15 分钟，可按聊天伸缩。

左右方向键分步展开，上下方向键切换段落；空格播放当前段落，末尾自动停下。数字 1～9 直达前九段，0 到最后一段。N 显示或收起串词，F 切换录屏模式，Esc 返回。打印可得到各段最后一个状态的静态页面，动效请使用网页播放。

“换成本页图片”允许选择本地 PNG、JPG 或 WebP。换图暂存在当前页面，“保存演示”将图片与全部脚本一起存入独立 HTML。图片不会上传，关闭前请保存。恢复按钮可还原原始画面。

[第二幕分页与串词](第二幕_分页与串词.md)随演示同步生成。修改 `content.json`、`template.html`、`visuals.js` 或图片后，运行 `node build.mjs`。无需额外依赖。`index.html` 包含全部图像，只转发这一个文件即可播放。

真实产物、原理动效和实机画面均注明来源。W/T 使用本机已有存档图包，D 阶段使用历史学院案例，不能视为同一轮完整验收。详见 [素材来源](素材来源.md)。Claude 的 [主讲方案](Claude主讲方案.md)保留为上一版单城叙事参考，当前演示以用户最新确认的全流程框架为准。

D4 调用回放已核对 2026-10-20 原始 JSONL，展示九步节选；选点和平移使用真实 anchorBlock，组团轮廓仍为原理示意。公开请求与返回见 replay-evidence.json，未附原始会话。它不会连接 MCP 或重新执行游戏操作。

[Astra 单人连讲稿](Astra_第二幕连讲稿.md)仅收录 Astra 台词；后八段新增 19 段，可配合画面连续讲述，其余伙伴原句保持不变。
