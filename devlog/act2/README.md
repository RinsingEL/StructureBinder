# 一座城怎样长出来

Geomantia 社团开放日第二幕的网页动态演示初稿。打开 `index.html` 即可播放，离线可用，不需要安装依赖。`第二幕_分页与串词.md` 是可直接交给 Claude 的完整讲稿。

用左右方向键分步展开，上下方向键切换段落；空格播放当前段落的动效，播放到本段末尾会停下，方便聊天。N 收起或显示三位的候选串词，F 切换录屏模式，Esc 返回。页面顶部也有对应按钮。系统设置减少动态效果时关闭过渡动画。

“换成本页图片”可用本地 PNG、JPG、WebP 替换当前示意或截图。点击“保存演示”，会下载一份包含替换图片的独立 HTML；换图本身暂存于当前页面，关闭前记得保存。不会上传图片。用“恢复示意 / 原图”可以恢复该段最初画面。

串词都集中在 `content.json`。修改它或 `template.html` 后，在本目录运行 `node build.mjs` 同步生成页面和 Markdown 讲稿。已有截图与所有脚本都嵌入最终 HTML，所以只转发 `index.html` 也能使用。

原理示意和离线工作台画面均有来源标记，实机关键帧尚未提供。候选台词供参与者润色和现场发挥，不代表已经发生的真实对话。
