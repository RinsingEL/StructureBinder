# 乐器分配与云端写曲工具

本说明只提供当前可用的音源、乐器分配和制作工具。作曲与编排由你独立设计。

## 写曲与音频工具

- **Python**：编写音符、控制器和自动化数据。
- **mido**：生成、读取和编辑 MIDI。
- **GeneralUser GS 2.0.3**：当前使用的 SoundFont 采样音源。
- **tinysoundfont 0.3.7**：加载 SoundFont，把音符渲染成音频。
- **NumPy / SciPy**：音频数组、滤波、音量曲线和其他信号处理。
- **imageio-ffmpeg 0.6.0 所带 FFmpeg**：导出、编码音频及合成视频。

也可以用自己熟悉的 DAW 与工具。上述组合支持离线渲染音频，无需先安装完整 DAW。云端环境请自行确认 Python 与依赖是否可用。

## 云端资源准备与相对路径

以下路径均以你在云端检出的仓库根目录为基准，与仓库在机器上的绝对位置无关。

| 用途 | 建议相对路径 |
| --- | --- |
| 独立试作输出 | `devlog/音频/claude_trial/` |
| 自己编写的作曲脚本 | `devlog/音频/claude_trial/compose.py` |
| 可选的隔离 Python 环境 | `.tools/devlog-audio/.venv/` |
| SoundFont 音源 | `.tools/devlog-audio/soundfonts/GeneralUser-GS.sf2` |
| 音源许可原文 | `.tools/devlog-audio/soundfonts/LICENSE.txt` |

这些是约定的存放位置，不表示文件已存在。原本机的依赖、SoundFont 和生成音视频没有随 Git 上传；云端需要自行安装依赖并获取音源。

### 获取工具与音源

- Python 包：`mido`、`numpy`、`scipy`、`tinysoundfont`、`imageio-ffmpeg`。根据云端操作系统安装兼容版本；无需复用本机 Windows 二进制文件。
- [TinySoundFont Python 项目](https://github.com/amberwhitehead/tinysoundfont-pybind)：用于 SoundFont 离线音频渲染，安装与平台依赖参照项目说明。
- [GeneralUser GS 作者网站](https://www.schristiancollins.com/generaluser.php)：音源下载与许可入口。
- [GeneralUser GS 官方仓库](https://github.com/mrbumpy409/GeneralUser-GS)：根目录 `GeneralUser-GS.sf2` 为音源，`documentation/LICENSE.txt` 为许可。下载后分别放入上表的音源及许可路径。

上述工具链接仅供获取工具和音源。请根据本文乐器分工独立作曲。

## 云端安装（Python 3.12）

从仓库根目录执行。以下示例使用 Linux 环境；Python 自行在云端准备，不需要复制本机解释器。

```bash
python3 -m venv .tools/devlog-audio/.venv
.tools/devlog-audio/.venv/bin/python -m pip install -r devlog/音频/requirements.txt
.tools/devlog-audio/.venv/bin/python -m pip install --no-deps tinysoundfont==0.3.7
```

TinySoundFont 单独安装是因为它的包元数据默认依赖 PyAudio。离线加载音源、生成音频使用 `Synth.sfload()` 和 `Synth.generate()`，不调用实时声卡播放的 `Synth.start()`，因此不需要 PyAudio/PortAudio。`--no-deps` 仅用于这一步；其余依赖按清单正常解析安装。

若平台没有可用的 TinySoundFont 预编译包，可能需要 C++ 编译工具。上述路径是 Linux 虚拟环境布局；Windows 对应解释器位于 `.tools/devlog-audio/.venv/Scripts/python.exe`。

音源通过上面的作者网站或官方仓库自行下载，放到约定位置并保留许可。`.tools/` 已由仓库根目录忽略；不要提交解释器、虚拟环境、包缓存或音源文件。
