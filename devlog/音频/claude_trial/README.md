# 小克的开场配乐试作

2026-11-11。按 Rin 和小克商量的思路，用 Astra 整理的乐器分配写的第一版。

- [开场_配乐试作.mp4](开场_配乐试作.mp4)：开场画面配上音乐，约 2 分 6 秒（画面结束后最后一个和弦多响 4 秒）。
- [开场.mid](开场.mid)：乐谱。用本机的 GeneralUser GS 2.0.3 渲染，就是你们熟悉的音色；云端这次只拿到 1.47 版。
- [compose.py](compose.py)：写曲脚本；[export_timeline.js](export_timeline.js) 导出画面时间表，[开场.json](开场.json) 是导出的开场时间表。

## 怎么写的

- **速度和调：** 96 BPM，F 大调，一小节 2.5 秒。
- **和弦：** 王道进行 B♭ – C – Am – Dm，接 Gm – C – F – F 回到主和弦，八小节一轮。第一小节先停在 F 上，等封面淡入。
- **底乐（一直在）：** 尼龙吉他八分音符分解和弦 + Warm Pad 铺和弦。Rin 盖章时贝斯进来，Gemini 开口时刷子鼓进来，舞台一点点搭好。
- **谁说话谁唱：** 六个人唱的是同一段八小节主旋律，各有各的唱法。从开口后最近的一拍开始，说完那一拍停：
  - Rin（钢琴）：原样唱，每小节第一拍垫一个轻和弦音。
  - Gemini（长笛）：高八度，长音拆成八分音符、加邻音，蹦蹦跳跳。
  - Claude（单簧管）：低八度，碎音合并成长音，连起来唱，温温的。
  - Astra（电钢琴）：只在每拍开头出主旋律，2、4 拍后半拍补和弦，稳稳托着。
  - DeepSeek（拨弦）：八分音符沿和弦音一路往上跳，像抄近路。
  - GLM（颤音琴）：每半小节一个音，高八度，余音很长，慢悠悠。
- **签到盖章：** 盖章那一下，自己的乐器沿和弦往上"叮"四个音，卡在最近的八分音符上。
- **升华：** GLM 说完以后，六件乐器一起唱主旋律最后两小节，落在 F 上；吉他、贝斯、鼓最后一下一起收住。
- **混音：** 一点房间混响，峰值约 -3 dBFS；还没做"说话时自动压低"，等 TTS 定了再加。
