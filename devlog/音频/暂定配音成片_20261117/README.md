# 暂定音色成片试听：开场与第二段

本轮使用用户确认的“原版 Claude + 当前 GLM”五人音色。开场复用已确认的 5 段录音，第二段新生成 62 句，使用 Fish `s2.1-pro-free`。全部为独立试听输出，原 HTML、配乐源码与旧视频未覆盖。

## 成片

- `01_开场_暂定配音.mp4`：约 2:07。
- `02_第二段_暂定配音.mp4`：14:40。
- `开场至第二段_暂定配音.mp4`：两段连续播放版本，约 16:47。

均为 1920×1080、24fps、H.264/AAC。最终导出是否完成及解码验证见 `delivery_check.json`。

## 声画处理

- Gemini PR #73 / `全片配乐_v6` 原曲与乐器分配保留，108 BPM，不随台词改变速度。
- 真人声正常速度播放；少数过长句子让后续开口延至下一拍，再利用之后的余量回到原时间轴，总时长不变。
- 字幕卡使用本地语音识别的字词时间定位，字幕文字仍保留原脚本，不用识别结果改写台词。参考音文本没有重新识别。
- Rin 使用用户确认的上滑气泡单音，约每秒 8.7 次，在逐字显示期间持续触发；文字显示完后停止，字幕保留安静阅读时间。
- 人声居中，配乐在人声期间平滑降低约 7.5dB，Rin 提示音期间降低约 3dB；最终混音约 -18.5 LUFS。
- 第二段 PPT 翻页跟随对应字幕卡调整，镜头与原画面结构保留。

## 可复用材料

- `voices/`：各句 API 原始音频、生成记录、清单，可断点续跑；不含密钥。
- `*_人声与气泡.wav`、`*_Gemini配乐.wav`、`*_混音.wav`：分轨和混音。
- `timeline_*_配音.json`、`*_字幕.srt`：实际字幕时间。
- `*_配音预览.html`：独立预览页，媒体资源引用原项目。
- `mix_report_*.json`：声音开始/结束、字幕定位、时间偏移及响度。

`generate_voices.py`、`render_score.py`、`align_voices.py`、`build_stage.py`、`record.cjs` 保存本次制作方法。依赖本机已有音频运行环境和隐藏 Chromium；网页预览路径中包含本机绝对 base URL，迁移电脑时需重新生成 HTML。

本轮完成的是前两段；第三至第五段尚未合成配音或导出成片。
