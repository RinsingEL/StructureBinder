# 社团开放日：最终剪辑与网页编辑器

2026-11-22 用户已完成全片听审并确认发布。当前最终工程为 [最终剪辑 JSON](定稿_20261122/最终剪辑_配乐气泡均为负10dB.json)，最终成片采用 [第二段 PPT 时序修订](定稿_20261122/PPT时序修订/README.md)。约 37:40、五幕、188 个人声片段、339 张字幕卡；配音原速，BGM 与 Rin 气泡音轨均为 -10 dB。

## 恢复与打开

Git 保存源码、时间轴、最终工程与核验数据，不包含本目录的大音频与 MP4。仅克隆仓库不能完整试听，需另备素材包；当前素材包仅保存在制作电脑，尚无公开下载地址。

1. 切到 `codex/devlog`，将对应素材包按包内相对路径解压到仓库根目录。
2. 在仓库根目录运行 `python "devlog/音频/全片配音_20261118/media_bundle.py" check`，核对 432 个素材文件的大小与 SHA-256。
3. 运行 `python "devlog/音频/全片配音_20261118/serve_preview.py" --port 8790`（Python 3.10+，服务本身仅用标准库）。
4. 浏览器打开 http://127.0.0.1:8790/devlog/音频/全片配音_20261118/editor.html 。
5. 顶部“导入”选择上述最终剪辑 JSON；打开页面不会自动覆盖或导入浏览器草稿。

草稿存于当前浏览器、当前访问地址的 localStorage。导出工程 JSON 包含已保存的各幕状态，不只当前幕；它不内嵌音频。换电脑必须同时携带素材包，尤其是 `imports/` 中的局部替换录音。

## 编辑

- 空格播放/暂停当前幕；输入文字时不抢占空格。
- A1 配音块：拖动移动、拖左右边裁剪，S 分割，Delete 删除，双击打开大波形。
- 大波形中单击定位，拖动选区，左右边界独立调整；可压低、静音、删除并保留空位，或只接合当前片段。
- 右侧“替换录音”可选择本地 WAV/MP3 等浏览器支持的文件，替换选中块或整句；原文件保留。替换后检查时长造成的空隙/重叠。
- S2 单张字幕可独立移动并修改起止时间。屏幕台词修改不重新生成配音，独立配音剪辑也不强行移动字幕。
- BGM、人物配音、Rin 气泡为独立音轨。Rin 固定 600×170 文本框，逐字显现后保留阅读时间。

## 生成与渲染

`prepare_editor.py` / `prepare_preview.py` 是最初生成工程的工具，会重写元数据或预览页面。日常打开、恢复和剪辑无需运行它们；特别是已有的候选录音版本不要被重新初始化覆盖。

最终渲染入口在 `定稿_20261122/render_final.py`，使用已冻结的 `render/*_cards.json` 和最终工程重建分轨混音与 HTML。若继续改字幕或时间轴，必须重新导出 cards，不能把旧 cards 用作新工程。视频帧由相邻 `暂定配音成片_20261117/record.cjs` 录制，`assemble_final.py` 合并各幕、章节和 SRT。渲染需要 NumPy、SciPy、imageio-ffmpeg、Node.js、Playwright/Chromium；Playwright 安装在 `devlog/视频素材/tools/`。

第二段 PPT 修订由 `editor_bridge.js` 与渲染器共同实现。全片完整解码、字幕数量与时序已验证；修订前后第二段解码音频哈希一致。证据在 `定稿_20261122/PPT时序修订/`。网页实时音乐压低与离线确定性采样不承诺逐样本一致。

网页没有“一键导出成片”按钮，渲染仍是单独流程。旧 `audioEdits` 形式的破坏式编辑尚未接入最终渲染；当前定稿使用独立 clips，不受此限制。

## 素材备份

`media_manifest.json` 是相对仓库根目录的冻结素材清单，包含原录音、编辑干声、替换录音、BGM、气泡和本机图片依赖。`media_bundle.py check` 只校验，不调用 TTS；`pack --output <新文件.zip>` 校验后打包，不覆盖已有 ZIP。该包不含最终 MP4，成片另行保存。

服务默认只监听本机并按 `access_manifest.json` 提供精确文件白名单。本地导入录音保存在 `imports/<SHA256>.wav`。不要用普通文件服务器直接公开整个仓库。

`节奏排查/` 和 `第三段Astra排查/` 是剪辑前的定位候选，不代表定稿仍存在这些问题。历史试音、缓存、旧成片均保留本机，不作为当前版本入口。
