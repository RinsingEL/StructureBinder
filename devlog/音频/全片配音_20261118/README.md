## 时间轴编辑器（新增）

`index.html` 现在转到 `editor.html`；原版连续预览保留为 `preview.html`。

- 下方五条轨道：实时画面、字幕/人物、配音、BGM、Rin气泡。标尺点击定位，拖动片段调整起点。
- 配音与字幕/人物默认联动；取消勾选可单独移其中一项。Rin气泡随其字幕区间移动。
- 右侧可改屏幕台词、表情、开始秒数、配音片段音量；音轨支持静音/音量。修改屏幕台词不生成新的语音。

- 草稿保存于浏览器 localStorage（devlog-editor-20261118-v1），可导出/导入工程JSON、撤销、恢复本幕原版。建议导出JSON备份；该JSON不包含音频和图片。

## 新增句内音频编辑

选中配音可在右侧拖波形选择片内区间，支持压低15dB、静音、删除或仅保留选区，带5ms边缘淡化，可导出剪好的干声WAV（不含轨道音量/BGM）。操作保存在JSON草稿，不改原素材。下方S2单张字幕可拖动，右侧可设置单卡起止时间。删除音频仅缩短当前配音，字幕不自动强行对齐、后续录音不自动前移；用S2人工调整。音频编辑后的整片视频导出仍未实现。

## 新增独立音频片段时间轴

A1 每块配音均可双击进入大尺寸波形编辑窗口，左侧波形、右侧参数。波形显示真实LR声道（单声道素材显示Mono），选区左右边界可分别拖动。单击波形定位播放头，拖动建立选区。

- 选中 A1 音频块，把播放头放在块内，按 S 或点“分割”。
- 切开的每一块可以单独拖动、Delete 删除、拖左右边裁剪。字幕不自动跟随独立音频块。
- 选区删除可保留空位，或只让当前片段后半段接合；不会自动移动其他配音和字幕。
- 参数、源in/out和独立增益保存在工程clips列表中，音频原文件不变；撤销和JSON导出/导入保留这些操作。
- 播放以片段列表为准，BGM压低也跟随编辑后的片段。修改后视频导出仍未接入。

## 直接选择本地录音替换

右侧替换录音新增“选择本地音频文件并替换…”：浏览器解码用户选择的WAV/MP3等支持格式，转换为PCM WAV，保存到本机imports/内容哈希.wav，草稿以importedAudio和audioChoice引用。原录音不覆盖，旧版本可切回。替换对象为当前整句配音；已有分割裁剪时先确认清除该句的音频剪辑，字幕及其他句保留。工程JSON仅保存导入素材路径，换电脑需要连同imports目录一起携带。导入接口只接收localhost同源有效PCM，并固定写入imports目录；不接受自定义写入路径。

## 部分替换

先在A1用S切出要替换的范围，选中该块；右侧替换范围选择“只替换选中片段”，再选择本地文件。新声音替换该块，其余块继续使用原音源，字幕与后续录音的位置不自动移动。时长不同时请检查缝隙或重叠，再拖动音频/字幕。工程JSON记录sourceId，换机器时需携带imports素材。下方候选版本切换按钮仍针对整句。
