# 开场到第二段：可编辑配乐参考工程 v4

本工程是 Astra 已制作、用户反馈“感觉还可以”的 5 分 02 秒连续样片源码。用户希望小克参考 MIDI、乐句处理和同步方法，避免重复前几轮的问题。它是参考版本，六人音色与完整成片音乐尚未最终确定。

## 从哪里看起

1. [打开或下载 MIDI](开场至七国_同步配乐.mid)：直接在支持 MIDI 的软件中查看 10 个乐器声部、速度事件、角色落点标记与 CC11 曲线。
2. [经验与问题定位](参考经验.md)：说明节拍、音画同步、角色合奏、表情曲线和长段落疲劳问题。
3. [画面落点](hit_points.json)：角色发言时间、视觉目标帧、对应拍位与速度映射锚点。
4. [编曲源码](make_preview.py)：`PARTS` 是乐器分配，`harmony()` 是和声，`background()` 是伴奏节奏，`phrase()` / `build_score()` 是角色乐句与回应，`expression()` 是音量表情。
5. [展开的音符与曲线数据](score_events.json)：`notes` 每项为 `[起音秒, MIDI音高, 时值秒, 力度]`，`envelopes` 保存连续表情包络控制点。
6. [渲染器](renderer.py)：SoundFont 离线渲染、滤波、分轨电平、轻压缩和 WAV 输出。
7. [渲染报告](render_report.json)与[基准样片技术检查](quality_check.json)：用于复核参数和技术时序，不代表主观听感已通过。

## 当前音乐结构

Rin 用钢琴，Gemini 用长笛，Claude 用单簧管，Astra 用电钢琴，DeepSeek 用拨弦弦乐，GLM 用颤音琴。伴奏是尼龙吉他、原声贝斯、轻打击和薄铺底。完整音色/工具信息见[配器与工具说明](../配器与工具说明.md)。

角色共享一个短动机，以不同节奏和奏法接话；较长发言有后续乐句，交接后上一件乐器有时继续轻声回应。当前角色区别仍较简化，不是六首完整角色主题。

| 时间约 | 内容及伴奏变化 |
| --- | --- |
| 0:00–2:03 | 标题、欢迎、六人介绍，角色乐器接力和合奏 |
| 2:03–2:20 | Rin 引入流程，逐渐收轻 |
| 2:20–2:30 | 空白世界，稀疏伴奏 |
| 2:30–3:07 | 扫描地图，规整脉冲 |
| 3:07–3:34 | 山海地形，撤掉打击、长音舒展 |
| 3:34–4:15 | 国度与生活，轻切分 |
| 4:15–5:02 | 选址，交替拨弦与低音 |

D 大调为主，接近 108 BPM，按乐句映射在约 104.94–113.68 BPM 间变化，服务于视觉落点。这些是当前作品的选择，不是后续作曲的固定要求。

## 云端复现

需要 Python 3.12、[依赖清单](../requirements.txt)以及 GeneralUser GS 2.0.3。依赖安装步骤、下载地址和许可见[工具说明](../配器与工具说明.md)。也可以直接使用用户传送的 SoundFont 文件。

从仓库根目录执行，只生成 MIDI / WAV / MP3：

```bash
python devlog/音频/开场到第二段_v4/make_preview.py --audio-only
```

音源默认位于 `.tools/devlog-audio/soundfonts/GeneralUser-GS.sf2`；如果在其他位置：

```bash
python devlog/音频/开场到第二段_v4/make_preview.py --audio-only --soundfont /path/to/GeneralUser-GS.sf2
```

使用你已安装依赖的 Python。代码也兼容本机 `.tools/devlog-audio/python/` 包目录，但该目录不是运行必需条件。无需本机 Windows 解释器或二进制包。

若需要合成同一段画面，先获取仓库 Git LFS 管理的 `devlog/视频素材/第二版完整版/开放日_完整版.mp4`，再去掉 `--audio-only`。输入为源视频前 7250 帧，24 fps，302.083 秒。LFS 指针文本不能充当真实视频文件。

生成文件写在本目录，临时混音写在 `.tools/devlog-audio/`。执行会重新生成本目录的 MIDI、音符数据和报告；改写自己的版本前建议复制工程目录到同层新目录，或另开分支。音视频与音源没有随本参考工程提交。

## 声音与验证边界

实际使用 GeneralUser GS SoundFont + TinySoundFont，未依赖 FL、Splice 或 BBC 插件。`renderer.py` 的渲染函数从先前小样直接抽取，工程不再依赖未提交的旧小样目录。

角色声部有连续音量表情，电钢琴/吉他/贝斯做轻压缩，声部共享短混响。采样音源没有真实木管连奏过渡，简单音量曲线也不等于多层演奏动态。

MIDI 保留表情参考，但不同合成器对 CC11、音色、混响的响应不同，不承诺 MIDI 播放与基准 WAV 完全一致。当前音画检查采用独立声部 5 ms RMS 窗口、局部峰值 25% 阈值估计起音，0–5 ms 的结果只是技术指标。

当前五分钟样片尚不代表整段 14 分钟讲解或 35 分钟成片的最终接受度。
