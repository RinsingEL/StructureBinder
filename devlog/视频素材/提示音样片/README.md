# Rin 的提示音样片

2026-11-10。Rin 的台词不配真声，改用"啵啵啵"的提示音（像偶像大师里不出声的制作人）；其他小伙伴用 TTS。这里是三种音色的样片，每个约 34 秒，挑了 Rin 五句不同情绪的台词：

| 顺序 | 台词 | 情绪 |
|---|---|---|
| 1 | 5-1 到这里，我们社团开放日的展示就结束啦，非常感谢大家耐心看完～ | 感谢 |
| 2 | 3-9 更搞笑的是，4 月当时行不通的方案，9 月行得通了： | 开玩笑 |
| 3 | 3-14 哈哈好，那时间线小便签就交给小克了。 | 笑 |
| 4 | 3-14 Astra，你能一个个讲讲吗？…… | 提问，句尾往上扬 |
| 5 | 4-21 是的，我一直很希望……找到归属感。 | 说心愿，更慢、更低、更轻 |

- [样片A_木琴.mp4](样片A_木琴.mp4)：短、圆，像木琴敲一下。
- [样片B_八音盒.mp4](样片B_八音盒.mp4)：亮一点，带余音，像八音盒。
- [样片C_泡泡.mp4](样片C_泡泡.mp4)：软软的"啵"，音高往下滑。

- [样片D_泡泡单音.mp4](样片D_泡泡单音.mp4)、[样片E_木琴单音.mp4](样片E_木琴单音.mp4)：Rin 觉得 A～C 有律动、太突兀，改成偶像大师那样一个音调，不起伏、问句也不上扬，每三个字响一声。

规则（A～C）：字幕按每秒 6 个字计时，平时每两个字响一声，说心愿时每三个字响一声；遇到标点停一下；问句最后几个字音高往上走；音高在五声音阶里起伏，像说话的语调。

音轨由 [make_blips.py](make_blips.py) 生成（numpy，48 kHz）。选定音色以后，再把它接进录制流程，给整部片子生成 Rin 的音轨。最后一句"大家再见！"打算用 Rin 的真声混在全员合唱里。

## 自己调或者换成录音

在这个文件夹里运行（要先有 `spans.json` 和对应的片段，脚本会按字幕时间排）：

```
python make_blips.py --kinds bubble --flat --every 3 --pitch 440
python make_blips.py --sound 我录的一声.wav --flat --every 3
```

- `--flat`：单音，不起伏。
- `--every`：每几个字响一声。
- `--pitch`：基准音高，数字越大越高（392 大约是 G4，440 是 A4）。
- `--sound`：用自己录的一小声（wav，越短越好，0.1 秒左右）代替合成音色，脚本会按字幕节奏一个个摆上去。
