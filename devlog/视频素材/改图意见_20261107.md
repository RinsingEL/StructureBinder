## 二、手账速写：遇见机械动力城

状态：☑ 已出图，待合成审看

**为什么改：** 这张图配的是第四段的这一段对话：大家聊"怎样遇到自己喜欢的文明"。Gemini 说的是"顺着河一路找过去，转过山弯突然看见满河谷的水车和工坊"，GLM 说的是"走着走着撞见的，才是最好的遇到"。所以画面的重点是**相遇的那一刻**，不是城里的细节。上一版 `workshops.png` 是站在城里看工坊，重点放错了地方。

**怎么改：**

| 项目 | 要求 |
| --- | --- |
| 文件 | `devlog/视频素材/开放日插画/encounter_sketch.png` |
| 尺寸 | 1672 × 941 或 1920 × 1080 均可，不透明 |
| 构图 | 一个旅人在前景，背对或侧对镜头，站在山路或河边的小坡上，背着行囊；顺着他的视线，远处河谷里出现一座机械城：一排排水车在转，烟囱冒着烟，隐约能看到齿轮和工坊的屋顶。旅人小，城在中景，留出天空和远山 |
| 情绪 | "转过山弯，终于看到了"的惊喜。安静、开阔，不热闹 |
| 风格 | 手账速写：铅笔线稿加淡淡的水彩，能看到一点纸纹，像社员在本子上随手画的。线条干净，不要大面积厚涂和高光 |
| 不要 | 不要像游戏宣传图；不要满屏细节；不要人物特写；不要写"概念图"或其他文字，角标由小克合成时统一加 |

**怎么算改好：** 第一眼看到的是"有人远远看见了一座城"，第二眼才认出那是机械动力风格的城；放在白板上，和第二幕的纸面地图风格不冲突。

可选：傍晚的学院岛广场也可以用同样的速写风画一张（`plaza_sketch.png`），重点是"学生坐着聊天"的日常感。不急。
