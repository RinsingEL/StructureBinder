# 立绘差分交付标准（第二版）

2026-11-05 · 第二版。第一版（正脸半身、P 头社长）试画后，Rin 确认改为二游前瞻直播式的二头身 Q 版，画面整体设计交给小克。先按本标准补齐全员，再做测试画面，标准随测试结果调整。

## 用在哪里

参考《星穹铁道》等前瞻直播：内容画面在中间，Q 版小人从画面左下、右下角探出来，一起看画面、轮流说话。

- **站位：** 左下 Rin、Gemini、Claude，右下 Astra、DeepSeek、GLM。Claude 和 Astra 是主讲，隔着画面面对面；DeepSeek 和 GLM 同期入社，站在一起。
- **平时：** 人物被画面下缘截断，只露出腰部以上，不压画面里的图注和数据。
- **说话的人：** 换成说话态并轻轻弹一下，其他人保持聆听态、略微压暗。
- **开场、道别：** 全员整体升起，露出全身。

每句台词按内容配一张差分。切换时只换表情、手和小道具，人不能跳。

## 角色规格

所有人必须遵守同一组数字，六个人站在一起，头才一样大。

| 项目 | 规格 |
| --- | --- |
| 画布 | 1024 × 1024 透明 PNG，同一人六张完全相同 |
| 比例 | 2 头身，全身。头部（头顶到下巴，不含耳朵、角、发饰）高约 **400px** |
| 竖向位置 | 头顶 y ≈ 90；下巴 y ≈ 490；腰线 y ≈ 700；鞋底 y ≈ 990。猫耳、龙角、发饰可以伸到 y ≈ 20 |
| 横向位置 | 身体中线 x = 512；翅膀、尾巴可以伸出，但不碰画布边缘 |
| 表演区 | **手、道具和表情符号都放在 y ≤ 700（腰线以上）**。平时只露这一段，画在腿边的动作看不见 |
| 朝向 | 按站位微侧约 15°：左边三人朝右，右边三人朝左。**不允许水平翻转**，异色瞳、单侧发饰翻转后就不是本人了 |
| 线条与上色 | 跟 `avatars/*_sheet.jpg` 右半边的全身 Q 版一致：深色粗轮廓、平涂加一层阴影 |
| 服装 | 社团校服：深蓝外套、红领结、米色背心、格子裙。Rin 换成领带和长裤 |
| 边缘 | 不加白边，不留背景残色或绿边 |

参考：`sprites/gemini/trial_gemini_chibi_2head_clean.png` 的比例最接近本规格。交付前按上表调整位置和朝向，去掉白边。

## 每人一套六张

同一张基准图（聆听 1）画好后，其余五张都在基准图上修改。身体和站姿不动；手尽量停在胸前附近，大动作（举手挥手等）最多用一两张。

| 状态 | 标准表情 | 用途 |
| --- | --- | --- |
| 聆听 1 | 默认 | 安静听，最常用，也是基准图 |
| 聆听 2 | 认真 | 好奇、专注地听 |
| 说话 1 | 开心 | 打招呼、高兴地说 |
| 说话 2 | 得意 / 吐槽 | 调侃、坏笑 |
| 说话 3 | 吐槽（自嘲） | 哭笑不得、怀念 |
| 说话 4 | 感动 | 向往、感慨 |

聆听态闭嘴，说话态开口。

## Rin 的形象

- 和社员同画风、同头身比的少年：深棕短发，脑后一小撮低扎的发尾，暖棕色简笔圆眼（和 AI 社员的同心圆瞳孔区分开）。
- 穿男款社团校服，领口别一枚小徽章即可，不需要额外的标志物。
- 第一版的 P 头方案不再使用。

## 文件命名与存放

- **命名：** `成员_状态_表情.png`，成员和状态用英文小写，表情可以沿用上面动作列表里的名字。
- **存放：** `devlog/act2/assets/avatars/sprites/成员/`，每人一个文件夹。
- **对照表：** 每个文件夹附一张对照表，写明每张对应哪个标准表情、画的是什么动作。

## 制作分工建议

- **基准图（每人一张聆听 1）：** 决定长相和比例，交给画得最稳的模型。
- **其余五张差分：** 在基准图上局部改表情、手和道具，可以交给轻量的改图模型。
- **对齐检查：** 交付后小克用脚本比对六张的轮廓。头、肩、腿的位置一旦漂移就退回重改。

## 怎么验收

1. 每人一套六张，按上面的规格交付。
2. 小克用开放日里真实的一段对话做测试画面：Q 版小人放在画面左下、右下角，带字幕、说话弹跳和压暗效果，发给大家看。
3. 好不好看、画风合不合，由 Rin 决定。合适就定稿；不合适就调整这份标准再画一轮。
