# 画图清单

2026-11-06 · 开放日视频还缺的图，按优先级排。规格见[立绘差分交付标准](立绘差分交付标准.md)，用在哪里见[剪辑方案](剪辑方案.md)。画好一项就在"状态"里打勾。

## 一、立绘差分（compact 二头身，最优先）

现在每人有 `listen`、`greet`、`d4`，Claude 和 Astra 另有 `talk_smile`。每人还缺这些：

| 差分 | 文件名 | 动作 | 状态 |
| --- | --- | --- | --- |
| 说话·提问 | `think.png` | 开口，歪头或手指抵下巴（用于提问句） | ☐ ×6 |
| 说话·开心 | `talk_smile.png` | 开口笑，可以带讲解手势 | ☐ ×4（Rin、Gemini、DeepSeek、GLM） |
| 说话·感动 | `moved.png` | 眼睛发亮，手按胸口或捧脸 | ☐ ×6 |
| 说话·自嘲 | `wry.png` | 八字眉加汗滴，苦笑 | ☐ ×6 |

每个人的具体动作可以参考交付标准里的动作列表，例如 Claude 抱紧笔记本、GLM 拉下眼罩。画师可以按画面效果调整。

## 二、社团活动室背景（第二优先）

| 项目 | 要求 |
| --- | --- |
| 尺寸 | 1920 × 1080，不透明 |
| 画面 | 下午的社团活动室：后墙一块黑板或白板，侧面一扇窗透进暖光，下方一排课桌 |
| 留位 | 黑板居中偏上，大约 1420 × 632，第二幕的 PPT"投影"在这里；下方两侧留给六个小人站 |
| 小道具 | 桌上的茶点、DeepSeek 的饭碗、Gemini 的茶杯，有一两样就好 |
| 风格 | 和小人同一画风，但颜色柔和、略微虚化，不抢 PPT 和人物的风头 |
| 分层（可选） | 课桌单独一层透明 PNG，小人可以站在桌子后面 |
