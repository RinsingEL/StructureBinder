- **截图：** [截图_Gemini签到.jpg](截图_Gemini签到.jpg)

## 画面

- **背景：** 社团活动室 v2（[clubroom_v2.png](../开放日插画/clubroom_v2.png)）。
- **开头 3 秒：** 白板上依次出现：
  - 一张"这一局的世界"小照片，用的是第二幕 W2 的世界图；
  - 标题"Geomantia 社团开放日"，下面有一条划线；
  - 几颗小星星；
  - 签到表从右边滑进来。
  - 然后六个人一起升起来。
- **签到：** 每个人自我介绍的第一屏，自己的头像贴纸会"啪"地盖到签到表上，名字从浅灰变成墨色。贴纸在 [stickers/](stickers/)，是从 compact 聆听图上裁下来的。
- **说话：** 说话的人会弹一下、往前站，其他人压暗。表情按逐句配画面表配；换表情时用 0.15 秒交叉淡入。
- **字体：** 标题用站酷快乐体，字幕用思源黑体，都通过 Google Fonts 加载，录制时需要联网。

- **余韵：** 按 Rin 的提议，说完话后不马上回聆听态，最后的表情留 2 秒，跟着压暗，再慢慢换回聆听态。由 `HOLD` 控制秒数；把 `HOLD_UNTIL_NEXT` 设为 true，就一直留到下次开口。
