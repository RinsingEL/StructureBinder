## 白板上的 PPT 怎么跟着对话走

- **翻页：** 配画面表"画面"一栏里写了第二幕的拍名（W1、T3、D4 等），说到那一屏字幕时就翻到那一拍。"W3 高度 → 水面 → 群系"这种写法，会按字幕的屏数依次翻。
- **等动画：** 翻页前，如果上一拍的动画还没播完（例如 T2、T3 的扩张，D7 的全城快放），会先停一下，等它播完再往下讲。
- **录制：** 录制时，另开一个页面打开 `act2/wtd-atlas.html`，按"第几拍、播到几成"定格当前那一帧，截图后贴到白板上。所以白板上是真实的第二幕动画，每次录出来都一样。录制脚本思路和测试画面相同，多了一步 PPT 定格。
- **开头：** 白板上先保留开场结束时签满的封面（[cover_board.jpg](cover_board.jpg)），Claude 一开口就淡出，换成 W1。

## 已知问题

- **长度：** 原始长度约 14 分钟，比预计的 10～12 分钟长，主要是在等 T2、T3、D1e、D7 的动画。剪辑时可以加快这些动画，或者缩短停顿。
- **小人遮挡：** Claude 讲解时伸出的手会稍微碰到字幕框。
