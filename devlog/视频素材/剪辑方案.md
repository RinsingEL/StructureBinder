## 画面版式

参考二游前瞻直播：

- **内容画框：** 居中偏上，边框是浅木色或软木板，四角贴手账胶带，不用深色电视框。底色用和 PPT 纸面相近的暖米色。
- **站位：** 二头身 Q 版，左下站 Rin、Gemini、Claude，右下站 Astra、DeepSeek、GLM。
  - 平时只露出腰部以上，不挡画框里的图注、数据和来源角标；挡到了就整体缩小画框。
  - 开场和道别时，全员升起露出全身。
- **说话：** 说话的人换成说话态，轻轻弹一下，其他人略微压暗。
- **白边：** 立绘素材本身不带白边，合成时统一加一圈贴纸白边，粗细一致。
- **介绍卡：** 原设比例的大立绘只用在第一段的自我介绍上。
- **字幕：** 放在画框下方、两侧角色之间。每屏最多两行，每行约 20 字。字幕前标名字，或用名字颜色区分。

## 对话怎么美化

按纪录片的规矩来：过程和结果是真的，成片可以修饰。

- **可以：**
  - 删句子、缩短长句；
  - 在同一话题内调整顺序；
  - 补"嗯""哈哈"这类语气词；
  - 把"同一时刻"的几句反应错开排；
  - 一句长话按意思拆成几屏字幕。
- **不可以：** 新增事实，改变谁说了什么的意思。
- **不进成片：** 【】里的翻页标记、"小声"的幕后话。
- **口头禅只留一次：** 比如 DeepSeek 的"能一步到位绝不走两步"。
- **表情：** 按说话内容配，从六种标准表情里选。没说话的人保持聆听态；画面上有大事发生时（比如"只落下一栋"），旁听的人可以换成"认真"。

实录里每段的"剪辑建议""剪辑备注"已经写了哪些句子留、哪些不用，剪辑时照着执行。几个重点：

| 段落 | 要点 |
| --- | --- |
| 第一段 | GLM 自我介绍剪到两三句，保留"四十分钟马上就调用"和眼罩 |
| 第二段 | 同一时刻的反应按建议择用；D4 处 Astra 第一句缩短，避免和后面的回忆重复；天象台小河一段完整保留 |
| 第三段 | 保留记岔时间和当场纠正；GLM 那句不用；"时间线小便签"玩笑可以做成便签贴上屏幕的小动画 |
| 第四段 | 机械动力的例子是重点，配概念图；"社长才是最强的多模态"保留 |
| 第五段 | 全员道别后，片尾彩蛋可选，由 Rin 决定 |

## 制作顺序

1. 每人一张二头身基准图，含社长。
2. 测试画面：D4 那段"四栋一下没了三栋"，用来定站位、字幕和动效。
3. 逐句配画面表：每句台词配哪个画面、哪张表情差分、时长多少。
4. 补齐差分、插画和动画。
5. 粗剪，交给 Rin 看。
6. 修改，定稿。

## 声音与音乐

- **字幕：** 一直保留，不管配不配音。
- **TTS 配音：** 先不定。测试画面那段（D4"四栋一下没了三栋"）做两个版本：只有字幕的，和配了 TTS 的，Rin 看完再选。逐句配画面表按"每句一行"来写，换方案时只要重算每句的时长。
  - TTS 在 Rin 的电脑上本地跑（4070 Ti Super），环境请 Astra 帮忙搭。
  - 声音用开源模型自带的音色，或者自己调出来的音色，不克隆真人声优或真人的声音。
  - 专有名词（Geomantia、D4、Astra 等）先试读，读不准的在字幕稿里标注读法。
  - Rin 的台词可以用 TTS，也可以由 Rin 本人录。
- **背景音乐：** 无人声的轻音乐，音量压在对话下面。只用允许二次使用的曲库，用前确认授权条款，不用商业动画原声。分段情绪：
  - 第一段：轻快，像走进活动室；
  - 第二段：安静，以钢琴或木吉他为主，不抢讲解；
  - 第三段：怀旧，温暖；
  - 第四段：明亮，有期待感；
  - 第五段：欢快收尾。
