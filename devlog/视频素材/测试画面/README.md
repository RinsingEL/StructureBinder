# 测试画面 · D4"四栋一下没了三栋"

2026-11-06 第一版，2026-11-07 第三版（换上社团活动室），字幕版。用来定站位、字幕和说话效果，按[剪辑方案](../剪辑方案.md)和[立绘差分交付标准](../立绘差分交付标准.md)制作。

- **视频：** [d4_字幕版.mp4](d4_字幕版.mp4)，1920×1080，24fps，约 42 秒。
- **截图：** [截图_Gemini提问.jpg](截图_Gemini提问.jpg)、[截图_Astra说话.jpg](截图_Astra说话.jpg)
- **画面源文件：** [scene.html](scene.html)，直接用浏览器打开会循环播放；地址后面加 `?static` 则停住，供逐帧录制。

## 这一版做了什么

- **画面布置：** 背景是社团活动室（[clubroom.png](../开放日插画/clubroom.png)），第二幕 D4 那一页（[d4_ppt.jpg](d4_ppt.jpg)，裁掉了下方留白）投在后墙白板上，用正片叠底贴合白板。第一、二版用的浅木框和手账胶带已经替换掉。
- **站位：** 二头身小人用 `avatars/sprites/compact/`。左边 Rin、Gemini、Claude，右边 Astra、DeepSeek、GLM，各自朝画面中间，靠近中间的人站在前面。
- **说话效果：** 说话的人换成说话态，开口时弹一下，说话期间轻轻浮动、放大一点，并移到最前面；其他人压暗。贴纸白边在合成时统一加。
- **换表情：** 用 0.15 秒交叉淡入，同时轻轻一压一弹；压暗用 0.25 秒渐变。都按帧计算，录出来每一帧都一样。
- **按字幕配表情：** 每一屏字幕可以单独指定表情。缺图时自动找替代：Gemini 提问那一屏指定的是「思考」，还没画，暂时用反应图代替。
- **字幕：** 名字标签加字幕卡，每屏最多两行，按每秒约 6 字计算时长。台词出自开放日实录第二段 D4，Astra 第一句按剪辑方案缩短。

## 录制方法

用 Playwright 逐帧调用 `render(t)` 截图，再用 ffmpeg 合成：

```bash
ffmpeg -framerate 24 -i frames/%05d.jpg -c:v libx264 -pix_fmt yuv420p -crf 22 d4_字幕版.mp4
```
