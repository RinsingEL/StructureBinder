# 来源与许可

本轮几何、像素纹理、色板、预览脚本、配置和文档由 Codex 按用户要求在本仓原创制作；没有下载人物皮肤、没有截取 Minecraft 村民贴图、没有从第三方角色或模型提取几何，也没有使用 ImageGen 位图素材。视觉采用方块人形及像素绘制语言；这不是 Mojang 官方资产。

本目录沿用 Realmfolk 的既有许可 **GPL-3.0-or-later**（见 `../../../addons/realmfolk/LICENSE`）。本说明不改变全仓其他资产的许可，也不代表为第三方资源重新授权。未内嵌其他项目源码或字体文件。预览文字由本机 Windows 字体栅格化，字体文件不分发。

Blockbench 仅作为拟议编辑工具；本轮依照其公开工程格式生成 JSON，没有复制其实现代码。格式参考：[官方 bbmodel 说明](https://www.blockbench.net/wiki/docs/bbmodel/)、[Blockbench v4.12.6 工程编解码源码](https://github.com/JannisX11/blockbench/blob/v4.12.6/js/io/formats/bbmodel.js)。没有引入 Blockbench、GeckoLib 或其他游戏库依赖。

资源路径参考 [Forge 1.20.1 资源文档](https://docs.minecraftforge.net/en/1.20.1/concepts/resources/)。`.rfmodel.json`、catalog 与池语义是本项目提案，非 Forge 标准，现有游戏代码不识别。

后续素材 agent 必须为每个资产提交来源、作者/工具、许可、引用 URL（如有）、是否允许修改和分发；不使用授权不明的皮肤站下载品。若引入许可不同的素材，先在 manifest 单项标注并审查兼容性，不默认套用本目录许可。
