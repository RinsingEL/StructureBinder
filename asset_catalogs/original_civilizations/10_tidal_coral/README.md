## 风格识别基准

**海洋幻想**：珊瑚与贝壳意象、青绿色石材、曲面或放射状体量、干湿空间分层；不把有码头的任意建筑都归入此类。

这段定义用于指导后续制作和风格复核，不代表本次已经重做或逐项确认现有模型全部符合；具体落地条件仍读各模型的 `terrain`。

## 环境与文明表达

依托浅海、潮间带、群岛与可用岸线，明确干燥、浸水和水下区域；水位变化与水下功能属于后续玩法适配范围。

架空与水下空间形成不同生活层次，海藻、珍珠和潜水设施组成产业与探索方向。

角色定义、填充多样性标准、内饰与标记要求见[总清单](../README.md)。原有编号保留；新增填充族使用 `TC-Fxx`。结构族数量不等于实际模型数量。


## 当前交付

核心4项与专项2项已完成原创v01及主审复核，137张新版浏览器截图全部实际查看并归档。当前NBT和作者标记双哈希一致，数据与步行导航零警告，已注册公共构建入口。9个填充族仍在制作，现有生活草稿不计入已验收数量。

独立源码：`tools/structure_studio/studio/tidal_coral.py` 和 `tidal_civic_details.py`。贝壳拱顶、浅色肋架、透明潜水舱、开放水庭、断裂古拱和灯冠分别表达功能；[验收画廊](验收画廊.md)汇总外观、内饰与完整证据。

常规滨水模型参考水面Y=5、低潮3、高潮6，干地板Y=7；水下站参考水面14、低潮12、高潮15，干舱地板3，北端干式入口地板16、脚底17，以封闭实体楼梯连接。各项柱脚Y=0必须接承载地层。淡水需要岸上补给或处理；潮汐、船舶、潜水呼吸、水密和流体行为均未进行MC运行时验证。
