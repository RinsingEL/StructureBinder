## 风格识别基准

**海洋幻想**：珊瑚与贝壳意象、青绿色石材、曲面或放射状体量、干湿空间分层；不把有码头的任意建筑都归入此类。

这段定义用于指导后续制作和风格复核，不代表本次已经重做或逐项确认现有模型全部符合；具体落地条件仍读各模型的 `terrain`。

## 环境与文明表达

依托浅海、潮间带、群岛与可用岸线，明确干燥、浸水和水下区域；水位变化与水下功能属于后续玩法适配范围。

架空与水下空间形成不同生活层次，海藻、珍珠和潜水设施组成产业与探索方向。

角色定义、填充多样性标准、内饰与标记要求见[总清单](../README.md)。原有编号保留；新增填充族使用 `TC-Fxx`。结构族数量不等于实际模型数量。
