## 环境与文明表达

依据林地、水源、林间空隙与生态资源选址；独立落地建筑、附树建筑和树冠连接应分别说明适配条件。

曲线木石、植物与功能性种植空间共同表达生活方式，建筑保留林地层次与通行关系。

角色定义、填充多样性标准、内饰与标记要求见[总清单](../README.md)。原有编号保留；新增填充族使用 `FS-Fxx`。结构族数量不等于实际模型数量。
