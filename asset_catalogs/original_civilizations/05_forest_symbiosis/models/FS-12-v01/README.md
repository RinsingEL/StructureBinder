树干、板根、残墙与拱顶共同形成历史层次，根盘不虚悬；破损拱顶之外保留完整室内可读性。

空间用途：旧石砌记录室：拱顶残段、刻石、遗物与根外通道；根抱旧庭：南东侧被根盘侵入的开放旧庭，西侧保留探索线。

- **选址**：保存石砌房间和巨大根盘的历史林地；树根整体落地并避开主要探索路线
- **落地**：只整理建筑本体与步道；保留未写入的林地。附树版本包含独立柱脚和树根占地，不能套入任意现存树体。
- **高程**：主入口脚底 Y=3；高位层和坡地接驳另见楼层与使用点
- **运行边界**：种植、蜂具、藤果、兽栏与遗留物均为原版静态空间表达；实际生产、动物和生态行为须另行接入。
