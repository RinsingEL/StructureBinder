三座功能体围绕保留树体，西记录、东储备、南育苗；前后通路绕开可见板根。
种子柜和花盆表达保存与育苗空间，不声明原版种子库系统。

空间用途：种源记录厅：种源登记、样本分类和记录查阅；干燥种子库：储备柜、筛选与封装作业；采光育苗廊：面向林隙的育苗展示与换土空间。

- **选址**：潮湿林地中的排水良好高地；前庭接步道，采光育苗庭位于南侧林隙
- **落地**：只整理建筑本体与步道；保留未写入的林地。附树版本包含独立柱脚和树根占地，不能套入任意现存树体。
- **高程**：主入口脚底 Y=3；高位层和坡地接驳另见楼层与使用点
- **运行边界**：种植、蜂具、藤果、兽栏与遗留物均为原版静态空间表达；实际生产、动物和生态行为须另行接入。

[建模源码](../../../../../tools/structure_studio/studio/forest_symbiosis.py)；在工具目录执行 `python -m studio.build FS-03-v01` 重建。
