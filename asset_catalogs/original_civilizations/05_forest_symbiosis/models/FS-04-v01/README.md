客房位于主屋后段，栏棚与主屋之间是宽阔的照护与卸具通道；动物行为未实现。

空间用途：家庭生活空间：烹饪、饮水、餐桌、床位与储藏齐备；中央保留穿行；驿站接待厅：旅人登记、公共座位和餐桌；双间照护棚：独立照护隔间，宽侧开口接南北赶畜通路。

- **选址**：宽度足够的林路停歇处；兽栏与旅客门口分开，南侧须有真实动物到达路径
- **落地**：只整理建筑本体与步道；保留未写入的林地。附树版本包含独立柱脚和树根占地，不能套入任意现存树体。
- **高程**：主入口脚底 Y=3；高位层和坡地接驳另见楼层与使用点
- **运行边界**：种植、蜂具、藤果、兽栏与遗留物均为原版静态空间表达；实际生产、动物和生态行为须另行接入。
