一侧挡风背墙的长棚，适合院边晾药、编织物和短时货物周转
悬挂晾架由链条接屋顶；工具、晾晒与材料存取均有可达站位。
按工具组装、晾材切整、晾药扎包、维修发料四种用途配置工作台、材料和周转设施；保持从入口到各工作面的连续通路。

空间：开放操作与晾晒棚：维修台、磨具、悬挂晾架、干料架与独立柱脚；双端整理与干料分类：西侧选药、东侧扎包，中部晾晒观察与分类容器，不混用湿料和包装。

- **选址**：一侧挡风背墙的长棚，适合院边晾药、编织物和短时货物周转
- **落地**：只整理建筑本体与步道；保留未写入的林地。附树版本包含独立柱脚和树根占地，不能套入任意现存树体。
- **高程**：主入口脚底 Y=3；高位层和坡地接驳另见楼层与使用点
- **运行边界**：种植、蜂具、藤果、兽栏与遗留物均为原版静态空间表达；实际生产、动物和生态行为须另行接入。
