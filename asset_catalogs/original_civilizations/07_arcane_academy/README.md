## 风格识别基准

**魔法学院**：塔楼、回廊、书库、观测与实验空间、晶体或符文装饰；魔法主题需要落到空间组织和细节，不能只靠紫色配色。

这段定义用于指导后续制作和风格复核，不代表本次已经重做或逐项确认现有模型全部符合；具体落地条件仍读各模型的 `terrain`。

## 环境与文明表达

选址由聚落服务范围、魔法资源设定与普通地理条件共同决定；传送与供能设施的实际运行需要玩法接入。

魔法深入交通、教育、维修和生活基础设施；建筑有明确学科与工作流程。

角色定义、填充多样性标准、内饰与标记要求见[总清单](../README.md)。原有编号保留；新增填充族使用 `AA-Fxx`。结构族数量不等于实际模型数量。
