## 环境与文明表达

先确认实际存在的文明联系，以及水陆交通、资源或历史交汇条件。混合特征由贸易、迁徙与扩建等关系解释。

普通结构按原文明归档；此处维护表达双方交流的独立设施与可重复配套。

角色定义、填充多样性标准、内饰与标记要求见[总清单](../README.md)。原有编号保留；新增填充族使用 `XC-Fxx`。结构族数量不等于实际模型数量。
