## 重建与查看

在 `tools/structure_studio` 使用已准备的 Python 环境：

```sh
.cache/venv/bin/python -m studio.build CH-13 CH-14 CH-11 CH-16 CH-17 CH-18 CH-19 CH-20 CH-21 CH-22
.cache/venv/bin/python cli.py serve
```

浏览 `http://127.0.0.1:8765/?asset=CH-13-v02`，也可选择中式木构分类切换其他建筑。macOS 可双击工具目录的 `start.command`。服务读取导出后的 NBT；去屋顶、楼层切片、房间聚焦与工作点用于检查内饰。

源码：`tools/structure_studio/studio/chinese.py`、`chinese_culture.py`、`chinese_inn.py` 与 `chinese_palace.py`；木构、屋面、门廊等部件：`chinese_parts.py`。

## 已实现的局部配置

以下是作者 Python 源码的重建参数，默认资产只导出一套，未增加 Studio 界面选项或 City 运行时配置：

- `palace_grand(ceremony="audience" | "banquet", garden_theme="flower" | "grape" | "gourd")`（`chinese_palace.py`）：高台重殿版；正殿陈设与内院棚架主题，换皮不改宫门、台阶与主次院落。
- `palace(ceremony="audience" | "banquet", garden_theme="flower" | "grape" | "gourd")`：正殿陈设与内院棚架主题。
- `manor(garden_theme="grape" | "gourd" | "flower", shop="general" | "cloth" | "woodcraft" | "tools")`：后园棚架与院侧店铺商品陈设。
- `tall_inn()`（`chinese_inn.py`）：新增三层楼廊版，当前推荐体量，固定十二间双床客房。
- `inn()`：保留低层围院标准版、朴素客房与普通餐饮；带店铺形体、雅致客房和茶食版本尚未制作。

省略参数采用默认值。主题更换保留主体、房间和站位；作者记录 `authoring_parts` 给出部件范围和当前配置。本批仍使用固定灰瓦、深木与浅墙材料，通用材料槽替换工具尚未接入。

葡萄用叶块和紫晶簇、葫芦用南瓜作原版静态表达；不宣称已有对应作物行为。生活、营业与礼仪设施为实物几何和作者用途，未启动 Minecraft 或接入 City 运行时。

新增七项只交付默认形体，无额外换皮参数。文化身份不通过改招牌互换；宗祠、庙宇和园林分别保留祖祭、公共供奉、游赏用途。
