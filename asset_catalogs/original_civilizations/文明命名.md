2026-09-23 更新：一个风格一份建筑清单，各自在风格内确定建筑的功能、形体与空间。本页仅作导航和风格识别参考；[通用建筑与景物](建筑类型清单.md)只收集小屋、雕像、喷泉等选题，不规定跨风格的布局模板。材料换皮按设计前填写的材料方案执行，不承担结构设计。

## 通用风格候选

以下风格各有独立设计文档，尚未分配模型编号或制作成品。具体建筑在各自文档中定义。

| 风格 | 形体与构造基准 |
| --- | --- |
| [中式](风格清单/中式建筑.md) | 坡屋顶与出檐、木构开间、院落组合、门廊；具体模型明确屋顶形式和比例，不要求所有建筑都使用夸张翘角。 |
| [日式](风格清单/日式建筑.md) | 深檐、木构与轻隔断、缘侧、错落屋面；根据住宅、店铺或公共建筑分别组织空间。 |
| [欧洲中世纪](风格清单/欧洲中世纪建筑.md) | 山墙、陡坡顶、外露木构或厚石墙、紧凑街面；选定具体构造与比例，避免将所有欧洲建筑混为一个模板。 |

## 使用规则

- 本表是当前套系的分类和制作基准，不代表全库已经具有充分的风格辨识度。本次没有重做模型，也没有新增风格验收结论。
- 作者记录中的 `civilization` 暂沿用现有字段名，当前值表达上述风格类别，不是实际生成世界的国名或居民种族证明。
- “因地制宜”约束具体建筑如何适应场地；风格定义建筑如何表达。同一风格可以跨地形发展，同一种地形也可以承载不同风格。沙漠、北欧这样的常见地域风格名称可以保留，不能直接转成生物群系硬绑定。
- 每个模型的 `terrain`、用途、入口高程、支撑和交通条件保持有效。改名不意味着已有建筑已支持任何环境。
- 路径、源码模块、结构前缀和模型 ID 是稳定技术标识，不能替代风格定义或场地条件。
- 2026-09-23 按本轮确认补入中式、日式、欧洲中世纪风格候选，并以各风格独立文档组织建筑清单。保留既有套系对应关系；新增候选没有成品数量或制作完成承诺。本次仅修改清单，未重建模型。

## 风格检查

- 同类型跨风格对照时，明确屋顶轮廓、构架、开口或空间组织的可见差异，不能只列材料色表。
- 同风格跨用途对照时，检查作业、生活、装卸、采光等需要是否影响建筑设计，避免给相同外壳反复更换名称与内饰。
- 允许普通住宅和街铺合理复用构件；风格一致不要求每栋建筑外壳一致，也不要求每栋都成为地标。
- 风格与功能共同决定设计，材料方案在 AI 设计前填写。执行材料换皮不重新选择风格、不修改几何，也不启动多模态长时间思考。
