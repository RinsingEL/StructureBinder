## 环境与文明表达

依托矿产、山地通道及可用能源，先区分地表、贴山与山腹空间；矿业和高差运输必须有明确服务对象。

厚重石体、金属构件、炉厅与长屋共同表现山地生产生活，利用高差形成层次。

角色定义、填充多样性标准、内饰与标记要求见[总清单](../README.md)。原有编号保留；新增填充族使用 `MF-Fxx`。结构族数量不等于实际模型数量。
