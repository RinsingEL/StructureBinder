# SC-07-v03 皮革鞍具双帐洁污分区

游牧填充，尺寸 51×19×34。当前 25 张最终视图全部作者实看通过，数据和导航零警告，主审交叉复核通过。

双帐洁污分区；结合行业分别组织收料、加工、成品和管理。

功能组织：独立洁净储藏帐（成品与包装分离原料）；原料处理与封装（原料柜、洗槽、主处理、封装、成品与管理）。

使用点：未加工皮料与辅料、皮料浸洗、裁切缝制与皮带装配、鞍具组装、浸洗皮料独立晾架、扣环针线与修补辅件、成品鞍具与修补件、订单与尺码登记、洁净成品与包装柜、独立成品包装、鞍带扣具与护套、洁净复核与整箱扎包、已验封箱待发货、休息交接桌、背风营路入口。

落地条件：

- 选址：依托畜牧与行旅维修，浸洗用水须回收，不就地排向水源；两帐分别容纳加工与洁净封装储物
- 资源与季节：须接已有水草与补给路线，储槽为外部运水；按当地风向使入口背风，长季定居与短期停驻明确区分。
- 高程：默认入口脚底Y=3；坡台住宅Y=5由实体台阶接入，见点位。
- 落地限制：仅整理模板营地占地，不推平外部草坡；留出畜群、货车或来客外接通路。
- 运行边界：原版静态空间与作者点位，未接入动物、交易、季节迁徙或运行时生成。
