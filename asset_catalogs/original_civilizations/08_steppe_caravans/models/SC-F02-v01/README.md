# SC-F02-v01 双短畦菜圃

游牧填充，尺寸 31×19×29。当前 17 张最终视图全部作者实看通过，数据和导航零警告，主审交叉复核通过。

双短畦菜圃；面积、田埂组织、工作棚与值守帐分别不同。

功能组织：短期营地种植畦（四格内独立水眼与完整田埂；限足够生长季和日照）；短期营地种植畦（四格内独立水眼与完整田埂；限足够生长季和日照）。

使用点：季节短畦采收、季节短畦采收、种子与轮作记号、采收分拣与扎束、洗菜与器具储水、植物余料集中堆肥、背风营路入口。

落地条件：

- 选址：只用于具有耕土、可靠运水和足够生长季的固定或长驻营地；双短畦菜圃沿既有补给小路布置。
- 资源与季节：须接已有水草与补给路线，储槽为外部运水；按当地风向使入口背风，长季定居与短期停驻明确区分。
- 高程：默认入口脚底Y=3；坡台住宅Y=5由实体台阶接入，见点位。
- 落地限制：仅整理模板营地占地，不推平外部草坡；留出畜群、货车或来客外接通路。
- 运行边界：原版静态空间与作者点位，未接入动物、交易、季节迁徙或运行时生成。
