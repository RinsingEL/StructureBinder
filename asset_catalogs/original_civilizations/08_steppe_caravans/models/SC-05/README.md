# SC-05 · 议事家帐与炊事副帐

圆形毡帐屋檐连续，贯通到弧墙的带门寝区与会客桌、口述史座席、缝补分区；独立炊事副帐含连续备餐、水槽和烟道，室外餐叙保持间距。

角色：`planning_role.key`；尺寸：43 × 19 × 39。

**选址**：家族常住或长季驻扎台地；主帐南向背风、炊事副帐在下风侧，与主帐之间留防火间距。

**高程**：入口与营地脚底Y=3；局部巡路台脚底Y=6，见标记与台阶。

**资源与季节**：依赖外部季节水草及商路补给；水槽为运水储备，不凭空生成水源。严寒风暴季撤帐或转入冬营。

**适配边界**：朝南开口按当地背风方向旋转；保留营地外人畜廊道，禁止直接压平山体或河滩。

**运行边界**：帐篷、马具、货车与遗存均为原版静态表达，动物、交易及迁徙尚未接入。

当前 25 张最终视图全部实看并发布；数据与离线步行零警告。
