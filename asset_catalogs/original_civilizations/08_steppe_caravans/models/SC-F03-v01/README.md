# SC-F03-v01 开敞照护草棚

游牧填充，尺寸 31×19×31。当前 13 张最终视图全部作者实看通过，数据和导航零警告，主审交叉复核通过。

开敞照护草棚；开放照护、半围合、分料储草和完整值守生活组合分别建立。

功能组织：背风照护与草料棚（棚下干草、露天照护与饮水，不封闭畜群通路）。

使用点：开敞饮畜水、梳洗与照护工具、分组干饲草垛、背风营路入口。

落地条件：

- 选址：依托已有畜群、水草及运水路线；开敞照护草棚储草架离开低洼积水，入口背风，不占商队车道。
- 资源与季节：须接已有水草与补给路线，储槽为外部运水；按当地风向使入口背风，长季定居与短期停驻明确区分。
- 高程：默认入口脚底Y=3；坡台住宅Y=5由实体台阶接入，见点位。
- 落地限制：仅整理模板营地占地，不推平外部草坡；留出畜群、货车或来客外接通路。
- 运行边界：原版静态空间与作者点位，未接入动物、交易、季节迁徙或运行时生成。
