# SC-08-v03 看管帐货物场

游牧填充，尺寸 47×19×37。当前 23 张最终视图全部作者实看通过，数据和导航零警告，主审交叉复核通过。

看管帐货物场；分类规模、装卸侧、看管配套与货车排列不同。

功能组织：值守生活帐（睡眠隔断、衣物、热食储水与记账用餐）；分类干货与装卸（中央卸货通道，两侧分类柜与货垛）。

使用点：粮袋干货、分组封装货垛、织品皮料、分组封装货垛、陶器工具、分组封装货垛、收发货登记、值宿床铺与行李、值守衣物与干粮、值宿热食、值守储水、值守记录与用餐、背风营路入口。

落地条件：

- 选址：季节停驻贸易点的带值宿的稳定存放区；货棚保持干燥，南端接既有车道。
- 资源与季节：须接已有水草与补给路线，储槽为外部运水；按当地风向使入口背风，长季定居与短期停驻明确区分。
- 高程：默认入口脚底Y=3；坡台住宅Y=5由实体台阶接入，见点位。
- 落地限制：仅整理模板营地占地，不推平外部草坡；留出畜群、货车或来客外接通路。
- 运行边界：原版静态空间与作者点位，未接入动物、交易、季节迁徙或运行时生成。
