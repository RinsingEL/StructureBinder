# SC-10 · 祖灵石阵与守护小帐

错落纪念石、彩釉纹石与环行步道围合露天供物区；守护小帐具床铺、衣柜、记录和避开支柱的水槽，备物棚有厨房和桌椅。

角色：`planning_role.key`；尺寸：41 × 20 × 39。

**选址**：远离放牧主通路的干燥脊肩，石阵朝向当地日出缺口；仅具有祖灵仪式需求的组团明确选用，保留远眺界面。

**高程**：入口与营地脚底Y=3；局部巡路台脚底Y=6，见标记与台阶。

**资源与季节**：依赖外部季节水草及商路补给；水槽为运水储备，不凭空生成水源。严寒风暴季撤帐或转入冬营。

**适配边界**：朝南开口按当地背风方向旋转；保留营地外人畜廊道，禁止直接压平山体或河滩。

**运行边界**：帐篷、马具、货车与遗存均为原版静态表达，动物、交易及迁徙尚未接入。

当前 20 张最终视图全部实看并发布；数据与离线步行零警告。
