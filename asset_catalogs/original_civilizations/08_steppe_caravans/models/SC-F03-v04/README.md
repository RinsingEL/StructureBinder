# SC-F03-v04 照护小帐兽栏

游牧填充，尺寸 51×19×35。当前 22 张最终视图全部作者实看通过，数据和导航零警告，主审交叉复核通过。

照护小帐兽栏；开放照护、半围合、分料储草和完整值守生活组合分别建立。

功能组织：值守生活帐（睡眠隔断、衣物、热食储水与记账用餐）；饮水休畜栏（休畜、运水、饲料与检畜通路）。

使用点：值宿床铺与行李、值守衣物与干粮、值宿热食、值守储水、值守记录与用餐、运水饮畜槽、运水饮畜槽、照护与清栏器具、检畜与交接净空、兽用清洁与敷料、照护记录与配料台、背风营路入口。

落地条件：

- 选址：依托已有畜群、水草及运水路线；照护小帐兽栏储草架离开低洼积水，入口背风，不占商队车道。
- 资源与季节：须接已有水草与补给路线，储槽为外部运水；按当地风向使入口背风，长季定居与短期停驻明确区分。
- 高程：默认入口脚底Y=3；坡台住宅Y=5由实体台阶接入，见点位。
- 落地限制：仅整理模板营地占地，不推平外部草坡；留出畜群、货车或来客外接通路。
- 运行边界：原版静态空间与作者点位，未接入动物、交易、季节迁徙或运行时生成。
