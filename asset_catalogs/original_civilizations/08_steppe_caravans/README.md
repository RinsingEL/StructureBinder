## 风格识别基准

**游牧**：帐篷与毡布、可拆装木架、围场、火塘、织物纹样；移动生活方式与构造形成识别，不意味着只能位于草原。

这段定义用于指导后续制作和风格复核，不代表本次已经重做或逐项确认现有模型全部符合；具体落地条件仍读各模型的 `terrain`。

## 环境与文明表达

依托季节性水草、商路与集会节点；常住、季节停驻和废弃营地分别标记，保持帐群与牲畜活动空间。

帐篷、车队、兽栏与公共集会表达流动生活，储存与维修设施适合行旅需求。

角色定义、填充多样性标准、内饰与标记要求见[总清单](../README.md)。原有编号保留；新增填充族使用 `SC-Fxx`。结构族数量不等于实际模型数量。
