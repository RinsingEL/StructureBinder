# 通用建筑与景物参考

[返回总入口](README.md) · [各风格建筑清单](文明命名.md)

这里收集可以在多种风格中重新设计的常见建筑与景物，供补充素材时选题。文件名保留以兼容旧链接。不规定统一布局、功能编制或跨风格模型骨架，也不要求每种风格做全。

| 通用对象 | 选题内容 |
| --- | --- |
| 小屋 | 居住小屋、看守小屋、园中小屋 |
| 雨棚 | 遮雨棚、门前棚、路边歇脚棚 |
| 亭子 | 园亭、路亭、水边亭 |
| 雕像 | 人物、动物、纪念性雕塑 |
| 喷泉 | 广场喷泉、庭园喷泉、壁泉 |
| 水井 | 井口、井台、井亭 |
| 水池 | 庭园池、蓄水池、浅水景 |
| 桥 | 小桥、步桥、带栏桥 |
| 门与围墙 | 院门、门柱、围墙、栏杆 |
| 台阶与步道 | 石阶、坡道、园路、栈道 |
| 廊与花架 | 连廊、遮阴花架、藤架 |
| 庭园 | 花坛、树池、小庭院 |
| 灯具与标识 | 路灯、灯柱、路牌、布告栏 |
| 街边陈设 | 长椅、桌椅、饮水槽、货架 |

具体名称、意义、用途、尺寸、结构和外观都在选定风格的建筑清单内确定。例如雕像塑造谁、喷泉如何供水、小屋由谁使用，不在这张总表统一设定。魔法研究、空艇接驳等建筑直接在相应风格文档中定义，不设“特殊设施”兜底类别。

材料方案在 AI 设计前填写。材料换皮只替换材料，不改变几何，不代替建筑设计，不触发多模态重设计。
