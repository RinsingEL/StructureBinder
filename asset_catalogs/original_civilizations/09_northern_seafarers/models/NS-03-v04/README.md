# NS-03-v04 · 错台风干盐坊

31×28×29 格。湿加工留在低台，干燥架抬高两格置于有顶通风台，独立台阶和三边护边避免潮湿卸料与干货转运混杂。

抬高入口平台有完整支承，原料与成品工作面分开。

角色：`planning_role.fill`。空间：低台湿加工间、抬高通风干燥台。

- **选址**：稳定的寒地海湾背风岸台；避开潮涌、雪崩、海冰推挤和行洪通道。
- **高程**：湿坊脚底Y=3，干燥台Y=5；三宽双级阶连接，两级边沿需要完整保留。
- **保留空间**：完整独立模板，连同檐口、通路和本体配套保留；不可贴邻堵住工作面。
- **风雪**：厚木围护、短风斗和陡坡屋面表达避风防雪；不模拟风雪、温度或雪荷载。
