# NS-06-v02 · 坡岸前作后居宅

27×25×31 格。湿具处理与小修留在低岸前屋，家居抬高两格，后屋再隔炊食与双床寝间；中央阶院连接两屋，防止湿具穿越卧室。

前作业后抬高生活台可辨，台阶衔接，二床区与湿具分离。

角色：`planning_role.fill`。空间：低岸生产间、后高台炊食间、后高台双床寝间。

- **选址**：稳定的寒地海湾背风岸台；避开潮涌、雪崩、海冰推挤和行洪通道。
- **高程**：前部作业脚底Y=3，后部生活脚底Y=5，双级三宽石阶连接；需匹配前低后高岸坡。
- **保留空间**：完整独立模板，连同檐口、通路和本体配套保留；不可贴邻堵住工作面。
- **风雪**：厚木围护、短风斗和陡坡屋面表达避风防雪；不模拟风雪、温度或雪荷载。
