# NS-09-v04 · 避风院分屋客栈

35×28×33 格。长食堂、独立炊事屋和后院客寝围出避风院，洗漱在院廊，海员登记寄物、吃饭和休息各有实际空间。

院落客栈的住宿和供餐空间独立，旅客与服务流线经院相接。

角色：`planning_role.fill`。空间：长食堂及登记寄物厅、独立厨房、后院三床客寝、遮雪洗漱廊。

- **选址**：稳定的寒地海湾背风岸台；避开潮涌、雪崩、海冰推挤和行洪通道。
- **高程**：干燥主层脚底 Y=3，建筑基础底 Y=0；外部步行地面需接主层。
- **保留空间**：完整独立模板，连同檐口、通路和本体配套保留；不可贴邻堵住工作面。
- **风雪**：厚木围护、短风斗和陡坡屋面表达避风防雪；不模拟风雪、温度或雪荷载。
