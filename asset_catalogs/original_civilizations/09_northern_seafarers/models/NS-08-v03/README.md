# NS-08-v03 · 双层干货与装备库

21×28×29 格。窄地块两层储备：下层收发重工具，上层密封食品与织物，三排架保持横向取货带，内梯带完整梯井护栏。

双层库上层货架留中心搬运面；补斜视确认梯井 U 形护栏实体高度与连接。

角色：`planning_role.fill`。空间：下层工具收发库、上层轻质干货库。

- **选址**：稳定的寒地海湾背风岸台；避开潮涌、雪崩、海冰推挤和行洪通道。
- **高程**：干燥主层脚底 Y=3，建筑基础底 Y=0；外部步行地面需接主层。
- **保留空间**：完整独立模板，连同檐口、通路和本体配套保留；不可贴邻堵住工作面。
- **风雪**：厚木围护、短风斗和陡坡屋面表达避风防雪；不模拟风雪、温度或雪荷载。
