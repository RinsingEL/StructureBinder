# NS-F01-v06 · 避风前室海图文具铺

25×28×25 格。海图文具铺带独立短风斗，中心宽台铺图核对、后部抄写装订和纸墨干存，适合航民出航准备。

风斗等候、铺图核对与后抄写装订逐段安排。

角色：`planning_role.fill`。空间：短风斗等候间、海图选择与校对厅、后抄写装订区。

- **选址**：稳定的寒地海湾背风岸台；避开潮涌、雪崩、海冰推挤和行洪通道。
- **高程**：干燥主层脚底 Y=3，建筑基础底 Y=0；外部步行地面需接主层。
- **保留空间**：完整独立模板，连同檐口、通路和本体配套保留；不可贴邻堵住工作面。
- **风雪**：厚木围护、短风斗和陡坡屋面表达避风防雪；不模拟风雪、温度或雪荷载。
