## 风格识别基准

**北欧**：长屋、陡坡木屋顶、外露梁柱、石质基座与集中炉火；海运只是部分建筑功能，内陆聚落也能采用这一传统。

这段定义用于指导后续制作和风格复核，不代表本次已经重做或逐项确认现有模型全部符合；具体落地条件仍读各模型的 `terrain`。

## 环境与文明表达

依托可用海湾、寒地航路和渔业资源，考虑避风、储粮与冬季补给；住宅和生产空间围绕实际岸线安排。

长屋、船屋与公共浴屋形成寒地生活，储备、修缮和共同活动具有鲜明存在感。

角色定义、填充多样性标准、内饰与标记要求见[总清单](../README.md)。原有编号保留；新增填充族使用 `NS-Fxx`。结构族数量不等于实际模型数量。
