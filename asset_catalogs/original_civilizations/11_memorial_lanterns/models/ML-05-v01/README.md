# ML-05-v01 · 祖先议事庭与双侧公档翼

47×32×41 格。高挑议事主庭配双侧低翼，前纪念花庭形成公开入口，石肋和彩窗保持一致构造语言。

实际查看21图：前旁听长凳、两侧代表桌、中央陈述位、后主持记录及纪念台完整；公档查阅和公众事务各占独立窄翼。

作者角色：`planning_role.key`。空间：开放旁听席、议事与纪念主庭、公共档案侧翼、书记事务侧翼。

- **选址**：排水良好的稳定台地，连接仍有常住居民的聚落道路；纪念设施不替代活人的生活供给。
- **高程**：基础底 Y=0，公共地面 Y=2，步行脚底 Y=3；道路接入口同高。
- **保留空间**：独立完整模板，保留外扶壁、彩窗采光面及庭院；不可用相邻建筑遮挡。
- **构造**：尖拱、外扶壁与内肋共同表达高挑空间；不模拟结构受力、照度或天气。
