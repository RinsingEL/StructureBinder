## 风格识别基准

**哥特**：尖拱、竖向体量、肋状构造、彩窗与纪念庭院作为后续制作基准；丧葬用途不自动等于哥特，尚未建模不能宣称达标。

这段定义用于指导后续制作和风格复核，不代表本次已经重做或逐项确认现有模型全部符合；具体落地条件仍读各模型的 `terrain`。

## 环境与文明表达

依托纪念地、朝圣路线与可维持活人生活的聚落条件；墓园、居住和生产空间各有明确用途。

生活围绕记忆、祖先与丧葬制度展开，同时具有正常的饮食、医疗、生产和居住。

角色定义、填充多样性标准、内饰与标记要求见[总清单](../README.md)。原有编号保留；新增填充族使用 `ML-Fxx`。结构族数量不等于实际模型数量。
