## 环境与文明表达

依托有通行与停靠条件的河流、湖岸、河口和运河节点；区分陆侧通路与水侧装卸面，保留岸线特征。

临水商住、桥头公共生活和仓储船务共同构成聚落；中式或其他视觉语言可在具体套系中确定。

角色定义、填充多样性标准、内饰与标记要求见[总清单](../README.md)。原有编号保留；新增填充族使用 `WT-Fxx`。结构族数量不等于实际模型数量。
