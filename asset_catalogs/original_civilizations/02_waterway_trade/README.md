## 风格识别基准

**地中海**：浅色墙面与连续拱廊、陶瓦屋顶、内庭及蓝绿色点缀；码头是功能，建筑风格也适用于内陆商街与住宅。

这段定义用于指导后续制作和风格复核，不代表本次已经重做或逐项确认现有模型全部符合；具体落地条件仍读各模型的 `terrain`。

## 环境与文明表达

依托有通行与停靠条件的河流、湖岸、河口和运河节点；区分陆侧通路与水侧装卸面，保留岸线特征。

临水商住、桥头公共生活和仓储船务共同构成聚落；当前套系按地中海的浅色拱廊与陶瓦语言归类，不以水网功能代替风格判断。

角色定义、填充多样性标准、内饰与标记要求见[总清单](../README.md)。原有编号保留；新增填充族使用 `WT-Fxx`。结构族数量不等于实际模型数量。
