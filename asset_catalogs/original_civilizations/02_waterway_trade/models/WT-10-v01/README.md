核心结构；议事长桌及对坐席、教学桌椅、档案卷册、分水演示池、两处控制杆与后廊长凳齐备，池底有实体承托。空间标记包括：合议大厅、水工教学室、堤渠档案室、后庭水工展示、后庭讲解廊。

- **选址**：服务真实水利管理需求的岸上聚落中心；有足够议事与教学用地、生活供水和步行联系
- **高程**：主体地坪方块 Y=2，脚底 Y=3；局部高差另在房间与接驳标记记录
- **落地**：只整备本体院落与岸台；水侧桩脚和实体岸基分别承接，不填满外部水道
- **运行边界**：作者资产表达空间与设备外形，交通、船只、液体和机器行为需要另行接入

已完成当前 NBT 外观、内饰、作者标记与已标站位的离线验收。贸易、议事、造船、住宿或仪式由空间和作者标记表达，尚未自动接入国度 Mod 对应玩法。 演示水工或泵机为静态构筑物，未实现水动力、泵送或红石控制。未启动 MC，未接入国度 Mod 运行时目录。
