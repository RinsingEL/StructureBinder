## 风格识别基准

**蒸汽朋克**：砖石厂房、金属骨架、铜制设备、大跨候车与生产空间；识别来自工业构造，不是必须修在某种地形。

这段定义用于指导后续制作和风格复核，不代表本次已经重做或逐项确认现有模型全部符合；具体落地条件仍读各模型的 `terrain`。

## 环境与文明表达

适合具有生产与客货运输需求、能够组织可行线路的谷地、盆地或交通走廊。车站与工厂依据运输用途选址，山地线路另行考虑高差。

砖石、金属与玻璃构成清晰的生产设施；住宅、服务建筑和设备维护空间共同表现铁路社会。

角色定义、填充多样性标准、内饰与标记要求见[总清单](../README.md)。原有编号保留；新增填充族使用 `SR-Fxx`。结构族数量不等于实际模型数量。
