# DS-F03-v04 · 双列采收葡萄园

填充结构；两列采收、集中分拣、周转筐和前段取水均有布置与站位，主通道连续。空间标记包括：葡萄棚 · 西棚、葡萄棚 · 东棚、采收分拣棚。

- **选址**：只用于整合包设定允许种植葡萄、具可靠灌溉和适宜土壤的绿洲
- **地块**：两列长藤棚夹中央作业道，后段设独立分拣遮棚、货筐和取水处。
- **接地**：使用地坪 Y=1，脚底 Y=2；不自动削坡或补齐外部通路
- **边界**：模板包含内部地坪和封边，未写入的凹角与外部格保持原环境
- **作物表达**：原版木架、常驻树叶和倒挂紫晶簇作为葡萄果串外观；非可收获作物，不声明生长或产量
