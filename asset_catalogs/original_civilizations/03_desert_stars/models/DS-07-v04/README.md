填充结构；下台原砂、燃料和登记交付，上台窑前操作、窑后维护、器具、模具、冷却、饮水坐席均已标记。空间标记包括：下台原料库、下台成品间、上台加工间、上台露窑与遮阳。

- **选址**：具砂料、燃料、供水与外运条件的生产地块，热作业区和烟道周围保持净空
- **地块**：下台收料与成品，上台窑炉和加工，短阶连接一格高差，生产与顾客空间分开。
- **接地**：下台脚底 Y=2，上台脚底 Y=3，沿 +Z 抬升一格
- **落地**：独立完整建筑与内部院落，不依靠运行时补齐；模板外与凹角未写入格保持原环境
