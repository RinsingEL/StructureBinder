- **选址**：有稳定生活用水的干热聚落，通风方向与遮阳不被邻屋完全堵塞
- **地块**：前低后高两台住宅，低院炊事、上台睡眠与家务，用内院短阶衔接一格高差。
- **落地**：独立住宅模板，庭院及其硬地属于实际占地；未写入格保留原环境
- **高程**：主入口脚底 Y=2；上台脚底 Y=3
