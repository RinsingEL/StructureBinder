填充结构；双操作台、双维护位、原砂、燃料、模具和冷却陈列分区，宽院落保留横向搬运和歇工取水。空间标记包括：原料库、露院双窑、加工冷却厅、独立休息室。

- **选址**：具砂料、燃料、供水与外运条件的生产地块，热作业区和烟道周围保持净空
- **地块**：露天双窑与遮阳操作区并列，东北原料库、南侧加工冷却厅和独立休息室围院展开。
- **接地**：主入口与地面层脚底 Y=2；上层版二层脚底 Y=9
- **落地**：独立完整建筑与内部院落，不依靠运行时补齐；模板外与凹角未写入格保持原环境
