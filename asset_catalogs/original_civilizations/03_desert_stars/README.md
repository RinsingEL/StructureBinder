## 风格识别基准

**沙漠**：厚墙、内院、遮阳廊、平顶与穹顶、几何装饰；表达可辨认的干旱地区建筑传统，不泛指所有沙地建筑。

这段定义用于指导后续制作和风格复核，不代表本次已经重做或逐项确认现有模型全部符合；具体落地条件仍读各模型的 `terrain`。

## 环境与文明表达

以可靠水源、遮蔽条件和商路补给间距为依据，适合绿洲、干旱盆地与山前通道；供水关系应能解释居民生活。

厚墙、内庭与遮阳空间表现干旱生活；星象、玻璃、香料和商队设施体现文化与产业。

角色定义、填充多样性标准、内饰与标记要求见[总清单](../README.md)。原有编号保留；新增填充族使用 `DS-Fxx`。结构族数量不等于实际模型数量。
