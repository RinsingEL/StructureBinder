住宿、分拣棚与偏折船骸形成三块独立作业空间；外缘木台由实体岩坳承接。
船骸是预制静态情景，不能宣称模拟过坠落；实地地形和历史来源必须匹配。

空间用途：回收队生活营房：四床、共餐、炉灶、饮水及物资；有顶回收工棚：拆解、修理和分类周转；坠落船骸现场：偏折龙骨、断肋、折桅与落帆；拆解通路沿外侧。

- **选址**：高原峡谷侧的低缓岩坳，先有可进入的坠落船骸与回收需求，再布置临时营地；北侧步道接补给
- **高程**：主平台地板 Y=4，入口脚底 Y=5；外接同高岩台道路
- **固定与承重**：北侧石砌锚座压在实体岩台，南侧木梁和斜撑回接石墩；石墩底必须落在连续承载岩层。不可当作无支撑浮空结构。
- **接驳边界**：模板内支撑与边栏完整；外侧山体、接驳道路、峡谷宽度及航行净空必须按实际场地核对。
- **运行边界**：泊位、缆索、风向仪、船体与吊装均为静态空间表达；未实现飞行、气象、物流或受力模拟。
