## 环境与文明表达

依托具有飞行补给需求的高原、山脊、悬崖或浮空设定；区分有地面支撑与真正浮空的落地条件。

泊塔、缆索、悬臂平台与导航设施表现航行社会，粮食、维修和日常居住同样完整。

角色定义、填充多样性标准、内饰与标记要求见[总清单](../README.md)。原有编号保留；新增填充族使用 `CN-Fxx`。结构族数量不等于实际模型数量。
