# 精灵新制 · 第二版

完成离线建模与本轮复核。本套 24 个独立类型，含 8 个文化核心；不以换色、旋转或尺寸变体充数。

分叉柱、叶脉曲顶、椭圆地坪、架空客亭与跨庭桥廊。核心从白枝议庭、月泉圣所到双塔王庭分别组织主空间。
