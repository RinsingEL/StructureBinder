## 环境与文明表达

依托明确存在的古代巨械或建筑遗骸，考虑残骸稳定范围、可居住空间、补给与运输；新旧空间关系可被观察。

新住宅、回收产业和公共生活附着在旧文明设施上，保留可辨认的时代叠加。

角色定义、填充多样性标准、内饰与标记要求见[总清单](../README.md)。原有编号保留；新增填充族使用 `RS-Fxx`。结构族数量不等于实际模型数量。
