# RS-03 断轮广场零件市场

角色 `planning_role.key`，尺寸 47×24×43。23张当前最终视图作者实看通过；确定性重建、数据与导航零警告，待主审。

深色旧机梁、齿轴与氧化铜壳为旧骨架；浅木、橙色板补丁与布棚为后加住用空间。

功能分区：

- 市场分类后仓：有独立旧场坪支承的后加板房，门窗和完整使用通路
- 旧断轮下新摊街：四类有后勤柜的行业摊位围绕可通行庭院

使用点：登记零件后仓、精细仪表盒、鉴定与批次登记、紧固件与金工、紧固件与金工储物、旧仪表鉴别、旧仪表鉴别储物、回收帆布缝补、回收帆布缝补储物、修复工具试用、修复工具试用储物、摊位管理与账目、搬运路入口。

落地条件：

- 选址：旧巨械车轮骨架包围交易前庭，商棚与后仓使用独立落地支架，南侧接商路。
- 接地：完整旧机座埋入稳固碎石台地，地坪Y=2、入口脚底Y=3；不将薄壳残板当作新房基础。
- 外接：南侧接既有搬运路；模板外须保留回转、排水与坠落隔离带。避开活动滑坡、洪道及悬空残骸。
- 供给：生活水依外部运水，燃料和食物由聚落补给；不假设旧机械仍能工作。
- 边界：独立承载静态原版结构；残骸稳定、探险门禁与设备功能未接入运行时。
