# RS-11 断继电塔下旅途营地

角色 `planning_role.structure`，尺寸 43×27×41。22张当前最终视图作者实看通过；确定性重建、数据与导航零警告，待主审。

深色旧机梁、齿轴与氧化铜壳为旧骨架；浅木、橙色板补丁与布棚为后加住用空间。

功能分区：

- 修补值守住屋：有独立旧场坪支承的后加板房，门窗和完整使用通路
- 断塔机座：上部禁止居住的旧设施，地面勘察与独立新营地分开

使用点：屏后床位、衣物与床品、干粮与器具、备餐火灶、运水和清洗、用餐桌席、起居记事与交接、继电零件与巡路维修、线路修复工作台、应急运水、停用继电机柜、搬运路入口。

落地条件：

- 选址：城外旧继电站完整基座与断塔仍在，生活板房避开塔臂坠落区，物资由巡路者补给。
- 接地：完整旧机座埋入稳固碎石台地，地坪Y=2、入口脚底Y=3；不将薄壳残板当作新房基础。
- 外接：南侧接既有搬运路；模板外须保留回转、排水与坠落隔离带。避开活动滑坡、洪道及悬空残骸。
- 供给：生活水依外部运水，燃料和食物由聚落补给；不假设旧机械仍能工作。
- 边界：独立承载静态原版结构；残骸稳定、探险门禁与设备功能未接入运行时。
