# RS-02 巨械肋架拆解大厅

角色 `planning_role.key`，尺寸 49×23×45。25张当前最终视图作者实看通过；确定性重建、数据与导航零警告，待主审。

深色旧机梁、齿轴与氧化铜壳为旧骨架；浅木、橙色板补丁与布棚为后加住用空间。

功能分区：

- 修补值守住屋：有独立旧场坪支承的后加板房，门窗和完整使用通路
- 巨械残轴拆解区：双侧工位围绕真实旧轴和机座，中央吊运天窗及前场搬运通路

使用点：屏后床位、衣物与床品、干粮与器具、备餐火灶、运水和清洗、用餐桌席、起居记事与交接、拆解待验零件、分类合格部件、初拆切整台、修复校整台、作业工单与检验、零件清洗、旧巨械传动轴勘察、搬运路入口。

落地条件：

- 选址：废弃巨械腹腔旧机座上开展拆解；侧边新值守屋独立落地，前场通重件。
- 接地：完整旧机座埋入稳固碎石台地，地坪Y=2、入口脚底Y=3；不将薄壳残板当作新房基础。
- 外接：南侧接既有搬运路；模板外须保留回转、排水与坠落隔离带。避开活动滑坡、洪道及悬空残骸。
- 供给：生活水依外部运水，燃料和食物由聚落补给；不假设旧机械仍能工作。
- 边界：独立承载静态原版结构；残骸稳定、探险门禁与设备功能未接入运行时。
