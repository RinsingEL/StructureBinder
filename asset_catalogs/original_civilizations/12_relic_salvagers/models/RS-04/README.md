# RS-04 断裂控制舱与侧接档案间

角色 `planning_role.structure`，尺寸 43×23×39。19张当前最终视图作者实看通过；确定性重建、数据与导航零警告，待主审。

深色旧机梁、齿轴与氧化铜壳为旧骨架；浅木、橙色板补丁与布棚为后加住用空间。

功能分区：

- 后加档案修复间：有独立旧场坪支承的后加板房，门窗和完整使用通路
- 原控制舱：成排停用控制台、操作席与旧档案，保持历史用途证据

使用点：断电主控制台、旧纸本运行档案、旧线路图校对、旧值班铺与遗留私物、整理后档案柜、复抄工作台、纸本装帧修补、控制舱外断轴遗存、搬运路入口。

落地条件：

- 选址：旧控制舱嵌在稳定半截机壳内；残轴尾段保持封边，新增档案间由外侧地基承重。
- 接地：完整旧机座埋入稳固碎石台地，地坪Y=2、入口脚底Y=3；不将薄壳残板当作新房基础。
- 外接：南侧接既有搬运路；模板外须保留回转、排水与坠落隔离带。避开活动滑坡、洪道及悬空残骸。
- 供给：生活水依外部运水，燃料和食物由聚落补给；不假设旧机械仍能工作。
- 边界：独立承载静态原版结构；残骸稳定、探险门禁与设备功能未接入运行时。
