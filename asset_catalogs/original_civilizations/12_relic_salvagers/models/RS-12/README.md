# RS-12 封存动力舱设备库

角色 `planning_role.structure`，尺寸 47×25×45。18张当前最终视图作者实看通过；确定性重建、数据与导航零警告，待主审。

深色旧机梁、齿轴与氧化铜壳为旧骨架；浅木、橙色板补丁与布棚为后加住用空间。

功能分区：

- 设备维护备品侧间：有独立旧场坪支承的后加板房，门窗和完整使用通路
- 封存双动力机舱：两组真实机座、轮轴与管体；封存区只从开放走廊观察，不伪造内部可达点
- 开放维护走廊：检查窗、耗材及记录点保持连通

使用点：玻璃封存界面与设备观察、密封备件与工具、维护装配台、封存台账、开放维护通道耗材、设备布局核验、搬运路入口。

落地条件：

- 选址：完整旧动力舱基础上的设备封存遗址，单侧维修走廊开放；封存区保留可观察边界。
- 接地：完整旧机座埋入稳固碎石台地，地坪Y=2、入口脚底Y=3；不将薄壳残板当作新房基础。
- 外接：南侧接既有搬运路；模板外须保留回转、排水与坠落隔离带。避开活动滑坡、洪道及悬空残骸。
- 供给：生活水依外部运水，燃料和食物由聚落补给；不假设旧机械仍能工作。
- 边界：独立承载静态原版结构；残骸稳定、探险门禁与设备功能未接入运行时。
